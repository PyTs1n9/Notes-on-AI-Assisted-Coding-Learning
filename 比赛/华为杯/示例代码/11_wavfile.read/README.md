# 读 WAV 与识别采样格式

[返回示例总目录](../README.md)。每段独立运行，下面是 `BaiQing3.10AI` 的真实输出。

## 函数卡

- **作用**：读取 WAV 的采样率和 PCM（数字采样值）序列。
- **语法**：`scipy.io.wavfile.read(filename, mmap=False)`。
- **关键参数**：`filename` 是文件路径或类文件对象；`mmap` 是可选的内存映射读取，部分格式不支持。
- **返回值**：返回 `(sample_rate, data)`。单声道形如 `(帧数,)`，多声道形如 `(帧数, 通道数)`。数据类型依 WAV 编码而定。
- **常见坑**：别把采样率和数组顺序写反。单声道没有通道轴；多声道降为单声道通常沿 `axis=1`。整数 PCM 的静音中心依格式而变，8 位无符号通常是 128。先转浮点再做差值。
- **适用场景**：音频质检、基本采样统计、频谱预处理。

## 示例 1：读取单声道 PCM16 并汇报时长

从文件得到采样率、帧数、时长和有符号峰值，不假定固定采样率。

运行 [示例01.py](示例01.py)。

```text
采样率、帧数、存储类型 8000 6000 int16
时长（秒）、绝对峰值 0.75 11000.0
```

## 示例 2：读取立体声，观察混成单声道后的抵消

两个通道中的相反分量会相互抵消；先做形状核对，再按每帧平均。

运行 [示例02.py](示例02.py)。

```text
采样率、转换前后形状 12000 (6000, 2) (6000,)
各声道峰值、混音峰值 [10926.0, 10926.0] 2000.0
```

## 示例 3：把 uint8 采样还原成以零为中心的波形

区分无符号 PCM 静音中心和有符号 PCM 的零，避免把直流偏置误当成信号。

运行 [示例03.py](示例03.py)。

```text
读取类型、采样率、原均值 uint8 8000 128.0
居中后的最小值、最大值、均值 -0.703125 0.703125 0.0
```
