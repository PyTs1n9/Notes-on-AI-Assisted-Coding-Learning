## 函数卡

- **作用**：把时域采样序列转换成复数频率分量。每个分量可取幅值，还保留相位信息。
- **语法**：`np.fft.fft(a, n=None, axis=-1, norm=None, out=None)`（NumPy 2.x；1.x 无 `out`）；反变换 `np.fft.ifft(a, n=None, axis=-1, norm=None, out=None)`。
- **关键参数**：`n` 是变换点数；大于当前轴长会补零，小于会截断；`axis` 表示沿哪个轴变换；`norm` 控制归一化方式。
- **返回值**：复数数组，默认沿最后一维变换。可以用 `np.abs` 取各频率分量的量值。
- **常见坑**：`fft` 的原始结果是双边谱。对于实信号，要恢复单边正弦振幅，应按约定缩放且不能把 DC、Nyquist 一起翻倍。比较加窗的结果还要考虑窗的增益。补零把频率格点变密，不会增加真实时长或分辨信息。
- **适用场景**：分解混合音、观察补零、按指定频段做离线频域演示。
