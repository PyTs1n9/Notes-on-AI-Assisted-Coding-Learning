## 函数卡

- **作用**：检查一列文本中每条是否包含指定字面量或正则模式。
- **语法**：`Series.str.contains(pat, case=True, flags=0, na=<按 dtype 决定>, regex=True)`。
- **关键参数**：`regex=False` 表示按字面匹配；`case=False` 不区分大小写；`na=False` 让缺失直接返回假。
- **返回值**：与原 Series 同索引的布尔掩码（不指定 `na` 时可能有缺失）。
- **常见坑**：点号、加号、竖线默认可能被当成正则符号；需要可用于筛选的布尔掩码时显式处理 `na`。
- **适用场景**：工单渠道过滤、业务编号抽取、组合命中及排除词。
