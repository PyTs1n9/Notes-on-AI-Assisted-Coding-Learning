## 函数卡

- **作用**：把像素或一般数值按区间计数，不负责画图。
- **语法**：`np.histogram(a, bins=10, range=None, density=None, weights=None)`。
- **关键参数**：`bins` 可是箱数或完整边界；`range` 是自动等宽分箱的范围；`density=True` 返回概率密度而非计数。
- **返回值**：返回 `counts_or_density, bin_edges`；边界比箱数多 1。除最后一箱外都是左闭右开，最后一箱包含最右边界。
- **常见坑**：指定区间外的数据不计数；各箱宽不是 1 时密度的和不一定为 1，乘箱宽后总面积才为 1。比较不同样本量的比例时应使用频数除以总数。
- **适用场景**：RGB 通道分布、质检分级、跨批次分布比较。

## 示例 1：RGB 三通道各自计数

对小型彩色图逐通道取数，验证三个频数合计各是一个通道的像素数。

运行 [示例01.py](示例01.py)。

```text
通道、分箱计数 R [2, 2, 1, 1]
通道、分箱计数 G [5, 1, 0, 0]
通道、分箱计数 B [1, 1, 1, 3]
箱边界 [0.0, 64.0, 128.0, 192.0, 256.0]
```

## 示例 3：不等宽直方图的密度和箱内比例

区间宽度不同，密度值与「这一箱占几成」不是同一个数。

运行 [示例03.py](示例03.py)。

```text
箱内比例 [0.375, 0.25, 0.375]
各箱密度 [0.375, 0.125, 0.125]
密度乘箱宽后的合计 1.0
```
