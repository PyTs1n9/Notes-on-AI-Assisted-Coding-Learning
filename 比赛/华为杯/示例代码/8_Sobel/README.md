# OpenCV 有方向 Sobel 梯度

[返回示例总目录](../README.md)。每段独立运行，下面是 `BaiQing3.10AI` 的真实输出。

## 函数卡

- **作用**：对灰度图按某一方向估计亮度变化速率，结果能保留亮变暗或暗变亮的方向。
- **语法**：`cv2.Sobel(src, ddepth, dx, dy[, dst[, ksize[, scale[, delta[, borderType]]]]]) -> dst`。
- **关键参数**：`dx=1, dy=0` 求 x 梯度；`dx=0, dy=1` 求 y 梯度；`ksize=3` 使用 3×3 核，`ddepth=cv2.CV_32F` 保留带符号浮点结果。
- **返回值**：得到与输入灰度图宽高相同的梯度图，具体 dtype 由 `ddepth` 决定。
- **常见坑**：x 梯度描述像素沿列方向的变化，强响应常出现在竖直边缘。不把浮点梯度直接转无符号，否则会丢符号或发生错误的截断。
- **适用场景**：定位竖边/横边、识别亮暗过渡、比较噪声和边缘。

## 示例 1：定位竖条的左右边

竖条两侧的亮度变化沿 x，观察 x 与 y 梯度的差异。

运行 [示例01.py](示例01.py)。

```text
x 方向有梯度的列 [18, 19, 34, 35]
x 与 y 最大绝对梯度 760.0 0.0
```

## 示例 2：保留暗变亮和亮变暗

灰度图有两个过渡；8 位输出只适合不会丢失预期信息的情况，这里和浮点输出对照。

运行 [示例02.py](示例02.py)。

```text
浮点梯度最小/最大 -840.0 560.0
负梯度位置在无符号结果里的最大值 0
```

## 示例 3：平滑后再查找带噪图像的边

用同一张带噪合成板比较：平滑应降低背景误响应，同时真边缘仍明显。

运行 [示例03.py](示例03.py)。

```text
背景平均梯度：平滑前、后 24.29 7.96
平滑后的接缝平均梯度 365.83
```
