[返回示例总目录](../README.md)。每段独立运行，下面是 `BaiQing3.10AI` 的真实输出。

## 函数卡

- **作用**：根据字符映射表删除、替换字符；不执行正则，也不自动判断一个词的语义。
- **语法**：`str.maketrans(x[, y[, z]])`；`text.translate(table)`；`Series.str.translate(table)`。
- **关键参数**：两串 `x`、`y` 等长时逐字符对应；`z` 列出要删除的字符；单字典写法可把单字符映射到多字符或 `None`。
- **返回值**：Python 得到新字符串；Pandas 按行翻译，得到新 Series，原文本不变。
- **常见坑**：删除标点可能粘词；只替换你列出的字符，不能把字典键写成多字符短语。
- **适用场景**：去除订单编号分隔符、避免分词粘连、统一全角符号。

## 示例 1：只删除编号中的分隔字符

保留原编号列，同时生成用于检索的紧凑版本。

运行 [示例01.py](示例01.py)。

```text
原编号 ['AB-01/02', 'XY-20', None, 'SN/8-9']
检索时使用的编号 ['AB0102', 'XY20', 'SN89']
```

## 示例 2：分隔词时替换为空格而不删除

清理后仍能把相邻的设备词分开。

运行 [示例02.py](示例02.py)。

```text
删除后按空白切 ['门禁电梯空调']
替换后按空白切 ['门禁', '电梯', '空调']
```

## 示例 3：用字典统一全角文本

把写法不同的编号转成同样格式，甚至把一个特殊符号换成多个字符。

运行 [示例03.py](示例03.py)。

```text
原标签 ＡＢ：７℃※
规范标签 AB:7 degC
```
