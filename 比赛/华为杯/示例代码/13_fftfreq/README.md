# NumPy FFT 频率坐标

[返回示例总目录](../README.md)。每段独立运行，下面是 `BaiQing3.10AI` 的真实输出。

## 函数卡

- **作用**：把 FFT 序列的下标换算为以采样时间单位为基准的频率坐标；`d` 以秒给出时频率单位为 Hz。
- **语法**：`np.fft.fftfreq(n, d=1.0, device=None)`（NumPy 2.x；1.x 无 `device`）；对照实数专用频率轴 `np.fft.rfftfreq(n, d=1.0, device=None)`。
- **关键参数**：`n` 与 FFT 变换长度一致；`d` 是相邻采样的时间间隔，常为 `1 / sample_rate`（不是采样率本身）。
- **返回值**：`fftfreq` 返回长度 n 的双边频率轴，顺序先零频、正频，之后是负频。偶数长度的 Nyquist（采样率一半）一般以负号出现在这条轴上。
- **常见坑**：不要把 FFT 下标当 Hz；裁剪频率轴与频谱必须用同一索引。`rfft` 的输出应用 `rfftfreq` 配对，不能用全 FFT 轴乱切。
- **适用场景**：给频谱图标 Hz、对比不同采样率、控制端点和频带。

## 示例 1：从 5 毫秒记录间隔建立频率轴

采集仪给的是时间间隔而不是采样率，检查两边的频率和值是否对应。

运行 [示例01.py](示例01.py)。

```text
相邻正频格点差（Hz） 2.5
峰下标、峰所在频率 10 25.0
```

## 示例 2：不同采样率下，同一音对应不同下标

两个设备采相同的音，固定取相同行数；不要用 FFT 下标判断两声是否相同。

运行 [示例02.py](示例02.py)。

