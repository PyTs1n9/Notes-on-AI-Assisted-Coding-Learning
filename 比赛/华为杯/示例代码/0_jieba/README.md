# 结巴中文分词

[返回示例总目录](../README.md)。每段独立运行，下面是 `BaiQing3.10AI` 的真实输出。

## 函数卡

- **作用**：把没有天然空格的中文切成词。
- **语法**：`jieba.cut(sentence, cut_all=False, HMM=True)`；`jieba.cut_for_search(sentence, HMM=True)`；`jieba.add_word(word, freq, tag=None)`（本机 0.34）。
- **关键参数**：`cut_all=False` 是精确模式；`HMM` 控制是否用模型猜测未登录词；`freq` 是词频，本机版本必填，可提高领域词被切出的优先级。
- **返回值**：`cut` 和搜索模式都返回可迭代对象；用 `list` 可以保留完整结果。
- **常见坑**：本机结巴 0.34 没有 `lcut`。词表修改会影响当前进程；单独运行示例不会永久修改默认字典。
- **适用场景**：中文评论、FAQ 搜索、专业短语识别。

## 示例 1：精确分词和搜索索引

索引既希望命中整词，也希望能找到更短的词。比较两种模式是否提供不同的粒度。

运行 [示例01.py](示例01.py)。

```text
精确分词 ['南京市', '长江大桥', '恢复', '通行']
搜索索引 ['南京', '京市', '南京市', '长江', '大桥', '长江大桥', '恢复', '通行']
```
