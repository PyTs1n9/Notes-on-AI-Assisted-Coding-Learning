# OpenCV 向量幅值

[返回示例总目录](../README.md)。每段独立运行，下面是 `BaiQing3.10AI` 的真实输出。

## 函数卡

- **作用**：把每个位置的两项分量合成长度：平方后相加再开平方。
- **语法**：`cv2.magnitude(x, y[, magnitude]) -> magnitude`。
- **关键参数**：`x`、`y` 是同形状、同浮点深度的两幅数据，例如浮点 Sobel 梯度或速度分量。
- **返回值**：返回同大小的非负幅值矩阵；不包含方向。
- **常见坑**：不能用一正一负直接相加抵消；不要先量化为 8 位再算幅值。幅值和方向要分开分析。
- **适用场景**：梯度边缘强度、二维运动速度、比较各区域的高响应占比。

## 示例 1：找出跑带上的二维移动异常

单个方向的速度不显眼，两个方向一起算时可以超过告警阈值。

运行 [示例01.py](示例01.py)。

```text
各点合速度 [[2.0, 2.059999942779541, 5.230000019073486], [4.199999809265137, 2.240000009536743, 0.0]]
超限位置 [[0, 2]]
```
