# PCA 主成分分析

[返回示例总目录](../README.md)。每段独立运行，下面是 `BaiQing3.10AI` 的真实输出。

## 函数卡

- **作用**：寻找变化最明显的新坐标轴，用较少列表示原始数值数据。
- **语法**：`PCA(n_components=None, *, copy=True, whiten=False, svd_solver="auto", tol=0.0, iterated_power="auto", n_oversamples=10, power_iteration_normalizer="auto", random_state=None)`；`pca.fit_transform(X, y=None)`；`pca.transform(X)`。
- **关键参数**：`n_components=2` 表示两个新坐标；`svd_solver="full"` 时可把 `n_components` 设成目标解释方差比例。
- **返回值**：返回形如「样本数 × 主成分数」的坐标。`explained_variance_ratio_` 给出各轴分别保留的方差比例。
- **常见坑**：PCA 会中心化但不会按列除以标准差；量纲不同要按目标决定是否先标准化。新数据复用旧坐标，不重新拟合。轴的符号整体翻转不改变其意义。
- **适用场景**：高维数据展示、降维、历史与新样本在同一坐标系比较。

## 示例 1：由解释方差比例决定保留几列

三个互相关联的传感特征是否能用更少的轴表达？

运行 [示例01.py](示例01.py)。

```text
原始形状、降维形状 (5, 3) (5, 1)
保留的方差比例 0.9993
```
