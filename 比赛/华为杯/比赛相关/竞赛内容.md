# 竞赛内容

本赛项围绕教育、工业、医疗等实际场景，考核选手完成从数据读取、数据清洗、特征工程、模型构建、结果落地到预警报告生成的全流程人工智能应用开发能力，全面检验数据工程、传统机器学习建模、轻量量化大模型离线应用等综合技能：

1. 数据读取与探索性分析：读取数据集，完成基础信息与缺失值统计、成绩统计描述、分数段分布统计与可视化。
2. 数据清洗与预警标签构建：完成缺失值填充、异常值处理，构建预警标签并统计标签分布。
3. 特征工程与数据集划分：完成特征筛选、独热编码、衍生特征构造、分层抽样划分与特征标准化。
4. 预警分类模型构建与评估：使用逻辑回归等构建双模型，计算评估指标，进行模型适配分析与模型保存。
5. 模型优化与风险画像分析：完成样本不平衡处理、网格搜索调优、特征重要性分析与高风险信息输出。
6. 大模型辅助个性化预警报告生成：加载轻量量化大模型，提取风险等特征，设计结构化提示词。
