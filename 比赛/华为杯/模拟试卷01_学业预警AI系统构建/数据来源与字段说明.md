# 数据来源与字段说明

## 来源与使用边界

- 数据集：UCI Machine Learning Repository，Student Performance，葡萄牙语科目 `student-por.csv`。
- 数据页面：https://archive.ics.uci.edu/dataset/320/student+performance
- 下载入口：https://archive.ics.uci.edu/static/public/320/student+performance.zip
- DOI：https://doi.org/10.24432/C5TG7T
- 作者：Paulo Cortez、Alice Silva；引用论文为 *Using Data Mining to Predict Secondary School Student Performance*，2008。
- 原始数据包含葡萄牙两所中学的学生背景、行为及成绩，不代表中国职业院校。原始说明称无缺失值；本卷缺失、重复、空记录与部分超阈值缺勤为出题人注入的训练扰动。
- 本地 `data/student-por_original.csv` 为直接从 UCI 归档解出的原始字节备份；`data/UCI_原始字段说明.txt` 为归档中的 `student.txt`，保留原文。考试输入另存为 `data/student_warning_exam.csv`，不修改原始备份。
- 考试副本新增稳定匿名编号 `student_id`，注入少量输入缺失、标签缺失、重复、空记录和异常候选，供审计与清洗考核。注入位置及内部参考实现不随卷公开。
- 原始备份不是解题替代输入；不得把备份覆盖考试数据，不通过恢复原值跳过题目规定的缺失处理。

## 文件格式

考试 CSV：分号分隔，UTF-8 BOM，首行为字段名。空记录使用实际空字段组成的一整行，并非只含换行的空白文本；读入后须据各字段是否为空判断。原始 UCI 文件同样为分号分隔，类别值带引号。

输出 CSV 按试卷约定为逗号分隔、UTF-8 BOM，不保存 DataFrame 索引。所有路径从本模拟卷目录解释；学生脚本应能从该目录启动。

## 字段字典

模型输入的类型以以下字典为准，不因缺失后 CSV 推断为浮点而把类别或等级含义改掉。

| 字段 | 中文含义 | 值域/说明 | 本卷处理角色 |
|---|---|---|---|
| student_id | 本卷添加的匿名编号 | POR 前缀；稳定对应原数据记录 | 对账标识，禁止作为模型特征 |
| school | 学校 | GP、MS，两所来源学校 | 类别输入 |
| sex | 来源数据中的性别编码 | F、M | 类别输入；不得据此作歧视性报告 |
| age | 年龄 | 来源说明为 15–22 岁 | 数值输入 |
| address | 居住区域类型 | U 城区、R 农村；不是详细地址 | 类别输入 |
| famsize | 家庭人数档位 | LE3 不超过三人、GT3 超过三人 | 类别输入 |
| Pstatus | 父母同住状态 | T 同住、A 分开 | 类别输入 |
| Medu | 母亲教育等级 | 0 无，1 小学，2 初中阶段，3 中学，4 高等教育 | 数值等级输入 |
| Fedu | 父亲教育等级 | 与 Medu 同尺度 | 数值等级输入 |
| Mjob | 母亲职业类别 | teacher、health、services、at_home、other | 类别输入；不传给报告模型 |
| Fjob | 父亲职业类别 | 与 Mjob 同类别体系 | 类别输入；不传给报告模型 |
| reason | 选择学校原因 | home、reputation、course、other | 类别输入 |
| guardian | 监护人类别 | mother、father、other | 类别输入 |
| traveltime | 通学时间档位 | 1 少于15分钟，2 为15–30分钟，3 为30分钟–1小时，4 超过1小时 | 数值等级输入，非分钟数 |
| studytime | 每周学习时长档位 | 1 少于2小时，2 为2–5小时，3 为5–10小时，4 超过10小时 | 数值等级输入，非精确小时数 |
| failures | 既往课程挂科次数编码 | 保留来源记录的数值；用于识别是否存在挂科经历 | 数值输入，不改写为成绩 |
| schoolsup | 是否获得学校额外支持 | yes、no | 类别输入 |
| famsup | 是否获得家庭学业支持 | yes、no | 类别输入 |
| paid | 是否参加该科目付费补习 | yes、no | 类别输入 |
| activities | 是否参加课外活动 | yes、no | 类别输入 |
| nursery | 是否接受过幼儿教育 | yes、no | 类别输入 |
| higher | 是否希望接受高等教育 | yes、no | 类别输入 |
| internet | 家中是否有互联网 | yes、no | 类别输入 |
| romantic | 是否处于恋爱关系 | yes、no | 类别输入；不传给报告模型 |
| famrel | 家庭关系质量等级 | 1 很差至5很好 | 数值等级输入 |
| freetime | 放学后空闲时间等级 | 1 很少至5很多 | 数值等级输入 |
| goout | 与朋友外出频率等级 | 1 很少至5很多 | 数值等级输入 |
| Dalc | 工作日饮酒等级 | 1 很少至5很多 | 数值等级输入；不传给报告模型 |
| Walc | 周末饮酒等级 | 1 很少至5很多 | 数值等级输入；不传给报告模型 |
| health | 自报健康状态等级 | 1 很差至5很好，不是临床诊断 | 数值等级输入；不传给报告模型 |
| absences | 缺勤次数 | 非负计数；本卷以大于30作为业务异常候选 | 数值输入；原始缺失与异常分别处理 |
| G1 | 第一阶段成绩 | 0–20 | 本卷禁止作为特征 |
| G2 | 第二阶段成绩 | 0–20 | 本卷禁止作为特征 |
| G3 | 期末成绩 | 0–20；0 为有效成绩 | 标签来源与历史评价，禁止作为特征 |

> 原文中 `failures` 值域描述存在易误解表述，应保留实际记录并将其理解为历史挂科字段，不按文字说明自行把值替换成 4。`studytime` 只表示区间；报告可以说“每周学习时长处于第2档”，不能把编码2写成每周恰好2小时。

## 业务补充

本卷为对齐样题，保留原数据允许特征供建模，**不等于这些字段已通过真实校园系统的必要性与公平性审查**。技术报告应提出：核实采集时间、限制字段用途、评估分组误差、限制访问和人工复核。禁止从全局系数或重要性直接得出家庭、性别或健康决定学生表现的因果结论。
