# 模拟试卷01 使用说明

先打开 [正式作答试卷](华为杯模拟试卷01_学业预警AI系统构建.md)。100 分，建议用时 360 分钟；时长与配分为本次训练设计。卷内既有任务要求，也有明确验收点和留白作答区。

## 开考顺序

1. 阅读 [开考前环境说明](开考前环境说明.md)，确认现有解释器与离线运行工具。依赖未满足时先记阻塞，不计入正式答卷用时。
2. 阅读 [数据来源与字段说明](数据来源与字段说明.md)，使用已经提供的 `data/student_warning_exam.csv`，不必联网下载。
3. 按六项任务完成作答；[提交目录说明](提交目录说明.md) 给出全部成果位置。自行创建 `submission/`，当前目录未放解题脚本和参考输出。
4. 完成后填写试卷【我的作答】，提交源码、真实日志和产物，再进行验收。

## 随卷资源

- `data/student_warning_exam.csv`：唯一考试输入，已加入训练用脏数据，分号分隔。
- `data/student-por_original.csv`：UCI 原始备份，仅供来源核对。
- `data/UCI_原始字段说明.txt`：UCI 随包原文。
- `资源清单.json` 与 `资源核验.py`：只校验来源材料、数据和共享模型的字节完整性，不执行清洗、建模或报告题，不提供题目答案。
- `出卷核验说明.md`：出题人验证范围及限制，不含参考实现或模型指标。

如果在 PyCharm 运行资源核验，保持工作目录为本模拟卷，并沿用自己现有解释器。资源核验仅用 Python 标准库，不需要安装包。模型仍放在上一级 `比赛相关/轻量量化模型/`。

## 训练约定

试卷按比赛目标覆盖此前未学的分类及离线推理内容，不把“题目已发布”记作掌握；原自主学习课程与通用大模型学习目录不因此重排。未作答前不公开标准答案；提交后按固定批改流程给参考答案和真实运行证据。
