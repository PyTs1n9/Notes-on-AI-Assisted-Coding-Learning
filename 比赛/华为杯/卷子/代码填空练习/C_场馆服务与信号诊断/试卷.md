## C01 场馆问答匹配与低分拒答（20 分）

输入：[`faq.csv`](data/faq.csv)、[`questions.csv`](data/questions.csv)。

`faq.csv` 中每行是一条知识库问题和答复；`questions.csv` 是新问题。统一把指定标点替为空格，结巴分词并去掉空白与 `请问`。只在知识库拟合词表，新问题只转换；用余弦相似度（衡量词向量方向接近程度）取最高分条目，并列保留原表最先出现的一条。如果最高分低于 0.35，或新问题没有词表内词，答案写 `转人工`，FAQ 编号留空，不得默认返回首条。保存每条结果和最高分。

验收产物：`faq_matches.csv`。

作答文件：[C01.py](作答/C01.py)。分值：1 空 4 分、2 空 4 分、3 空 4 分、4 空 4 分、5 空 4 分。

```python
import jieba
import numpy as np
import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

marks = '，。！？?!'
mapping = str.maketrans(marks, ' ' * len(marks))

def segment(text):
    keep = []
    for word in jieba.cut(text.translate(mapping)):
        if word.strip() and word != '请问':
            keep.append(word)
    return ' '.join(keep)

faq = pd.read_csv(os.path.join(DATA, 'faq.csv'))
queries = pd.read_csv(os.path.join(DATA, 'questions.csv'))

catalog = vectorizer.__C01_01__(faq['title'].map(segment))
lookup = vectorizer.__C01_02__(queries['query'].map(segment))
scores = cosine_similarity(__C01_03__)
results = []
for i in range(len(queries)):
    best = int(__C01_04__)
    score = float(scores[i, best])
    if __C01_05__:
        faq_id = ''
        answer = '转人工'
    else:
        faq_id = faq.at[best, 'faq_id']
        answer = faq.at[best, 'answer']
    results.append({'id': queries.at[i, 'id'], 'faq_id': faq_id, 'score': score, 'answer': answer})
pd.DataFrame(results).to_csv(os.path.join(OUT, 'faq_matches.csv'), index=False, encoding='utf-8-sig')
print('各问题命中或转人工', [row['faq_id'] or row['answer'] for row in results])
```

## C02 历史行为聚类后分配新访客（20 分）

输入：[`history.csv`](data/history.csv)、[`today.csv`](data/today.csv)。

仅使用历史表的 `weekly_visits`、`indoor_min`、`outdoor_min`，拟合标准化器、三簇 KMeans 和两维 PCA；编号只用于关联结果。今日来访者不能参与拟合，必须复用历史均值、尺度、聚类中心及 PCA 坐标系。保存新样本的簇与坐标，并画历史散点和今日叉号，颜色使用同一对象的簇标签。聚类在标准化的三列特征空间进行，而不是在二维图上进行。

验收产物：`visitor_overlay.png`、`history_map.csv`、`today_map.csv`。

作答文件：[C02.py](作答/C02.py)。分值：1 空 4 分、2 空 4 分、3 空 4 分、4 空 4 分、5 空 4 分。


## C03 预约记录：原始缺失、格式不合法、范围不合法（20 分）

输入：[`bookings.csv`](data/bookings.csv)。

验收产物：`booking_issues.png`、`booking_issues.csv`、`valid.csv`、`issue_tally.csv`。

作答文件：[C03.py](作答/C03.py)。分值：1 空 4 分、2 空 4 分、3 空 3 分、4 空 3 分、5 空 3 分、6 空 3 分。

## C05 定位一段音频中第一次主频切换（20 分）

输入：[`switch.wav`](data/switch.wav)。

把单声道 WAV 依次切成互不重叠的 0.5 秒窗，尾部不足一窗忽略。每窗去均值，应用 Hann（两端逐渐收小的权重窗），用窗长度四倍的点数补零做 FFT，与同点数的频率轴对齐。在 200–900 Hz 闭区间找主频。相邻窗主频绝对差第一次至少达到 100 Hz 时，以后一窗起点记录切换时刻；若始终不达标，报告 `no change`。输出逐窗主频、相邻差和带切换标记的折线图。

验收产物：`segment_peaks.csv`、`first_change.csv`、`frequency_transition.png`。

作答文件：[C05.py](作答/C05.py)。分值：1 空 4 分、2 空 4 分、3 空 3 分、4 空 3 分、5 空 3 分、6 空 3 分。

```python

band = (freq >= 200) & (freq <= 900)
starts = []
peaks = []
for start in range(0, len(audio) - window + 1, window):
    part = audio[__C05_02__]
    tapered = (part - part.mean()) * np.hanning(window)
    spectrum = np.fft.fft(__C05_03__)
    j = np.argmax(np.abs(__C05_04__))
    peaks.append(float(freq[band][j]))
    starts.append(start / sr)
jumps = np.abs(__C05_05__)
found = np.flatnonzero(jumps >= 100)
change_at = None
if found.size:
    change_at = starts[__C05_06__]
result = pd.DataFrame({'start_s': starts, 'peak_hz': peaks})

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(starts, peaks, marker='o')
if change_at is not None:
    ax.axvline(change_at, color='red', linestyle='--')
ax.set(xlabel='Window start (s)', ylabel='Peak frequency (Hz)')
fig.tight_layout()
fig.savefig(os.path.join(OUT, 'frequency_transition.png'), dpi=120)
plt.close(fig)

    print('首次切换 no change')

    print('首次切换（秒）', change_at)
```
