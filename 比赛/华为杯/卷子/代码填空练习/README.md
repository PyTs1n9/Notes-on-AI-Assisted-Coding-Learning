## 开始作答

1. 打开某一套的 `试卷.md`，读题后打开对应 `作答/题号.py`。只替换有编号的空位；脚本可独立运行，不需要先做前一题。
2. 沿用 PyCharm 的 `BaiQing3.10AI`，直接运行。每套的输入都已放在自己的 `data/`；产物会写到 `作答/outputs/题号/`，不会覆盖原始数据。
3. 做完再打开 `标准答案`。每空均有填法、理由以及对应该题的完整脚本和实跑输出。数值相当、满足题意的其他写法也可接受。

建议顺序：先做 A 卷覆盖全范围；再做 B、C 卷检验换条件后能不能独立填；最后练 D 卷的完整建模流程。有单个函数不熟时，可以先跑一个不使用原题数据的专项示例。
