## B03 传感器日志：真重复和业务键冲突

[完整参考实现](参考实现/B03.py)

| 空位 | 填入 | 为什么 |
| --- | --- | --- |
| `__B03_01__` | `False` | 标记全组；新增的行序号不可放进比较字段。 |
| `__B03_02__` | `drop_duplicates` | 先去掉真正的内容重复，才能区分下一步的同键不同内容。 |
| `__B03_03__` | `unique.duplicated(subset=key, keep=False)` | 按业务键而非全列判断，且列出同组各成员。 |

## B04 质检图：方向占优和幅值阈值

[完整参考实现](参考实现/B04.py)

| 空位 | 填入 | 为什么 |
| --- | --- | --- |
| `__B04_01__` | `cv2.COLOR_RGB2GRAY` | 输入通道顺序不同会改变灰度和最终边缘。 |
| `__B04_02__` | `1, 0` | 对 x 方向求一阶导；x 表示亮度变化方向，不是边线朝向。 |
| `__B04_03__` | `0, 1` | 对 y 方向求一阶导；不要把两个参数对写成一样。 |
| `__B04_04__` | `mag >= 120` | 使用合成幅值筛选强边缘，阈值边界包含等号。 |
| `__B04_05__` | `(np.abs(gx) >= np.abs(gy))` | 方向占优比较绝对值，否则负的强梯度会被误判。 |
| `__B04_06__` | `~x_edge` | 剩余强边缘全部归 y，不能把弱边缘也选进去。 |
| `__B04_07__` | `rgb[:, :, 1], bins=limits` | 绿色位于 RGB 的下标 1；边界列表允许箱宽不等。 |

**真实运行输出**

```text
强边缘、x 占优、y 占优 1206 511 695
```

## B05 设备音频：只在指定频带找峰

[完整参考实现](参考实现/B05.py)

| 空位 | 填入 | 为什么 |
| --- | --- | --- |
| `__B05_01__` | `audio - audio.mean()` | 减去均值以去除直流偏置；并不去除其他低频成分。 |
| `__B05_02__` | `centered` | 题设用全长，未指定 n 时默认变换输入全长。 |
| `__B05_03__` | `n, d=1 / sr` | 点数与 FFT 相同；d 为采样周期而不是采样率。 |
| `__B05_04__` | `(f >= 250) & (f <= 600)` | 带内掩码要同时满足上下限，且包含等号。 |
| `__B05_05__` | `np.argmax(band_mag)` | 局部峰位置是带内数组的下标，必须用同一掩码的带内频率轴进行映射。 |

**真实运行输出**

```text
各段全谱峰、带内峰 [(88.0, 326.0), (88.0, 513.6)]
带内峰绝对差 187.60000000000002
```
