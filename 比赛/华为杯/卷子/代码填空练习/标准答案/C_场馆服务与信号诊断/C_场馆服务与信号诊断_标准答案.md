## C03 预约记录：原始缺失、格式不合法、范围不合法

[完整参考实现](参考实现/C03.py)

| 空位 | 填入 | 为什么 |
| --- | --- | --- |
| `__C03_01__` | `'coerce'` | 非法日期转为缺失标记后可继续审计，原始列仍在。 |
| `__C03_02__` | `'coerce'` | 不可解析的字符串转为 NaN，不能把它们强行当作 0。 |
| `__C03_03__` | `raw['day'].notna() & days.isna()` | 这条是有原始日期但解析失败，不等于原始缺失。 |
| `__C03_04__` | `raw['minutes'].notna() & minutes.isna()` | 时间长度也要区分原始空值与坏字符串。 |
| `__C03_05__` | `(minutes < 0) \| (minutes > 240)` | 仅能解析并且超过上下限的数字会命中；0 和 240 合法。 |
| `__C03_06__` | `days.notna() & minutes.between(0, 240)` | 有效日期和合法数值须同时成立，缺失数值不会通过区间条件。 |

**真实运行输出**

```text
各类问题次数 {'bad_format': 3, 'missing': 2, 'out_of_range': 2}
通过记录 ['P1', 'P2', 'P8', 'P9']
```

## C05 定位一段音频中第一次主频切换

[完整参考实现](参考实现/C05.py)

| 空位 | 填入 | 为什么 |
| --- | --- | --- |
| `__C05_01__` | `n_fft, d=1 / sr` | 补零后频率点数必须与 FFT 相同；点更密不等于录得了更长信号。 |
| `__C05_02__` | `start:start + window` | 这里先截一个完整时间窗，不是每次从开头累计。 |
| `__C05_03__` | `tapered, n=n_fft` | 指定更长变换点数才会补零；不改变原时间窗。 |
| `__C05_04__` | `spectrum[band]` | 同一个频带掩码同时用于频率轴和频谱，才能正确找峰。 |
| `__C05_05__` | `np.diff(peaks)` | 在相邻峰值之间求一阶差分，输出比窗数少 1。 |
| `__C05_06__` | `int(found[0]) + 1` | 差分下标 0 对应第 1 和第 2 窗之间，所以切换时刻用后一窗起点。 |

**真实运行输出**

```text
各窗主频 [340.0, 345.0, 620.0, 620.0]
首次切换（秒） 1.0
```
