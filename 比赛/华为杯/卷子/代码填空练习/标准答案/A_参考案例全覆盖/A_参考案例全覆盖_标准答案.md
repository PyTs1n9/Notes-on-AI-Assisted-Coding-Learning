## A07 双 WAV 统计与频谱比较

[完整参考实现](参考实现/A07.py)

| 空位 | 填入 | 为什么 |
| --- | --- | --- |
| `__A07_01__` | `wavfile.read(os.path.join(DATA, name))` | SciPy 读 WAV 返回采样率和样本数组，顺序不能调换。 |
| `__A07_02__` | `1` | 二维 WAV 第 0 维是时间，第 1 维是通道；在通道维平均保留时间。 |
| `__A07_03__` | `len(audio) / sr` | 原始时长由原采样帧数决定，与 FFT 截断或补零无关。 |
| `__A07_04__` | `fft` | fft 返回复数频率分量，幅值需取绝对值。 |
| `__A07_05__` | `fftfreq` | d 是相邻采样点的秒数；截取的下标与幅值数组一致。 |
| `__A07_06__` | `n_fft` | 本题统一除以变换点数，不能改成原音频长度。 |
| `__A07_07__` | `mag[1:]` | 切去 DC 后索引从 0 重新开始，所以原数组下标要补回 1。 |
| `__A07_08__` | `abs(second['abs_peak'] - first['abs_peak']) / first['abs_peak']` | 相对差取两峰差的绝对值，基准为第一段的绝对峰值。 |

**真实运行输出**

```text
采样率、时长、峰值频率 [(8000, 0.75, 500.0), (12000, 0.75, 750.0)]
绝对峰值相对差、主频绝对差 0.5019 250.0
```
