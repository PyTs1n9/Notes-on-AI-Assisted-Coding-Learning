# 第四课：OpenCV 随机增强

## 【本节核心知识点】

把第三课的固定变换推进为随机增强：先抽取参数，再依次完成旋转、亮度线性变换、随机裁剪后缩放和高斯模糊；用像素范围截断与真实文件读回检查结果。

## 【核心概念讲解】

### 1. 前情提要与本课边界

上一课的彩色读取是 BGR（蓝、绿、红），数组形状是高、宽、通道；OpenCV 的输出尺寸却先宽后高。本课全程保持 BGR，只处理图片，不训练模型，也不把增强结果当成模型效果的证据。

**随机增强**指参数来自随机抽样。本课每张图都会经过各阶段，随机的是角度、乘数、加数和裁剪位置；“随机”不等于每个阶段都有执行概率。处理顺序会改变内容，本课统一为：原图 → 旋转 → 亮度 → 裁剪 → 缩放 → 模糊。

### 2. 随机种子管理的是一串抽样

`Generator`（随机数生成器）保存当前抽样状态；`seed`（随机种子）决定这串数从哪里开始。在相同 NumPy 版本中，重新创建相同种子的生成器，并按相同顺序、相同范围抽样，才能重现参数。只设置一次种子后连续抽两次，会消耗不同位置的随机数，通常得到不同结果；不应在每次循环内部重设种子却期待图片各不相同。

`uniform`（均匀浮点抽样）适合角度或亮度乘数；`integers`（整数抽样）适合像素坐标。后者默认包含下界、不包含上界；裁剪的最右合法起点是“图宽减窗口宽”，所以传给整数抽样的上界还要再加一。只在打印时四舍五入，计算仍用抽到的原始浮点数。

### 3. 旋转矩阵与画布

旋转矩阵是描述坐标如何移动的数字表，本课使用两行三列的矩阵：左侧两列描述旋转与大小变化，最后一列描述为了绕指定中心而增加的平移。`getRotationMatrix2D` 只算这张表；`warpAffine`（仿射变换）才把表应用到图片。仿射变换保持直线与平行关系，旋转是其中一种。

中心参数先横坐标、后纵坐标；像素编号从零开始，用宽、高各减一后的一半作为像素坐标中点。角度单位是度，正角在显示图上逆时针旋转；大小倍率为一表示不额外缩放。

输出画布仍可保持原图宽高，因此旋转后边角会被裁掉，原图覆盖不到的区域要补像素。本课指定常量补黑与双线性插值（利用周围位置估算新像素）；保持原尺寸不等于完整保留旋转后的全部内容。

### 4. 亮度线性变换与范围截断

每个颜色分量都执行“新值 = 乘数 × 旧值 + 加数”。乘数拉开或压缩分量差异，加数整体抬高或降低；乘数不是只控制亮度，也会影响对比度。这里是对已编码颜色分量的简化操作，不等同于物理光照模拟。

`uint8`（八位无符号整数）只能存零到二百五十五；先转成 `float32`（三十二位浮点数）做运算，保留负数和超范围值，再截断，最后转回 `uint8`。截断把低于下界的数改成下界、高于上界的数改成上界，并不把整张图按比例压缩。直接先转无符号整数可能回绕或丢失信息；也不要用带绝对值步骤的 `convertScaleAbs` 替代此处流程，否则负加数的含义会变。最后的类型转换直接舍去小数，不会自动四舍五入。

### 5. 随机裁剪后缩放与高斯模糊

裁剪只取一个局部窗口，缩放才把窗口变为统一输出尺寸。数组切片先行后列，起点包含、终点不包含；如果行列或宽高写反，窗口内容和形状都会出错。本课裁剪窗口与目标宽高比例相同，避免额外拉伸；固定窗口大小、只随机位置，是随机裁剪的一种简化形式。切片通常与原数组共享数据，本课只读取切片；若要直接修改它，应先了解副本与共享数据。

`GaussianBlur`（高斯模糊）用周围像素的加权平均平滑细节，中心附近权重更大；核大小决定观察多大的邻域，`sigma`（标准差）控制权重分布。本课指定正奇数核、显式的横纵标准差与反射边界；同样输入和参数会得到同样输出，它本身不会自动随机。模糊发生在缩放之后，调换顺序会改变结果。

## 【核心内置函数拆解】

沿用课程栏目名，下面主要是库函数和数组操作，并非 Python 内置函数。完整语法依据本机 `BaiQing3.10AI` 中 OpenCV 5.0.0、NumPy 2.2.5 的帮助；方括号表示可选参数，箭头说明返回值，实际代码不输入这些说明符号。`src` 指输入，`dst` 指输出，`hint` 是新版可选算法提示，本课省略。

### ① `np.random.default_rng` —— 创建随机数生成器

- **作用**：获得拥有独立状态的生成器。
- **完整语法**：`np.random.default_rng(seed=None)`。
- **关键参数**：`seed` 是整数种子；不指定时通常每次使用不同初始状态。
- **返回值**：`Generator` 对象，本课命名为 `rng`。
- **常见坑**：不受旧接口 `np.random.seed` 控制；不要混用两套随机接口。
- **适用场景**：集中管理增强参数，并在同版本同调用顺序下重放。

### ② `rng.uniform` —— 均匀抽取浮点参数

- **作用**：在指定区间抽取浮点数。
- **完整语法**：`rng.uniform(low=0.0, high=1.0, size=None)`。
- **关键参数**：`low` 是下界，`high` 是上界，`size` 指定抽样形状；本课省略 `size`，每次取一个数。
- **返回值**：单个浮点数或浮点数组。
- **常见坑**：通常按左闭右开区间理解，浮点舍入可能触及上界；不要在计算前把参数提前取整或四舍五入。
- **适用场景**：抽取旋转角度、亮度乘数。

### ③ `rng.integers` —— 抽取整数参数

- **作用**：在整数范围中抽样。
- **完整语法**：`rng.integers(low, high=None, size=None, dtype=np.int64, endpoint=False)`。
- **关键参数**：`low`、`high` 是上下界；`endpoint=False` 表示不包含上界；`high=None` 时从零抽到 `low` 之前。
- **返回值**：单个整数或整数数组。
- **常见坑**：合法裁剪起点可能包含最右、最下位置，要把整数上界多留一个；窗口超过原图会使范围非法。
- **适用场景**：抽取加数、裁剪左边界和上边界。

### ④ `cv2.getRotationMatrix2D` —— 计算旋转矩阵

- **作用**：围绕中心生成包含旋转和统一缩放的矩阵。
- **完整语法**：`cv2.getRotationMatrix2D(center, angle, scale) -> retval`。
- **关键参数**：`center` 为横、纵坐标；`angle` 为度；`scale` 为大小倍率。
- **返回值**：两行三列的浮点矩阵。
- **常见坑**：只生成矩阵，不会直接修改图片；中心不能写成行列顺序。
- **适用场景**：准备交给仿射变换的旋转参数。

### ⑤ `cv2.warpAffine` —— 将矩阵应用到图片

- **作用**：按仿射坐标关系生成输出图。
- **完整语法**：`cv2.warpAffine(src, M, dsize[, dst[, flags[, borderMode[, borderValue[, hint]]]]]) -> dst`。
- **关键参数**：`M` 为变换矩阵；`dsize` 为宽、高；`flags` 选插值，本课 `INTER_LINEAR`；`borderMode` 选边界，本课 `BORDER_CONSTANT`；`borderValue` 为 BGR 补充值。
- **返回值**：指定画布尺寸的图像数组。
- **常见坑**：画布保持原图尺寸时，旋转后可能裁掉角落；补黑像素还会参与后续亮度变换。
- **适用场景**：执行旋转或其他仿射变换。

### ⑥ `array.astype` —— 改变数组元素类型

- **作用**：按指定类型转换元素。
- **完整语法**：`array.astype(dtype, order='K', casting='unsafe', subok=True, copy=True)`。
- **关键参数**：`dtype` 是目标类型，本课先用 `np.float32`，最后用 `np.uint8`；其他参数保留默认。
- **返回值**：转换后的数组，默认创建副本。
- **常见坑**：类型转换不等于范围截断；浮点转整数会舍去小数部分。
- **适用场景**：亮度运算前后保护数值范围与保存类型。

### ⑦ `np.clip` —— 把分量限制在边界内

- **作用**：逐分量截断，不改变数组形状。
- **完整语法**：`np.clip(a, a_min=<no value>, a_max=<no value>, out=None, *, min=<no value>, max=<no value>, **kwargs)`。
- **关键参数**：`a` 是数组；`a_min`、`a_max` 是上下界；`out` 可指定输出数组；星号后的 `min`、`max` 是新版仅关键字边界写法，不与前一组混用。`<no value>` 是帮助中的未提供标记，实际不输入；本课按前三个位置参数传值。
- **返回值**：截断后的数组，本课不提供 `out`，接收新结果。
- **常见坑**：不会自动把浮点数组转回图片类型；也不是把最小最大值重新映射到边界。
- **适用场景**：保存前清除负分量和超过允许上界的分量。

### ⑧ 数组二维切片 —— 取出局部图片

- **作用**：选择指定行列范围，保留彩色通道。
- **完整语法**：`array[y_start:y_stop, x_start:x_stop]`；它是索引语法，不是函数调用。
- **关键参数**：前一段是上下范围，后一段是左右范围；结束位置不包含。
- **返回值**：局部数组，通常是共享原数据的视图。
- **常见坑**：越界切片可能静默变小，不能只看“没有报错”；需要核对真实形状。
- **适用场景**：取随机窗口，再单独缩放。

### ⑨ `cv2.resize` —— 裁剪后统一尺寸

- **作用**：放大或缩小数组。
- **完整语法**：`cv2.resize(src, dsize[, dst[, fx[, fy[, interpolation]]]]) -> dst`。
- **关键参数**：`dsize` 为宽、高；`interpolation` 为插值方法，本课缩小用 `INTER_AREA`（区域插值）；`fx`、`fy` 为替代的宽高缩放倍率，本课不用。
- **返回值**：目标尺寸的新数组。
- **常见坑**：尺寸参数与 `shape` 前两项顺序相反；目标比例不同会拉伸。
- **适用场景**：让不同取景窗口输出统一形状。

### ⑩ `cv2.GaussianBlur` —— 高斯模糊

- **作用**：按高斯权重平滑图片。
- **完整语法**：`cv2.GaussianBlur(src, ksize, sigmaX[, dst[, sigmaY[, borderType[, hint]]]]) -> dst`。
- **关键参数**：`ksize` 为核的宽、高；本课均用正奇数；`sigmaX`、`sigmaY` 为横纵标准差；`borderType` 本课显式为 `BORDER_REFLECT_101`（不重复边缘点的反射补边）。
- **返回值**：与输入形状、类型相同的模糊数组。
- **常见坑**：核不是输出图尺寸；它不自动随机。标准差为零或核为零有推导规则，本课不使用隐式推导。
- **适用场景**：模拟细节变软，观察模糊对图片的影响。

### ⑪ `cv2.imread` —— 读取输入和读回产物

- **作用**：把图片文件解码成数组。
- **完整语法**：`cv2.imread(filename[, flags]) -> retval`。
- **关键参数**：彩色输入用 `IMREAD_COLOR`；核对文件实际通道用 `IMREAD_UNCHANGED`；路径使用英文相对路径。
- **返回值**：图片数组，读取失败时返回 `None`。
- **常见坑**：本机含中文的绝对图片路径读取已实测失败，文件存在不等于解码成功。
- **适用场景**：读取本课素材及验证保存后的实际内容。

### ⑫ `cv2.imwrite` —— 保存每个阶段

- **作用**：按扩展名编码并保存图片。
- **完整语法**：`cv2.imwrite(filename, img[, params]) -> retval`。
- **关键参数**：`filename` 本课以 `.png` 结尾；`img` 是 BGR 数组；可选编码参数 `params` 本课省略。
- **返回值**：写入状态，成功为 `True`；非法格式等也可能抛异常。
- **常见坑**：不创建父目录；检查返回值后还要读回核对像素。
- **适用场景**：保存无损的阶段结果。

### ⑬ `np.array_equal` —— 比较全图像素

- **作用**：检查形状一致且每个位置的值都相等。
- **完整语法**：`np.array_equal(a1, a2, equal_nan=False)`。
- **关键参数**：`a1`、`a2` 为待比较数组；`equal_nan` 控制是否把对应的非数值标记视为相等，本课默认即可。
- **返回值**：一个真假值。
- **常见坑**：只比较一个角落或只比较形状不能证明全图相同；浮点中间结果可能需要容差，但这里比较保存前后整数图片。
- **适用场景**：检查 PNG 保存内容及固定种子重复结果。

演示里的 `float`、`int` 把单个数转为普通 Python 类型；`round` 只整理打印精度。数组的 `min`、`max` 汇总所有分量，`tolist` 可把像素转成列表。这些辅助打印不参与图片变换。

## 【完整代码示例 + 逐行注释】

继续使用 conda `BaiQing3.10AI`，不安装或修改环境。PyCharm 的本次运行“工作目录”设为 `D:/Code/Python/人工智能基础/深度学习自主学习/04_第四课：OpenCV随机增强`，运行 `demo.py`；命令行也先进入此目录。相对路径从进程工作目录开始查找，和脚本存放目录并非天然相同；`os.getcwd` 可查看当前工作目录。这里有意沿用英文相对图片路径，避开本机 OpenCV 中文绝对路径问题。

`input/sample.png` 原样复制自第三课 `input/practice_rgb.png`，用于延续观察；`input/practice_aug.png` 是独立的非正方形、不对称教师合成图，仅供本课练习，不是实拍数据。来源见 `input/素材说明.md`。本例按固定种子抽样并保存各阶段，重跑覆盖本例自己的同名文件。

```python
import os  # 导入已学的路径与目录工具
import cv2  # 导入 OpenCV（图像处理库）
import numpy as np  # 导入 NumPy（数组工具），用 np 简写

input_path = os.path.join('input', 'sample.png')  # 从本课工作目录拼接英文相对输入路径
output_dir = 'output_demo'  # 演示结果使用单独目录
os.makedirs(output_dir, exist_ok=True)  # 目录不存在时创建，重跑时允许目录已存在
image = cv2.imread(input_path, cv2.IMREAD_COLOR)  # 函数⑪：按 BGR 三通道读取图片
if image is None:  # 读取失败时先处理，避免继续访问空结果
    raise FileNotFoundError('无法读取 input/sample.png，请检查本课工作目录')  # 提示工作目录或输入问题
height, width = image.shape[:2]  # 取形状的前两项，先高后宽
print('原图 shape、dtype：', image.shape, image.dtype)  # 打印实际数组形状和元素类型
rng = np.random.default_rng(21)  # 函数①：创建固定种子的随机数生成器
angle = float(rng.uniform(-20, 20))  # 函数②：抽取旋转角度，单位是度
alpha = float(rng.uniform(0.8, 1.3))  # 函数②：抽取线性变换的乘数
beta = int(rng.integers(-25, 26))  # 函数③：抽取加数，整数上界不包含在内
print('随机角度、乘数、加数：', round(angle, 6), round(alpha, 6), beta)  # 只在打印时保留小数位，计算继续使用原值
center = ((width - 1) / 2, (height - 1) / 2)  # 中心按横坐标、纵坐标排列，采用像素坐标中点
matrix = cv2.getRotationMatrix2D(center, angle, 1.0)  # 函数④：生成绕中心旋转、大小倍率为 1 的矩阵
print('旋转矩阵：')  # 为下面的矩阵增加说明
print(matrix)  # 打印真实矩阵，它有两行三列
rotated = cv2.warpAffine(image, matrix, (width, height), flags=cv2.INTER_LINEAR, borderMode=cv2.BORDER_CONSTANT, borderValue=(0, 0, 0))  # 函数⑤：以双线性插值旋转，超出原图处补黑
raw = rotated.astype(np.float32) * alpha + beta  # 函数⑥：先转浮点数再运算，保留负数和超范围的值
print('截断前最小、最大：', float(raw.min()), float(raw.max()))  # min 和 max 汇总所有位置、所有通道的分量
clipped = np.clip(raw, 0, 255)  # 函数⑦：把超出像素范围的分量压回边界
bright = clipped.astype(np.uint8)  # 函数⑥：最后转回图片类型，小数部分直接舍去
print('截断后最小、最大：', int(bright.min()), int(bright.max()))  # 查看最终保存类型中的实际范围
crop_width = 200  # 指定裁剪窗口宽度，不是整张原图的宽度
crop_height = 120  # 指定裁剪窗口高度，必须小于或等于当前图片高度
x = int(rng.integers(0, width - crop_width + 1))  # 函数③：抽取左边界，允许窗口恰好贴住右边
y = int(rng.integers(0, height - crop_height + 1))  # 函数③：抽取上边界，行列位置不要颠倒
crop = bright[y:y + crop_height, x:x + crop_width]  # 函数⑧：先按行再按列切片，结束位置不包含在内
print('裁剪左、上、宽、高：', x, y, crop_width, crop_height)  # 记录随机窗口，便于复现和排查
resized = cv2.resize(crop, (160, 96), interpolation=cv2.INTER_AREA)  # 函数⑨：把裁剪图缩小，尺寸参数先宽后高
blurred = cv2.GaussianBlur(resized, (5, 5), sigmaX=1.1, sigmaY=1.1, borderType=cv2.BORDER_REFLECT_101)  # 函数⑩：用高斯加权平均模糊，边缘使用反射补点
print('裁剪图 shape：', crop.shape)  # 裁剪改变取景范围
print('最终图 shape、dtype：', blurred.shape, blurred.dtype)  # 缩放后再模糊，保持缩放后的形状与类型
file_names = ['rotated.png', 'brightness.png', 'crop.png', 'resized.png', 'blurred.png']  # 按处理顺序列出要保存的文件名
images = [rotated, bright, crop, resized, blurred]  # 同一顺序列出各阶段数组
for index in range(len(file_names)):  # 用已经熟悉的循环逐张保存与读回
    output_path = os.path.join(output_dir, file_names[index])  # 将目录和英文文件名连接起来
    success = cv2.imwrite(output_path, images[index])  # 函数⑫：按 PNG 格式保存 BGR 数组
    if not success:  # 写入失败时不继续假装成功
        raise RuntimeError('保存失败：' + file_names[index])  # 给出失败文件名
    saved = cv2.imread(output_path, cv2.IMREAD_UNCHANGED)  # 函数⑪：按文件实际通道与类型读回
    if saved is None:  # 核对图片能够重新解码
        raise RuntimeError('读回失败：' + file_names[index])  # 给出读回失败文件名
    same = np.array_equal(saved, images[index])  # 函数⑬：逐分量比较整张保存图和内存结果
    if not same:  # 保存成功也必须核对内容
        raise RuntimeError('像素不一致：' + file_names[index])  # 阻止带着内容差异继续运行
    print('读回：', file_names[index], saved.shape, saved.dtype, '像素一致：', same)  # 输出真实的文件形状、类型与比较结果
```
