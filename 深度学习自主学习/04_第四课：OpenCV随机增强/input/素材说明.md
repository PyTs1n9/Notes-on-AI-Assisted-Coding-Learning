# 本课输入素材说明

- `sample.png`：逐字节复制自第三课 `input/practice_rgb.png`，该图是教师合成的彩色教学图。用于演示与上节课的连续性，不声称是现实采集数据集。
- `practice_aug.png`：为第四课单独生成的教师合成 PNG。包含多通道渐变、不等大小的红蓝色块、偏移的绿色黄色区域和不对称黑白标记，方便判断旋转方向、裁剪内容、颜色顺序与模糊效果。它与演示图不同，避免从演示输出直接复制练习验收值。

素材仅用于解释数组与图像变换，不代表自然图像的统计分布。生成脚本、练习私有参考解及其输出留在课外教师临时目录，不放入课程，练习开始时没有预生成的 `output_practice`。

本机 OpenCV 已复现中文绝对图片路径解码失败，因此请按课件把工作目录设为本课目录，使用英文相对路径读写。输入原文件不参与覆盖；演示结果保存在 `output_demo`，练习结果由自己的脚本写入 `output_practice`。
