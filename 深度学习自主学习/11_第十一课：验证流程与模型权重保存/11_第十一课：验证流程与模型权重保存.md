# 第十一课：验证流程与模型权重保存

> 执行环境：`D:/Conda_envs/envs/BaiQing3.10AI/python.exe`。课程 `.venv` 缺少 `torch`，本课仅报告指定 Conda 环境实测，不安装或更改环境，也不声称双环境通过。

## 【本节核心知识点】

训练负责更新参数，验证负责选择方案，测试负责最终报告；把模式切换、梯度开关、按样本汇总指标和最佳权重保存连成一条清楚的流程。

## 【核心概念讲解】

### 1. 前情提要：先分清谁在改变什么

第十课比较不同训练顺序时，必须让两边使用**相同初始权重和相同数据**，并分别创建模型及优化器；同一模型先跑一段再接着跑，起点已经改变，不能当成公平对照。固定同一随机种子要放在每次创建模型之前；只在程序开头设一次种子，并不保证接连创建的模型初始化一样。

`backward` 算梯度，`step` 才根据梯度改参数。错误说法：“先 backward，再 zero_grad，最后 step 也能更新。”——**错**：刚算出的梯度被清掉了。旧梯度可以在前向之前或反向之前清除，但不能夹在本轮反向和更新之间。

本课继续用 `SmallClassifier`：两个输入特征 → `Linear(2, 4)` → `ReLU` → `Linear(4, 2)`。输出 logits（类别原始分数）；每行最高分所在位置是预测类别，不是概率。即使类别没变，原始分数和交叉熵损失也可能改变，因此检查重载时要比较**全部 logits**，不能只比较类别。

### 2. train / val / test：名字相似，职责不同

| 数据划分 | 中文含义 | 允许做什么 | 本课边界 |
|---|---|---|---|
| train（训练集） | 用于学习参数的数据 | 前向、算损失、反向和更新 | 梯度只来自它 |
| val / validation（验证集） | 用于比较方案的数据 | 评价每轮表现、挑最佳权重 | 不反向、不更新，不从它重新拟合预处理 |
| test（测试集） | 留到决策完成后的数据 | 对最终选定方案报告表现 | 不用它挑轮次、学习率或模型 |

验证集参与了选择，不能再把它的最佳成绩叫成独立测试成绩。测试集一旦被反复用来挑方案，就失去了“最后才看”的角色。这里用极小的独立内存样本讲清流程；它们的成绩不代表真实任务泛化能力。

### 3. 模型模式和梯度开关是两个问题

| 工具 | 管什么 | 不替你做什么 |
|---|---|---|
| `model.train` | 设置训练模式，并递归影响子层 | 不开启训练循环、不反向、不自动更新 |
| `model.eval` | 设置评估模式，影响有模式差异的层 | **不关闭梯度**，不冻结参数 |
| `torch.no_grad` | 在上下文中关闭常规运算的梯度记录 | **不自动调用 eval**，不清理已有 `.grad` |
| `torch.inference_mode` | 更严格的推理上下文，额外减少视图追踪等开销 | 不自动调用 eval；其中新建的推理张量不适合再接入需要保存它反向的计算 |

训练常用“train ＋ 正常梯度”；验证常用“eval ＋ no_grad”；最终推理常用“eval ＋ inference_mode”。离开上下文后，梯度设置恢复。`no_grad` 是较通用的“不为这段运算建图”；`inference_mode` 适合明确不再用于反向的推理，不需要为了初学把所有 no_grad 都替换掉。

本课的 Linear / ReLU 本身在两种模式下运算规则相同，因此不能拿它们“输出没变”推断 eval 无用。第二个独立探针用 Dropout（随机失活层）观察差异：训练时随机把部分输入置零，并缩放留下的值；评估时保持输入。第一份完整训练示例仍保持第十课网络结构。

### 4. 一个小批次不能和一个大批次拥有相同票重

batch（批次）损失默认是**本批样本的均值**。本课没有类别权重，也没有忽略标签；交叉熵的批次平均可以按实际样本数汇总：

> 整体验证 loss（损失）＝各批“平均损失 × 实际样本数”的总和 ÷ 全部样本数。
>
> 整体验证 accuracy（准确率）＝各批正确样本数的总和 ÷ 全部样本数。

最后一批可能不满，不能总乘预设批量大小；也不能直接平均各批 loss 或各批 accuracy。各批样本数一样时，两种平均一定一致；批次大小不等时也可能偶然一致，但不能据此认定这种汇总总是正确。验证加载器保留末尾样本，不设置丢弃最后一批。类别加权或忽略标签会改变交叉熵的分母，不能直接照搬本课公式。

### 5. 保存的是参数状态，重建的是模型结构

`state_dict`（状态字典）把参数名称映射到张量，还会包含模型注册的持久缓冲区，例如某些层的运行统计量。它不包含模型类定义、训练模式、优化器进度或完整训练程序。这里立即把最佳轮次的状态写盘；不要把 `best_state = model.state_dict()` 当成已经冻结的独立快照，因为里面的张量通常仍共享模型底层数据，继续训练可能让它跟着变。

流程是：先按**预先约定的验证指标**判优 → 立即保存状态 → 用相同结构创建新模型 → 安全读入权重 → 严格装载 → 显式设为 eval → 在相同输入上比较全部 logits。演示约定验证损失越小越好，相等保留较早轮次；这不等于任何任务都必须按 loss 挑选，指标规则要在看测试集之前确定。

`weights_only=True` 限制加载对象的范围，适合本课只含张量的状态字典；`map_location='cpu'` 把读入张量放到 CPU（中央处理器）。它只控制加载位置，不会自动搬动一个已经在其他设备上的模型。本课全程 CPU；不要加载来历不明的权重，也不要为了消除报错随手改成不受限的加载。只存权重适合恢复推理；若要精确续训，还涉及优化器及随机状态，留到后续课程。

## 【核心内置函数拆解】

以下语法中的 `model`、`tensor`、`optimizer` 等都是已创建对象。常用参数形式足够本课使用，未列出的高级参数不作为练习要求。

### ① `Module.train` — 进入训练模式

- **作用**：设置自身和子模块的训练模式标记。
- **完整语法**：`model.train(mode=True)`。
- **关键参数**：`mode=True` 训练；`False` 评估。
- **返回值**：模型自身，参数数值不会因此改变。
- **常见坑**：误以为它会执行训练或打开此前被上下文关闭的梯度。
- **适用场景**：每轮训练开始，尤其上一轮验证调用了 eval 之后。

### ② `Module.eval` — 进入评估模式

- **作用**：等价于把模型的训练模式设为 False，递归影响子层。
- **完整语法**：`model.eval()`。
- **关键参数**：无额外参数。
- **返回值**：模型自身。
- **常见坑**：误以为关闭梯度；加载权重后忘记重新设置；以 Linear 输出不变推断它无效。
- **适用场景**：验证或预测前，固定有模式差异的层的行为。

### ③ `torch.no_grad` — 这段常规运算不记录梯度

- **作用**：临时禁止常规张量运算建立反向计算图，减少验证开销。
- **完整语法**：`with torch.no_grad():`，缩进内部写要执行的运算。
- **关键参数**：上下文形式无参数；本课不涉及工厂函数的特殊例外。
- **返回值**：上下文管理器；内部运算仍返回其正常张量，只是不记录梯度。
- **常见坑**：以为它自动 eval 或清已有梯度；把训练损失放进去后还希望 backward。
- **适用场景**：验证、无需反向的临时输出快照。

### ④ `torch.inference_mode` — 明确只推理的上下文

- **作用**：关闭梯度记录并进一步减少推理中不需要的跟踪开销。
- **完整语法**：`with torch.inference_mode(mode=True):`。
- **关键参数**：`mode=True` 启用推理模式。
- **返回值**：上下文管理器；其中新建张量受推理模式限制。
- **常见坑**：没有先 eval；随后把推理张量接回需要反向的流程，可能报错。
- **适用场景**：选好模型后的最终预测与重载检查。

### ⑤ `nn.CrossEntropyLoss` — 明确批次损失的含义

- **作用**：比较类别原始分数与整数标签。
- **完整语法**：`nn.CrossEntropyLoss(weight=None, ignore_index=-100, reduction='mean', label_smoothing=0.0)`；创建后使用 `loss_fn(logits, targets)`。
- **关键参数**：本课 `weight=None`，所有标签有效，`reduction='mean'`；输入为样本×类别，标签为一维 int64 类别编号。
- **返回值**：默认返回单元素损失张量。
- **常见坑**：把批平均当全体平均；先转概率；使用类别权重后仍按本课分母解释。
- **适用场景**：分类训练和验证；本课按样本汇总未加权交叉熵。

### ⑥ `Tensor.item` — 标量张量变成数字

- **作用**：提取只有一个元素的张量中的数值。
- **完整语法**：`tensor.item()`。
- **关键参数**：张量必须只有一个元素。
- **返回值**：Python 数字。
- **常见坑**：多元素张量不能直接提取；返回的数字不能用于反向传播。
- **适用场景**：汇总验证损失、正确个数和打印记录。

### ⑦ `Tensor.argmax` — 从分数到类别编号

- **作用**：返回最大值所在位置。
- **完整语法**：`tensor.argmax(dim=None, keepdim=False)`。
- **关键参数**：本课类别轴是 `dim=1`；默认不保留被归约的轴。
- **返回值**：int64 索引张量。
- **常见坑**：省略 dim 变成全体只取一个索引；以为得到的是概率。
- **适用场景**：把每行 logits 转为预测类别。

### ⑧ `Tensor.sum` — 汇总正确个数

- **作用**：把张量元素相加；布尔值中 True 计为一、False 计为零。
- **完整语法**：`tensor.sum(dim=None, keepdim=False, dtype=None)`。
- **关键参数**：不指定 dim 时汇总所有元素；本课比较张量是一维，随后 item 提取总数。
- **返回值**：求和后的张量。
- **常见坑**：直接打印布尔列表，没有计算正确总数；把批准确率直接相加当全体准确率。
- **适用场景**：逐样本预测与标签比较后的计数。

### ⑨ `Module.state_dict` — 取得模型参数状态

- **作用**：收集已注册参数与持久缓冲区。
- **完整语法**：`model.state_dict(destination=None, prefix='', keep_vars=False)`。
- **关键参数**：本课保持默认；`keep_vars=False` 返回脱离求导历史的张量状态。
- **返回值**：键为名称、值为张量的字典式对象。
- **常见坑**：以为包含结构定义或 eval 标记；只赋值给另一个变量就以为完成独立快照。
- **适用场景**：把当前轮次权重交给保存函数。

### ⑩ `torch.save` — 立即保存状态

- **作用**：将对象序列化到文件。
- **完整语法**：`torch.save(obj, f)`（本课使用形式）。
- **关键参数**：`obj` 是状态字典；`f` 是文件路径或二进制文件对象；相对路径以工作目录为基准。
- **返回值**：None；文件是实际保存结果。
- **常见坑**：覆盖同名文件不提示；上级目录必须已存在；保存整个自定义模型会增加结构和加载依赖。
- **适用场景**：指标改善时保存最佳权重。

### ⑪ `torch.load` — 按权重读取并指定设备

- **作用**：从文件恢复已序列化的对象。
- **完整语法**：`torch.load(f, map_location=None, *, weights_only=True)`（本课使用形式）。
- **关键参数**：显式设置 `weights_only=True`；本课 `map_location='cpu'`；`*` 表示后面的参数按名称传入。
- **返回值**：本课是状态字典；它还没有自动装进模型。
- **常见坑**：以为返回值就是可调用模型；把设备映射当作模型迁移；不核实文件来源。
- **适用场景**：加载本课可信的张量权重文件。

### ⑫ `Module.load_state_dict` — 把状态装进模型

- **作用**：核对参数名称和形状，并把张量内容复制进模型。
- **完整语法**：`model.load_state_dict(state_dict, strict=True, assign=False)`。
- **关键参数**：`strict=True` 要求键名匹配，形状也须兼容；本课 `assign=False`，使用默认复制行为。
- **返回值**：包含 `missing_keys`（缺失键）和 `unexpected_keys`（多余键）的结果对象。
- **常见坑**：结构不一致；误以为它返回模型或自动 eval；用 strict=False 掩盖装错结构。
- **适用场景**：新建同结构模型后恢复已保存参数。

### ⑬ `torch.allclose` — 检查全部输出是否接近

- **作用**：对两张量的所有元素进行容差比较，返回整体结论。
- **完整语法**：`torch.allclose(input, other, rtol=1e-5, atol=1e-8, equal_nan=False)`。
- **关键参数**：允许误差由绝对容差 atol 和相对容差 rtol 共同决定；本课同机 CPU 重载比较两者都设零。
- **返回值**：Python 布尔值。
- **常见坑**：只比较预测类别；跨设备或跨版本仍要求完全相等而不先检查数值误差来源。
- **适用场景**：在相同模式与输入下核验重载后的全部 logits。

### ⑭ `Tensor.tolist` — 方便显示张量

- **作用**：把张量转为 Python 数字或嵌套列表。
- **完整语法**：`tensor.tolist()`。
- **关键参数**：无额外参数。
- **返回值**：与张量嵌套层级对应的 Python 列表，标量则是数字。
- **常见坑**：转成列表后不能再用它反向；大张量全部打印会淹没关键信息。
- **适用场景**：显示少量预测类别。

### ⑮ `nn.Dropout` — 用最小探针观察模式差异

- **作用**：训练时随机置零部分元素，并按保留比例缩放；评估时保持输入。
- **完整语法**：`nn.Dropout(p=0.5, inplace=False)`，创建后使用 `dropout(inputs)`。
- **关键参数**：`p` 是置零概率；本课不原地修改。
- **返回值**：Dropout 层；调用后返回同形状张量。
- **常见坑**：以为 no_grad 会停止随机失活；每次前向前重设种子会掩盖随机行为。
- **适用场景**：本课用于辨认模式与梯度开关，暂不加进训练网络。

### ⑯ `torch.ones` — 创建探针输入

- **作用**：创建所有元素为一的张量。
- **完整语法**：`torch.ones(*size, dtype=None, device=None, requires_grad=False)`。
- **关键参数**：`size` 给各维长度；本探针显式指定浮点类型，不请求输入梯度。
- **返回值**：给定形状的 Tensor（张量）。
- **常见坑**：输入不需要梯度，不代表后续含可训练参数的运算也不需要梯度。
- **适用场景**：让 Dropout 是否置零更容易观察。

## 【完整代码示例 + 逐行注释】

### 演示一：每轮验证，保存最佳权重，再用新模型恢复

把本课目录设为工作目录，用 `BaiQing3.10AI` 运行 `demo.py`。脚本与下方第一份代码块完全相同；会生成或覆盖当前目录的 `demo_best.pt`，不依赖预先存在的权重。为了聚焦验证，训练数据在每轮作为一个批次，验证则逐批累计。

```python
import torch  # 导入PyTorch张量和权重读写工具。
from torch import nn  # 导入模型基类、网络层和损失函数。
from torch.utils.data import TensorDataset, DataLoader  # 导入第九课的数据集与批次加载器。
torch.manual_seed(7)  # 固定随机种子，便于在同一环境复现初始化。
x_train = torch.tensor([[0.0, 0.2], [0.2, 0.0], [1.0, 1.2], [1.2, 1.0]], dtype=torch.float32)  # 训练特征，仅它参与反向更新。
y_train = torch.tensor([0, 0, 1, 1], dtype=torch.int64)  # 训练标签使用整数类别编号。
x_val = torch.tensor([[0.1, 0.1], [0.3, 0.0], [0.0, 0.3], [1.1, 1.1], [1.3, 1.0]], dtype=torch.float32)  # 验证特征不与训练样本重复。
y_val = torch.tensor([0, 0, 0, 1, 1], dtype=torch.int64)  # 验证标签只用于评价与选择权重。
x_test = torch.tensor([[0.05, 0.15], [1.15, 1.05]], dtype=torch.float32)  # 测试特征留到选好权重后再使用。
y_test = torch.tensor([0, 1], dtype=torch.int64)  # 测试标签不参与挑选最佳轮次。
val_dataset = TensorDataset(x_val, y_val)  # 沿用第九课：把对应位置的特征和标签配成样本。
val_loader = DataLoader(val_dataset, batch_size=2, shuffle=False, drop_last=False)  # 保留末尾不满批次，避免漏算样本。
class SmallClassifier(nn.Module):  # 沿用第十课：定义可注册参数的模型。
    def __init__(self):  # 创建模型时初始化网络层。
        super().__init__()  # 沿用第十课：初始化模型基类。
        self.hidden = nn.Linear(2, 4)  # 沿用第十课：输入特征映射到中间特征。
        self.activation = nn.ReLU()  # 沿用第十课：添加非线性激活。
        self.output = nn.Linear(4, 2)  # 沿用第十课：输出每个类别的原始分数。
    def forward(self, inputs):  # 指定前向计算的连接顺序。
        hidden = self.hidden(inputs)  # 先完成第一个线性变换。
        activated = self.activation(hidden)  # 再把负值变成零。
        return self.output(activated)  # 返回logits（类别原始分数），无需提前转成概率。
model = SmallClassifier()  # 创建待训练模型。
loss_fn = nn.CrossEntropyLoss(reduction='mean')  # 函数⑤：得到每个批次的平均损失。
optimizer = torch.optim.SGD(model.parameters(), lr=0.5)  # 沿用第十课：让优化器管理模型参数。
best_loss = float('inf')  # 辅助⑰：以正无穷初始化，使首轮的有限验证损失能入选。
best_epoch = 0  # 记录被选中权重对应的轮次。
checkpoint_path = 'demo_best.pt'  # 权重文件写在当前工作目录；重复运行会覆盖同名演示文件。
for epoch in range(8):  # 反复训练，每轮结束后验证同一份验证集。
    model.train()  # 函数①：每轮训练前明确恢复训练模式。
    train_logits = model(x_train)  # 训练前向需要建立计算图。
    train_loss = loss_fn(train_logits, y_train)  # 函数⑤：计算本轮更新前的训练损失。
    optimizer.zero_grad()  # 沿用第十课：反向前清除旧梯度。
    train_loss.backward()  # 沿用第十课：根据训练损失计算梯度。
    optimizer.step()  # 沿用第十课：利用梯度更新参数。
    model.eval()  # 函数②：开始验证前切到评估模式。
    loss_total = 0.0  # 累计所有验证样本的损失总量。
    correct_total = 0  # 累计预测正确的样本数。
    sample_total = 0  # 累计真正遍历的样本数。
    with torch.no_grad():  # 函数③：验证不建立用于反向传播的计算图。
        for features, targets in val_loader:  # 逐批验证，包括最后的不满批次。
            logits = model(features)  # 使用本轮更新后的同一个模型计算分数。
            loss = loss_fn(logits, targets)  # 函数⑤：当前批次的平均损失。
            batch_count = len(targets)  # 辅助⑰：取得本批实际样本数，不能一直使用预设batch_size。
            loss_total += loss.item() * batch_count  # 函数⑥：先还原本批损失总量，再纳入累计。
            predictions = logits.argmax(dim=1)  # 函数⑦：沿类别轴为每条样本选择最高分的编号。
            correct_total += (predictions == targets).sum().item()  # 函数⑧⑥：把逐样本真假比较汇成正确个数。
            sample_total += batch_count  # 累加本批样本数作为最终分母。
    val_loss = loss_total / sample_total  # 所有样本损失总量除以全部样本数，得到样本加权平均。
    val_accuracy = correct_total / sample_total  # 所有正确样本数除以全部样本数，得到accuracy（准确率）。
    if val_loss < best_loss:  # 本演示约定只按验证损失越小越好选权重；相等保留较早轮次。
        best_loss = val_loss  # 保存当前最佳的指标数值。
        best_epoch = epoch + 1  # 同步保存对应轮次。
        torch.save(model.state_dict(), checkpoint_path)  # 函数⑨⑩：立即写盘，固定本轮权重快照。
        with torch.no_grad():  # 函数③：留下一份最佳轮次的验证输出，之后核对重载是否恢复原行为。
            best_logits = model(x_val)  # 当前模型处于eval，得到独立输出张量，后续参数更新不会改写它。
    print('epoch', epoch + 1, 'train_loss', round(train_loss.item(), 6), 'val_loss', round(val_loss, 6), 'val_accuracy', round(val_accuracy, 6))  # 函数⑥及辅助⑰：打印实算指标。
reloaded = SmallClassifier()  # 创建新模型；它此刻尚未拥有最佳权重。
state = torch.load(checkpoint_path, weights_only=True, map_location='cpu')  # 函数⑪：按权重方式读入，并映射到CPU。
load_result = reloaded.load_state_dict(state, strict=True)  # 函数⑫：严格核对键名及形状，并复制到新模型。
reloaded.eval()  # 函数②：加载权重不会自动切换模式，推理前仍需明确设置。
with torch.inference_mode():  # 函数④：最终推理无需反向，并使用更严格的推理上下文。
    restored_logits = reloaded(x_val)  # 新模型输出整份验证集的原始分数。
    test_logits = reloaded(x_test)  # 最佳权重选定后，才进行最终测试。
    test_loss = loss_fn(test_logits, y_test).item()  # 函数⑤⑥：该测试集只用一个批次，直接取得平均损失。
    test_predictions = test_logits.argmax(dim=1)  # 函数⑦：从测试分数得到类别编号。
    test_accuracy = (test_predictions == y_test).sum().item() / len(y_test)  # 函数⑧⑥：计算最终测试准确率。
print('best_epoch', best_epoch, 'best_val_loss', round(best_loss, 6))  # 辅助⑰：展示按验证损失选中的轮次。
print('strict_load', load_result)  # 展示是否存在缺失键或多余键。
print('reloaded_logits_match', torch.allclose(restored_logits, best_logits, rtol=0.0, atol=0.0))  # 函数⑬：比较全部logits，不能只比较类别。
print('test_predictions', test_predictions.tolist())  # 函数⑭：将张量转成Python列表便于阅读。
print('test_loss', round(test_loss, 6), 'test_accuracy', round(test_accuracy, 6))  # 辅助⑰：测试结果是报告，不能倒过来挑权重。
```

### 演示二：模式开关不等于梯度开关

独立运行 `demo_modes.py`，不需要先跑演示一。探针让 Linear 的参数需要梯度，再分别观察评估模式和关闭梯度；Dropout 单独观察随机失活。

```python
import torch  # 导入张量和上下文工具。
from torch import nn  # 导入线性层与随机失活层。
torch.manual_seed(23)  # 辅助⑰：固定本次探针的随机序列，不在每次前向前重置。
inputs = torch.ones(16, 2, dtype=torch.float32)  # 函数⑯：用全一输入让失活结果容易观察。
linear = nn.Linear(2, 2)  # 第十课已用：创建带可训练参数的线性层。
linear.eval()  # 函数②：先设置评估模式，它不关闭梯度。
eval_output = linear(inputs)  # 参数需要梯度，所以此时仍会建立计算图。
print('eval_linear_requires_grad', eval_output.requires_grad)  # 辅助⑰：读取输出属性验证eval的边界。
linear.train()  # 函数①：恢复训练模式。
with torch.no_grad():  # 函数③：只关闭这段运算的梯度记录。
    no_grad_output = linear(inputs)  # 参数仍存在，但此次运算不记录反向图。
    print('no_grad_keeps_training', linear.training)  # 辅助⑰：观察上下文并未把模型切为eval。
    print('no_grad_output_requires_grad', no_grad_output.requires_grad)  # 辅助⑰：输出不需要反向梯度。
dropout = nn.Dropout(p=0.5)  # 函数⑮：创建训练时会随机失活的独立层。
dropout.train()  # 函数①：显式开启随机失活行为。
with torch.no_grad():  # 函数③：关闭梯度不会停止训练模式下的随机失活。
    train_output = dropout(inputs)  # 函数⑮：本次得到随机失活后的输出。
dropout.eval()  # 函数②：评估时失活层保持输入。
with torch.inference_mode():  # 函数④：独立观察明确用于推理的上下文。
    eval_dropout_output = dropout(inputs)  # 函数⑮：此时不再置零和缩放输入。
print('train_dropout_preserves_input', torch.allclose(train_output, inputs, rtol=0.0, atol=0.0))  # 函数⑬：整体比较，不只看首个元素。
print('eval_dropout_preserves_input', torch.allclose(eval_dropout_output, inputs, rtol=0.0, atol=0.0))  # 函数⑬：评估模式保持全部元素。
print('inference_output_requires_grad', eval_dropout_output.requires_grad)  # 辅助⑰：推理结果不需要反向梯度。
```

### 我的疑问

#### 补充答疑：整个Dataset与next取出的第一批

**进一步拆解iter与next**：本人反馈不理解连续两次 `next(iter(val_loader))` 的问题。此前教师未充分解释迭代器就要求预测，教学步幅过大；这不是已经验证的学生错误。

把迭代器理解为“记录取到哪一批的进度对象”。`iter(val_loader)` 创建一个新的进度，从头开始；`next` 沿着给定的进度取下一批，并推进该进度。一个表达式中又写一次iter，就是又创建一个新进度。本题shuffle=False，重复新建后取第一批，会重复拿到相同的第一批。

以下是独立观察片段，依赖前面已创建的 `val_loader`；不是整题解法，也不要求学生把手动next写成最终验证循环。所有调用均由教师在同一fixture和指定环境实跑核对：

```python
first_features, first_targets = next(iter(val_loader))  # 新建进度后只取第一批。
again_features, again_targets = next(iter(val_loader))  # 再新建进度，仍取第一批。
progress = iter(val_loader)  # 把一次创建的进度保存下来。
first_features, first_targets = next(progress)  # 使用这个进度，取第一批并推进。
second_features, second_targets = next(progress)  # 沿用同一进度，接着取第二批。
```

教师诊断输出，依次检查上述四次取批的形状：

```text

new_iterator_again torch.Size([4, 2]) torch.Size([4])
same_iterator_first torch.Size([4, 2]) torch.Size([4])
same_iterator_second torch.Size([1, 2]) torch.Size([1])
```

验证所有批次时优先用已经学过的for遍历，不需要学生手动维护next或处理取完后的StopIteration。本次先澄清进度是否复用，不增加候选选择、损失汇总等新内容；理解仍待后续确认。

**完整可运行类比**（不是未作答的多候选练习解法）：两个计费方案各自重新走同一组订单。在这里，方案名相当于候选名，单价相当于要切换的权重，订单批次相当于验证批次。

```python
rates = {'日常方案': 2, '加急方案': 3}  # 每个方案提供自己的单价。
batches = [4, 1]  # 各方案都处理同一组订单：列表里的每项是一批订单的数量。
for name in rates:  # 外层：每次完整评估一个方案。
    rate = rates[name]  # 取当前方案单价，不沿用上一轮单价。
    total_cost = 0  # 每个方案从零累计，不能放在外层循环之前。
    for batch_size in batches:  # 内层：当前方案重新遍历同一组批次。
        batch_cost = rate * batch_size  # 计算本批费用。
        total_cost += batch_cost  # 累加到当前方案的总费用。
    print(name, '总费用', total_cost)  # 内层结束后，只汇总当前方案。
```
