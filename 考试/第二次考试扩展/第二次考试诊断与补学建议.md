## 先看结论

这次最该补的不是“再背几个 OpenCV 函数”，而是从题目到可验证产物的组装顺序：**先确定数据是什么，再确定每一步做什么，最后接上调用、保存和读回核验**。你有函数拆分、目录定位、参数文档和输出形状等已有思路；目前遇到陌生任务时，还容易从示例直接搬函数体，却没有先写清函数要收什么、交回什么、谁来调用它。

## 已有基础与边界

原始注释段显示，你知道可以用 `__file__` 和 `os.path` 找脚本目录、会尝试把图像步骤封装成函数，并且注意到旋转后尺寸要保持；2.2 能列出希望组合的变换；2.3 原始注释段保留目录遍历、循环外读图和序号命名，但与题面原循环重合，独立迁移证据有限；“单图处理函数 + 并行调度”属于活跃参考修改版，不能归功于原始独立作答。第四课讲义已经讲了随机数生成器、旋转矩阵与仿射变换、范围截断、图像读写和全像素比较；第三课讲过 BGR/HWC、路径与基本变换。但第四课的练习尚未提交，讲义暴露不能等同于你已独立写会。

当前课程材料没有查到以下 API 的正式拆解与独立练习记录：`random.random`/`random.uniform` 标准库随机接口、`np.random.normal` 高斯抽样、`np.fromfile`/`cv2.imdecode` 与 `cv2.imencode`/`tofile` 中文路径编解码、`ThreadPoolExecutor` 并行实践。因此，原卷把它们放进考试却没有提供对应教学台阶，**不能仅凭这次表现判断为“学过但没掌握”**。第四课教的 `rng.uniform` 与标准库 `random.uniform` 是不同接口；高斯模糊也不等于高斯噪声。本次补卷不考这些未授课接口，将其保留为后续补学目标。

## 写代码时的建议

每次先写 5 行“草图”，再补语法：

1. **输入**：我拿到的是路径、目录名、PIL 图片，还是 NumPy 像素数组？颜色顺序、形状和类型是什么？
2. **输出**：这个函数应该交回什么？是新数组、保存路径、成功状态，还是错误信息？
3. **单步**：一张图最短需要哪些步骤？每步的结果要接到哪个变量？
4. **调用者**：谁负责传入参数、调用函数、接收返回值？有没有真正运行到它？
5. **验收**：跑前先确认输入存在；跑后核对退出状态、输出文件、可解码性、形状/类型，必要时比较像素或文件哈希。

推荐顺序：先只处理一张图；加上 `img is None` 检查；成功保存并读回；再把单图逻辑放进循环；最后才考虑线程池/进程池。遇到报错先按最后一行找“哪一步拿到的实际类型不对”，不要马上重写整段代码。随机增强需分清“抽随机参数”和“应用图像操作”；噪声要在浮点数组上叠加，再截断到 `[0,255]` 并转回 `uint8`。

## 补学次序

1. 路径/数组/函数输入输出和调用：本次补卷第一部分，先重建完整执行闭环。
2. 单图到串行批处理：把已会的函数组合起来，并用不同变换保证产物不是同一张图换文件名。
3. 随机参数与增强结果核验：迁移第四课内容；随机生成器和不同随机源的差别先对照学习，不预设已经掌握。
4. 中文路径编解码、并发处理：出示针对性函数卡与小示例后再做开放拓展，不混在主线闭卷题里。
