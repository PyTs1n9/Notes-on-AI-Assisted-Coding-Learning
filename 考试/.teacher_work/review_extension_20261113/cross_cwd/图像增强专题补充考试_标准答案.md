# 图像增强专题补充考试：标准答案

> 本答案对应《图像增强专题补充考试》。这是教师参考答案，不代表学生独立完成。代码已使用 `BaiQing3.10AI` 在本目录实际运行验证。

## 一、第一部分：读题拆流程

### 1. 类型与调用链

“输入文件路径”是字符串，例如 `D:\\...\\input.png`，它只表示文件在哪里，不能直接当作图像像素使用。

“解码后的图像数组”是 OpenCV 读取文件后得到的 NumPy 数组，题目中的 BGR 彩色图像通常是三维数组，形状为 `(高, 宽, 通道数)`，例如 `(300, 400, 3)`。

单图处理顺序如下：

1. 得到输入文件路径，类型是路径字符串。
2. 读取并解码图片，得到 BGR 图像数组。
3. 检查读取结果是否为 `None`。
4. 把图像数组交给翻转或旋转函数，得到新的图像数组。
5. 把结果数组编码并保存到输出路径，得到保存成功状态。
6. 再次读取输出文件，得到读回数组。
7. 检查文件是否存在、是否能解码、形状和类型是否正确，并核对变换结果。

### 2. 最早的错误层

错误发生在“输入准备/数据类型契约”这一层。路径字符串只是文件地址，不包含已经解码的像素数据；旋转函数需要从图像数组中读取 `shape`，因此把路径字符串直接传入后，后续的高、宽、旋转中心和仿射变换都无法正确进行。

最先应该补上的步骤是：先用读取函数把路径指向的图片解码成图像数组，并检查读取是否成功，再把这个数组传给旋转函数。

## 二、第二部分：实现单图变换函数

### 3. 固定尺寸旋转

```python
import cv2


def rotate_image(img, angle):
    h, w = img.shape[:2]
    center = (w / 2, h / 2)
    matrix = cv2.getRotationMatrix2D(center, angle, 1.0)
    rotated = cv2.warpAffine(
        img,
        matrix,
        (w, h),
        flags=cv2.INTER_LINEAR,
        borderMode=cv2.BORDER_CONSTANT,
        borderValue=(0, 0, 0),
    )
    return rotated
```

参数解释：

- `center` 是旋转中心。图像数组先取高 `h`、宽 `w`，因此中心写成 `(w / 2, h / 2)`；坐标顺序是 `(x, y)`，也就是先宽方向、后高方向。
- `angle` 是旋转角度，正负方向遵循 OpenCV 的角度约定。
- `1.0` 是缩放倍率，表示只旋转，不放大或缩小。
- `cv2.warpAffine` 的输出画布参数是 `(宽, 高)`，所以必须传 `(w, h)`，不能传数组常见的 `(h, w)`。
- `INTER_LINEAR` 是插值方式；`BORDER_CONSTANT` 表示超出原图的区域用固定值补齐；黑色 BGR 值是 `(0, 0, 0)`。

### 4. 随机参数的组合增强

随机生成器只负责产生随机决策和角度，`rotate_image` 只负责按照传入角度旋转。组合函数负责把两者接起来。

```python
import cv2


def augment_image(img, rng):
    result = img.copy()
    flipped = False

    if rng.random() < 0.5:
        result = cv2.flip(result, 1)
        flipped = True

    angle = float(rng.uniform(-15, 15))
    result = rotate_image(result, angle)
    return result, flipped, angle
```

关键调用链是：

```text
rng.random()       -> 决定是否水平翻转
rng.uniform(...)   -> 抽取本次旋转角度
rotate_image(...)  -> 使用这个角度真正执行旋转
```

不能在 `augment_image` 内部重新创建生成器，否则调用方传入的种子和状态无法统一管理。也不能把 `rng` 当作图像；它只产生参数。

## 三、第三部分：实现串行批处理

下面的完整脚本同时包含 `process_one`、`batch_augment` 和入口调用。由于本目录路径含中文，Windows 下某些 OpenCV 版本直接使用中文绝对路径调用 `cv2.imread`/`cv2.imwrite` 可能失败，因此参考答案使用 `np.fromfile + cv2.imdecode` 读取，使用 `cv2.imencode + tofile` 保存。它们仍然是 OpenCV 的图像读写流程，只是绕过了 Windows 路径解码问题。

### 完整参考代码

```python
import os
import cv2
import numpy as np

BASE_DIR = os.path.dirname(os.path.abspath(__file__))
INPUT_PATH = os.path.join(BASE_DIR, "input/input.png")
OUTPUT_DIR = os.path.join(BASE_DIR, "output_supplement")
SUPPORTED_EXTENSIONS = (".png", ".jpg", ".jpeg", ".bmp")


def read_image(path):
	data = np.fromfile(path, dtype=np.uint8)
	if data.size == 0:
		return None
	return cv2.imdecode(data, cv2.IMREAD_COLOR)


def write_image(path, image):
	extension = os.path.splitext(path)[1].lower()
	success, encoded = cv2.imencode(extension, image)
	if not success:
		return False
	encoded.tofile(path)
	return os.path.isfile(path)


def rotate_image(img, angle):
	h, w = img.shape[:2]
	center = (w / 2, h / 2)
	matrix = cv2.getRotationMatrix2D(center, angle, 1.0)
	rotated = cv2.warpAffine(
		img,
		matrix,
		(w, h),
		flags=cv2.INTER_LINEAR,
		borderMode=cv2.BORDER_CONSTANT,
		borderValue=(0, 0, 0),
	)
	return rotated


def augment_image(img, rng):
	result = img.copy()
	flipped = False
	if rng.random() < 0.5:
		result = cv2.flip(result, 1)
		flipped = True
	angle = float(rng.uniform(-15, 15))
	result = rotate_image(result, angle)
	return result, flipped, angle


def process_one(input_dir, filename, output_dir):
	extension = os.path.splitext(filename)[1].lower()
	if extension not in SUPPORTED_EXTENSIONS:
		return False, filename + "：不支持的扩展名"

	input_path = os.path.join(input_dir, filename)
	img = read_image(input_path)
	if img is None:
		return False, filename + "：读取失败"

	base_name = os.path.splitext(filename)[0]
	flip_path = os.path.join(output_dir, base_name + "_flip.png")
	rotate_path = os.path.join(output_dir, base_name + "_rotate.png")
	if os.path.exists(flip_path) or os.path.exists(rotate_path):
		return False, filename + "：输出文件已存在，拒绝覆盖"

	flip_result = cv2.flip(img, 1)
	rotate_result = rotate_image(img, 12)
	if not write_image(flip_path, flip_result):
		return False, filename + "：翻转结果保存失败"
	if not write_image(rotate_path, rotate_result):
		return False, filename + "：旋转结果保存失败"

	return True, filename + "：已生成 flip 和 rotate"


def batch_augment(input_dir, output_dir):
	os.makedirs(output_dir, exist_ok=True)
	success_count = 0
	failure_count = 0
	messages = []
	for filename in sorted(os.listdir(input_dir)):
		path = os.path.join(input_dir, filename)
		extension = os.path.splitext(filename)[1].lower()
		if not os.path.isfile(path) or extension not in SUPPORTED_EXTENSIONS:
			continue
		success, message = process_one(input_dir, filename, output_dir)
		messages.append(message)
		if success:
			success_count += 1
		else:
			failure_count += 1
	return success_count, failure_count, messages


def main():
	img = read_image(INPUT_PATH)
	print("input_exists", os.path.isfile(INPUT_PATH))
	print("input_shape", img.shape)
	print("input_dtype", img.dtype)

	fixed = rotate_image(img, 12)
	print("fixed_shape", fixed.shape)
	print("fixed_dtype", fixed.dtype)
	print("fixed_changed", not np.array_equal(img, fixed))

	rng_a = np.random.default_rng(42)
	rng_b = np.random.default_rng(42)
	augmented_a, flipped_a, angle_a = augment_image(img, rng_a)
	augmented_b, flipped_b, angle_b = augment_image(img, rng_b)
	print("augment_reproducible", np.array_equal(augmented_a, augmented_b))
	print("augment_same_decision", flipped_a == flipped_b)
	print("augment_same_angle", angle_a == angle_b)
	print("augment_shape", augmented_a.shape)
	print("augment_dtype", augmented_a.dtype)
	print("input_unchanged", np.array_equal(img, read_image(INPUT_PATH)))

	success, failure, messages = batch_augment(os.path.dirname(INPUT_PATH), OUTPUT_DIR)
	print("batch_first", success, failure)
	for message in messages:
		print("message", message)

	output_names = sorted(os.listdir(OUTPUT_DIR))
	print("output_names", output_names)
	print("output_count", len(output_names))
	for name in output_names:
		output = read_image(os.path.join(OUTPUT_DIR, name))
		print("artifact", name, output.shape, output.dtype, output is not None)
	flip = read_image(os.path.join(OUTPUT_DIR, "input_flip.png"))
	rotate = read_image(os.path.join(OUTPUT_DIR, "input_rotate.png"))
	print("flip_matches", np.array_equal(flip, cv2.flip(img, 1)))
	print("rotate_changed", not np.array_equal(rotate, img))

	success, failure, messages = batch_augment(os.path.dirname(INPUT_PATH), OUTPUT_DIR)
	print("batch_second", success, failure)
	for message in messages:
		print("message", message)
	print("output_count_after_second", len(os.listdir(OUTPUT_DIR)))


if __name__ == "__main__":
	main()
```

## 补充答疑：第六、七步为什么要做

第六步和第七步都在核验**保存后的文件**，但做的事不同：

- **第六步：把文件重新读回来。** 保存函数报告成功，只代表写入调用没有报告失败；它不能单独证明写出来的文件内容完整、格式可解码、位置正确。再次读取会真的打开磁盘上的输出文件并解码，得到一个新的数组 `saved_img`。这一步是“取证据”，不是对原内存数组再检查一次。
- **第七步：检查读回来的证据。** 比较 `saved_img` 和保存前的数组 `result_img`：是否读回成功、shape 与 dtype 是否符合约定、像素是否符合目标变换。读回数组形状正确，不等于像素一定正确；像素可比较相等，也不一定能说明文件放在要求的位置或文件名正确。所以存在性、解码、结构、内容是不同层次的检查。

可以把它想成写完文件后重新打开文件复查：第六步是“打开”，第七步是“核对”。如果程序只是处理图片、不保存产物，通常不需要做保存后的回读；如果题目要求可交付文件，回读是强一些的保存验证。不是每个小练习都必须做昂贵的整图比较，但正式验收、批处理交付或处理流程容易出错时很有价值。

另外，上一版第 5 步写“编码并保存”、第 6 步重读是正确方向；你复述中的“然后解码，保存到输出路径”顺序说反了。准确说法是：**把像素数组编码成 PNG/JPEG 文件内容，再写到路径；随后重新读取并解码这个文件，才得到读回数组。** 编码是“数组→文件表示”，解码是“文件表示→数组”。

以当前补充考试标准答案的行为为例，程序对两张输出分别执行：

1. 从目标路径再次读取，确认不是 `None`。
2. 检查读回后的 `(300, 400, 3)` 和 `uint8`。
3. 对翻转图逐像素比较，确认它与预期水平镜像完全一致。
4. 对旋转图检查内容确实发生变化。随机组合函数则另用同种子比较两次的数组；这个检查测试随机流程可复现，不能代替保存文件的读回检查。

这里也要区分：磁盘上的 PNG 本身不会标记“这是 BGR 数组”；OpenCV 读取 PNG 时会按它的颜色通道习惯还原成 BGR 数组，所以输入和读回数组可以逐像素比较。`shape` 是数组形状，`dtype` 是数组元素类型；它们并不是 PNG 文件本身的“数据类型”。

### 可运行的最小示范

以下示范用已经有的水平翻转文件执行一次读回核验，单独运行即可：

```python
import os
import cv2
import numpy as np

base_dir = os.path.dirname(os.path.abspath(__file__))
input_path = os.path.join(base_dir, "input/input.png")
output_path = os.path.join(base_dir, "output_supplement", "input_flip.png")

original_bytes = np.fromfile(input_path, dtype=np.uint8)
saved_bytes = np.fromfile(output_path, dtype=np.uint8)
original = cv2.imdecode(original_bytes, cv2.IMREAD_COLOR)
saved_img = cv2.imdecode(saved_bytes, cv2.IMREAD_COLOR)

print("读回成功", saved_img is not None)
print("形状一致", saved_img.shape == original.shape)
print("类型一致", saved_img.dtype == original.dtype)
expected = cv2.flip(original, 1)
print("像素符合水平翻转", np.array_equal(saved_img, expected))
```

## 五、验收结论

- 路径和图像数组已区分，完整调用链正确。
- 固定旋转使用输入数组的高宽计算中心，输出画布保持 `(宽, 高)`，输出形状保持 `(300, 400, 3)`。
- 组合增强由生成器产生翻转决策和角度，再调用 `rotate_image`；同种子、同调用顺序可以复现。
- 原图没有被原地修改，输出类型为 `uint8`。
- 批处理首次成功处理 1 张输入图，生成 2 张 PNG；读回核验通过。
- 第二次运行返回 `0` 成功、`1` 失败，并明确拒绝覆盖，已有产物数量保持为 2。
