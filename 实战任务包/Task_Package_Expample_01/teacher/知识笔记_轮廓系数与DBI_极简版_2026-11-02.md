## 一、轮廓系数 `silhouette_score` — 每个点投票，越大越好

想象你站在自己队伍里，问自己两个问题：

- **a** = 我离自己队友平均多近？（越小越好 → 抱得紧）
- **b** = 我离最近的那支「别队」平均多远？（越大越好 → 离得远）
- **s = (b − a) / max(a, b)**，范围 −1 ~ 1

**读法**（这是唯一要记的）：

| s 值 | 意思 |
| --- | --- |
| 接近 1 | 抱得紧又离得远，位置很安全 |
| 接近 0 | 骑在两队边界上，说不清属于谁 |
| 小于 0 | 我离别队反而更近，**站错队了** |

最后把所有点的 s 平均一下 = 轮廓系数。
→ **每个点一票，所以天数多的簇（大簇）话语权大**。

> 你这份数据：K=4 → 0.265，其中 29 天 s 是负的 → 边界本来就糊，别指望高分。

## 二、DBI `davies_bouldin_score` — 每一簇投票，越小越好

每一簇算两个数，再两两配对：

- **s_i** = 我这堆点到我自己质心的平均距离（我这堆有多散）
- 配对比值 **(s_i + s_j) / 质心间距**：自己散 + 对手散 + 离得近 → 比值大 → 糟

每簇挑出自己**最糟**的那个对手，最后取平均 = DBI。
→ **每一簇一票，跟簇大簇小无关**（正好和轮廓系数相反）。

> 你这份数据：K 越大每堆越小越紧 → 比值一路降 → DBI 把最优推向 K=8。

## 三、三个指标吵架怎么办（唯一要背的流程）

1. **肘部法则定档**：看 inertia 降幅从陡变缓的拐点（你数据 = K=4）
2. **两个指标验档**：K=4 的轮廓系数、DBI 是不是明显差档？不是 → 通过 ✅
3. **写结论时如实写分歧**：「轮廓最优在 K=2、DBI 最优在 K=8、肘部拐点在 K=4，取 K=4 是折中」

**核心：没有及格线，只有横向比大小。** 每个「最优 K」的说法都要能指回自己表里的数字。

---

## 四、三个共同的坑

1. **必须先 `StandardScaler`** — 否则 cnt 几千的量纲会主导距离
2. **K=1 算不了** — 没有「别的簇」可比，直接报错
3. **方向别记反** — 轮廓越大越好，DBI 越小越好

---

## 五、口诀（4 句）

1. 轮廓看单点：a 小 b 大 s 才大，负数＝站错队
2. DBI 看配对：最糟对手的比值再平均，越小越好
3. 逐点 vs 逐簇 —— 这就是它俩会吵架的原因
4. 肘部定档、两指标验档、分歧如实写
