# 知识笔记：轮廓系数与 DBI——两个指标怎么读、怎么定最优 K

- **整理时间**：2026-11-02（源自 A3 批改答疑）
- **覆盖问题**：`silhouette_score` / `davies_bouldin_score` 的内部计算过程、判读方向、与肘部法则的分工、三个指标意见不一致时怎么定 K
- **一句话红线**：**三个指标都没有"及格线"，只有横向比较；肘部法则负责定档，轮廓系数和 DBI 负责验档，任何"最优 K"的结论都要能指回自己表里的数字。**

## 〇、先认清三个指标各自的角色

| 指标 | 方向 | 打分单位 | 它在问什么 | 天然偏向 | 有无绝对锚点 |
| --- | --- | --- | --- | --- | --- |
| Inertia（肘部） | 越小越好 | 每个点到本簇质心的平方距离加总 | 簇内有多紧？ | **K 越大越低**（它只会降） | 无 → 只看"降幅何时变缓"，不看绝对值 |
| 轮廓系数 silhouette | 越大越好，范围 -1~1 | **每个样本一票**（逐点平均） | 这一天离本簇近、离**最近的对手**远吗？ | **偏小 K** | 有参考锚点：≈0 就是骑在边界上、负数＝站错队；但 0.5 只是经验参考，**不是及格线** |
| DBI | 越小越好 | **每个簇一票**（逐簇平均） | 每个簇跟它**最糟的对手**比，散得开吗？ | 本数据上偏大 K（第四节实测） | 无 → 只能横向比大小 |

统一理解：三者算的是同一件事的比值——**簇内紧 vs 簇间远**。差别只有两处：① 谁被平均（逐点 vs 逐簇）；② 拿谁当参照（最近的对手 vs 最糟的配对）。**这就是它俩会吵架的根源。**

## 一、轮廓系数：先算一天，再平均

### 1. 单个样本怎么算

- `a(i)` = 第 i 个样本到**同簇其他样本**的平均距离（簇内紧密度，越小越好）
- `b(i)` = 第 i 个样本到**最近的那个其他簇**全部样本的平均距离（分离度，越大越好）
- `s(i) = (b(i) - a(i)) / max(a(i), b(i))`，落在 [-1, 1]

判读直觉：`s≈1` 抱得紧又离得远；`s≈0` 骑墙（正好在两簇边界上）；`s<0` 离别的簇反而更近——**站错队了**。

### 2. 函数卡

| 字段 | 内容 |
| --- | --- |
| 作用 | 把每个样本的 `s(i)` 平均成一个数，评价"这组簇分得开不开" |
| 完整语法 | `silhouette_score(X, labels)`；单点版 `silhouette_samples(X, labels)` |
| 关键参数 | `X`：特征矩阵，**必须先 StandardScaler**；`labels`：每个样本的簇编号（`km.labels_`），至少要有 2 个不同取值 |
| 返回值 | `silhouette_score` 返回一个 float（-1~1，越大越好）；`silhouette_samples` 返回和样本等长的数组（731 个 s(i)） |
| 常见坑 | ① 忘了缩放——`cnt` 是几千的量纲，距离会被它一个特征主导；② `labels` 误传 `y` 或传成 KMeans 对象；③ K=1 直接报错（没有"别的簇"可比）；④ **逐点平均 → 大簇话语权大** |
| 适用场景 | K=2~8 横向比大小；配合 `silhouette_samples` 定位哪些样本在边界上 |

两者关系一句话：**`silhouette_score` 就是 `silhouette_samples(...).mean()`**——先有一堆单点分，再取平均。

### 3. 实跑读数（你的数据，K=4，完整输出见第五节）

- 单点验算：样本 #0（2011-01-01，簇3）`a=1.9909`、`b=2.1381` → 手算 `s=0.0688`，与 `silhouette_samples` 给的值**完全一致**
- 全局：`0.264953` 就是 731 个 `s(i)` 的平均
- **29 天 `s(i)<0`**（离别的簇比离本簇还近）、118 天 `s(i)<0.1` → 这份数据的簇边界本来就糊
- 最好的一天 #574 `s=0.5488`；最差的一天 #300 `s=-0.0815`
- 各簇内部均值：簇2 `0.3234` 最干净，簇3 `0.1776`、簇0 `0.1948` 最糊 → **簇的质量不均匀**

### 4. 判读口径（参考值，不是及格线）

| s 值 | 通常的说法 | 你这份数据 |
| --- | --- | --- |
| 0.5 以上 | 分得很开 | 只有最好的一天 0.5488 |
| 0.25~0.5 | 有结构但重叠 | 全局 0.264953（K=2 也只有 0.301661） |
| 0.25 以下 | 结构很弱 | K=5~8 全在 0.23 上下 |
| 小于 0 | 有样本站错队 | K=4 有 29 天 |

关键：**横向比，不看绝对值**。你这份数据整体就是"糊"的（真实业务数据，天与天的特征高度重叠），所以只能比较哪个 K 相对更好，不能宣称"分得很开"。

### 5. 四个坑

1. 不缩放就算（先 `StandardScaler`）；
2. K=1 算不了（`ValueError: Number of labels ... is 1`）；
3. **逐点平均 → 大簇说了算**：K=2 最大簇占 57.2%，K=8 才 17.2%（第五节表）——所以它天然偏爱"分成两大堆"；
4. `b(i)` 取的是**最近的对手**：K 越大，身边的对手越多，`b` 越容易被拉小 → 分数随 K 下降。

## 二、DBI：先算每簇，再配对比值

### 1. 四步流水线（一步不跳）

1. `s_i` = 簇 i 内所有点到**本簇质心**的平均距离（簇内散布，越小越好）
2. `d_ij` = 簇 i 与簇 j **质心之间**的距离（越大越好）
3. `M_ij = (s_i + s_j) / d_ij`：两簇各自散得开、彼此又近 → 比值大 → 糟（对角线自己跟自己比，不算）
4. 每个簇取它**最糟的那个对手**的 M，再对所有簇取平均 → **DBI**

### 2. 函数卡

| 字段 | 内容 |
| --- | --- |
| 作用 | 用"簇内散布 ÷ 质心间距"的配对比值，给整组簇打一个"重不重叠"的分 |
| 完整语法 | `davies_bouldin_score(X, labels)` |
| 关键参数 | `X`：特征矩阵，**必须先 StandardScaler**；`labels`：簇编号，至少 2 簇 |
| 返回值 | float，≥0，**越小越好**（方向和轮廓系数相反，最容易记混） |
| 常见坑 | ① 没缩放；② 把方向记成越大越好；③ K=1 报错；④ **逐簇平均 → 每簇一票**，131 天的簇和 316 天的簇话语权一样（和轮廓系数正相反） |
| 适用场景 | 与轮廓系数交叉验证；两者方向不一致时，用肘部＋业务可解释来定夺 |

### 3. 实跑读数（K=4，完整矩阵见第五节）

- `s_i`：簇0 `1.4387`、簇1 `1.1831`、簇2 `1.2752`、簇3 `1.3924`
- 质心最近的一对是 簇1↔簇3（`d=1.9389`），而两簇又都不算紧 → `M=1.3283` 是全场最糟配对
- 每个簇的最坏对手：簇0→簇1、簇1→簇3、簇2→簇3、簇3→簇1
- **DBI = 4 个最坏值的平均 = 1.254871，与 `davies_bouldin_score` 完全一致**

### 4. 判读

- 没有绝对锚点，**只能横向比**（常见经验说 >1 重叠明显，那也只是参考）；
- 你这份数据：K=8 最低 `1.172940` → 它把最优推向了**最大的 K**；K=2 最差 `1.359205`。

## 三、三个指标打架时怎么定 K（决策流程）

1. **肘部定档**：看 inertia 降幅序列，找"从陡变缓"的拐点。你的数据是 `[396.3, 202.2, 175.6, 116.7, 101.4, 70.2]`（依次对应 K=3…8），K=5 起降幅掉到 175→116→101→70，**拐点落在 K=4**；
2. **轮廓系数验档**：K=4 的 `0.264953` 在七档里排第 3，且**高于 K=5~8 的全部取值** → 不是差档 ✅；
3. **DBI 验档**：K=4 的 `1.254871` 在七档里排第 4，**优于紧邻的 K=3 与 K=5** → 不在差区 ✅；
4. **写结论**：三者不一致时**如实写分歧**——"轮廓系数最优在 K=2、DBI 最优在 K=8、肘部拐点在 K=4；方向不一致说明数据没有天然分界，取 K=4 是兼顾簇内紧度与簇数可解释性的折中"（K=8 每簇 731/8≈91 天、最大簇仅 17.2%，业务上太碎）。

分歧是常态，不是错误：三者只是"同一问题的三种问法"。判断行别背数字，用代码取：

```python
print('silhouette 最优 K =', int(sc.loc[sc['sil'].idxmax(), 'K']))   # idxmax 找最大值所在行
print('DBI 最优 K =', int(sc.loc[sc['dbi'].idxmin(), 'K']))         # idxmin 找最小值所在行
```

## 四、为什么你这份数据上两个指标方向相反（实测机制）

| K | 簇内散布均值 s̄ | 质心两两距离均值 d̄ | 示意比值 s̄/d̄ | DBI | 最大簇占比 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 2 | 1.5565（最散） | 2.2903（最近） | 0.6796 | 1.359205（最差） | 57.2% |
| 4 | 1.3223 | 2.3815 | 0.5553 | 1.254871 | 43.2% |
| 8 | 1.0742（最紧） | 2.5487（最远） | 0.4215 | 1.172940（最好） | 17.2% |

读法：K 变大 → 每坨更小更紧（`s̄` 从 1.5565 降到 1.0742），质心间距反而略增（`d̄` 2.2903→2.5487）→ 比值一路下降 → **DBI 把最优推向 K=8**。而轮廓系数是逐点打分、`b` 取最近对手、大簇话语权大，所以它把最优推向 K=2。**两者都"对"，只是问的角度不同。**

> `s̄/d̄` 只是示意（把两个方向摊开看）；真 DBI 是每簇取最坏配对再平均，见第二节。

## 五、实跑验证（你的 conda 环境，2026-11-02）

在 `submission/code` 目录下原样运行（相对路径与你的 `kmeans.py` 一致）：

```python
# -*- coding: utf-8 -*-
"""知识笔记配图脚本：把轮廓系数、DBI 的内部计算过程在学生自己的数据上逐项打印出来
运行目录：submission/code（相对路径与选手脚本一致）"""
import pandas as pd
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, silhouette_samples, davies_bouldin_score

FEATS = ['temp', 'hum', 'windspeed', 'cnt']
df = pd.read_csv('../data_outputs/day_clean.csv', encoding='utf-8-sig')
X = df[FEATS].to_numpy(float)
Xs = StandardScaler().fit_transform(X)
print('输入 day_clean.csv', df.shape, ' 特征', FEATS, ' 已标准化（距离才可比）')

K = 4
km = KMeans(n_clusters=K, random_state=42, n_init=10).fit(Xs)
lab = km.labels_
C = km.cluster_centers_
sizes = {c: int((lab == c).sum()) for c in range(K)}

# ========== 一、轮廓系数：单个样本的 s(i) 怎么来的 ==========
s_samples = silhouette_samples(Xs, lab)
i = 0                                             # 2011-01-01
mask_same = (lab == lab[i])
d_same = np.linalg.norm(Xs[mask_same] - Xs[i], axis=1)   # i 到同簇每一天的距离（含自己 0）
a_i = d_same.sum() / (d_same.size - 1)                   # 去掉自己，剩下同簇其他天的平均距离
dists_i = np.linalg.norm(Xs - Xs[i], axis=1)      # i 到所有点的距离
b_best, b_c = None, None
for c in range(K):
    if c == lab[i]:
        continue
    m = dists_i[lab == c].mean()                  # i 到簇 c 全部点的平均距离
    if b_best is None or m < b_best:
        b_best, b_c = m, c
s_hand = (b_best - a_i) / max(a_i, b_best)
print('\n=== 一、轮廓系数 silhouette_score：单个样本怎么算（K=4）===')
print(f'样本 #{i} 日期 {df["dteday"][i]}  所在簇 = {lab[i]}（本簇共 {sizes[lab[i]]} 天）')
print(f'  a(i) 同簇其他 {sizes[lab[i]]-1} 天到它的平均距离 = {a_i:.4f}   ← 越小越“抱得紧”')
print(f'  b(i) 最近的其他簇是 簇{b_c}（{sizes[b_c]} 天），i 到该簇全部点的平均距离 = {b_best:.4f}   ← 越大越“离得远”')
print(f'  s(i) = (b-a)/max(a,b) = ({b_best:.4f}-{a_i:.4f})/{max(a_i,b_best):.4f} = {s_hand:.4f}')
print(f'  sklearn silhouette_samples 给的 s(i) = {s_samples[i]:.4f}   手算一致 = {abs(s_hand - s_samples[i]) < 1e-12}')
print(f'  K=4 整体轮廓系数 = {s_samples.mean():.6f}（731 个 s(i) 的平均）  silhouette_score = {silhouette_score(Xs, lab):.6f}')
print(f'  s(i) < 0 的天数 = {int((s_samples < 0).sum())}（这些天离别的簇比离本簇还近）；s(i) < 0.1 的天数 = {int((s_samples < 0.1).sum())}')
print(f'  最好的一天 #{int(np.argmax(s_samples))} s={s_samples.max():.4f}；最差的一天 #{int(np.argmin(s_samples))} s={s_samples.min():.4f}（簇{lab[int(np.argmin(s_samples))]}）')
per_c = {c: round(float(s_samples[lab == c].mean()), 4) for c in range(K)}
print('  各簇内部 s(i) 均值 =', per_c)

# ========== 二、DBI：从质心到一个数 ==========
s_i = np.array([np.linalg.norm(Xs[lab == c] - C[c], axis=1).mean() for c in range(K)])
d_ij = np.linalg.norm(C[:, None, :] - C[None, :, :], axis=-1)
with np.errstate(divide='ignore', invalid='ignore'):
    M = (s_i[:, None] + s_i[None, :]) / d_ij
np.fill_diagonal(M, np.nan)
print('\n=== 二、DBI davies_bouldin_score：一个数怎么来的（K=4）===')
print('各簇内散布 s_i（本簇点到本簇质心的平均距离）:')
print(pd.Series(s_i.round(4), index=[f'簇{c}({sizes[c]}天)' for c in range(K)]).to_string())
print('质心两两距离 d_ij:')
print(pd.DataFrame(d_ij.round(4), index=[f'簇{c}' for c in range(K)], columns=[f'簇{c}' for c in range(K)]).to_string())
print('配对比值 M_ij = (s_i + s_j) / d_ij（越大越糟）:')
print(pd.DataFrame(M.round(4), index=[f'簇{c}' for c in range(K)], columns=[f'簇{c}' for c in range(K)]).to_string())
worst = np.nanmax(M, axis=0)                        # 每个簇找自己最糟的对手
part = {f'簇{c}': f'簇{int(np.nanargmax(M[:, c]))} (M={np.nanmax(M[:, c]):.4f})' for c in range(K)}
print('每个簇的最坏对手 =', part)
dbi_hand = float(np.nanmean(worst))
print(f'DBI = 4 个最坏值的平均 = {dbi_hand:.6f}   davies_bouldin_score = {davies_bouldin_score(Xs, lab):.6f}'
      f'   一致 = {abs(dbi_hand - davies_bouldin_score(Xs, lab)) < 1e-12}')

# ========== 三、三个指标一起读 ==========
rows, drops = [], []
prev = None
for k in range(2, 9):
    m_ = KMeans(n_clusters=k, random_state=42, n_init=10).fit(Xs)
    rows.append({'K': k, 'inertia': m_.inertia_,
                 'sil': silhouette_score(Xs, m_.labels_),
                 'dbi': davies_bouldin_score(Xs, m_.labels_),
                 '最大簇占比%': round(100 * np.bincount(m_.labels_).max() / len(Xs), 1)})
    if prev is not None:
        drops.append(round(prev - m_.inertia_, 1))
    prev = m_.inertia_
sc = pd.DataFrame(rows)
print('\n=== 三、三个指标横向读（K=2~8）===')
print(sc.round(6).to_string(index=False))
print('inertia 逐K降幅 =', drops)
print('轮廓系数最大在 K =', int(sc.loc[sc['sil'].idxmax(), 'K']), '（方向：越大越好）')
print('DBI 最小在 K     =', int(sc.loc[sc['dbi'].idxmin(), 'K']), '（方向：越小越好）')
print('肘部候选档（降幅从陡到缓的拐点）= K=4')
print('三档对照: K=2 sil=%s dbi=%s | K=4 sil=%s dbi=%s | K=8 sil=%s dbi=%s' % (
    round(float(sc.loc[sc['K'] == 2, 'sil'].iloc[0]), 6), round(float(sc.loc[sc['K'] == 2, 'dbi'].iloc[0]), 6),
    round(float(sc.loc[sc['K'] == 4, 'sil'].iloc[0]), 6), round(float(sc.loc[sc['K'] == 4, 'dbi'].iloc[0]), 6),
    round(float(sc.loc[sc['K'] == 8, 'sil'].iloc[0]), 6), round(float(sc.loc[sc['K'] == 8, 'dbi'].iloc[0]), 6)))

# ========== 四、DBI 为什么在这份数据上一路走低 ==========
print('\n=== 四、DBI 为什么随 K 一路走低（分子分母各自动了什么）===')
hist = []
for k in [2, 4, 8]:
    m_ = KMeans(n_clusters=k, random_state=42, n_init=10).fit(Xs)
    lab_, C_ = m_.labels_, m_.cluster_centers_
    s_ = np.array([np.linalg.norm(Xs[lab_ == c] - C_[c], axis=1).mean() for c in range(k)])
    dd = np.linalg.norm(C_[:, None, :] - C_[None, :, :], axis=-1)
    off = dd[~np.eye(k, dtype=bool)]
    dbi_ = davies_bouldin_score(Xs, lab_)
    hist.append((k, s_.mean(), off.mean(), dbi_))
    print(f'K={k}: 簇内散布均值 s̄={s_.mean():.4f}（越小=簇越紧）  质心两两距离均值 d̄={off.mean():.4f}'
          f'  示意比值 s̄/d̄={s_.mean()/off.mean():.4f}  DBI={dbi_:.6f}')
print(f'读法：K 从 {hist[0][0]} 到 {hist[-1][0]}，簇内更紧（s̄ {hist[0][1]:.4f}→{hist[-1][1]:.4f}），'
      f'质心间距反而略增（d̄ {hist[0][2]:.4f}→{hist[-1][2]:.4f}）→ 比值一路下降 → DBI 把最优推向 K=8')
print('注意：s̄/d̄ 只是示意；真 DBI 是每簇取“最坏配对”的比值再对所有簇平均（见第二节）')
```

## 六、口诀卡

1. **轮廓系数看单点**：a 小 b 大 s 才大；负数＝站错队；整体就是所有 s 的平均。
2. **DBI 看配对**：`(s_i+s_j)/d_ij`，每簇取最坏对手再平均，越小越好。
3. **两个都要先标准化，都算不了 K=1。**
4. **逐点 vs 逐簇**：轮廓系数大簇说了算，DBI 每簇一票——这就是它俩会吵架的原因。
5. **肘部定档、两指标验档；分歧要如实写，任何"最优 K"都要能指回自己表里的数字。**
