**标准答案：K=4，理由必须写成下面这样（全部数字来自上表）**：

- 肘部法则：inertia 逐 K 降幅 = [396.3, 202.2, 175.6, 116.7, 101.4, 70.2]（依次对应 K=3…8），降幅到 K=4 还有 202.2，**K=5 起跌破 200 并一路收窄**（175.6→116.7→101.4→70.2）→ 拐点落在 K=4；
- 轮廓系数：全局最大在 K=2（0.301661），之后一路走低到 K=6（0.225555），K=7、K=8 只微升到 0.229 上下；**K=4（0.264953）高于 K=5~8 的全部取值**（0.237236／0.225555／0.229247／0.229450），也就是 K 再往上分，簇只会更碎；
- DBI：最小在 K=8（1.172940）；**K=4（1.254871）优于紧邻的 K=3（1.297733）与 K=5（1.289737）**，在七档里排第 4（中上游），不在差区；
- 三指标不一致时的通行做法：先用肘部定档（K=4 拐点），再用轮廓系数与 DBI 检验该档不在差区 → 取 **K=4**。

## 四、A3-4 标准代码（评审组已实跑）与产物实测

```python
# -*- coding: utf-8 -*-
"""A3 参考实现（A3-3 收尾 + A3-4 两个产物 + A3-5 命名依据）
运行目录：submission/code（相对路径与选手 kmeans.py 一致）
"""
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, davies_bouldin_score
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

FEATS = ['temp', 'hum', 'windspeed', 'cnt']   # A3-1 要求的四个特征

# ---------- 输入 ----------
df = pd.read_csv('../data_outputs/day_clean.csv', encoding='utf-8-sig')
X = df[FEATS]
Xs = StandardScaler().fit_transform(X)        # A3-2：全数据标准化（聚类无标签，不切分）

# ---------- 选 K 的真实读数（理由只能引这里的数） ----------
rows = []
for k in range(2, 9):
    km = KMeans(n_clusters=k, random_state=42, n_init=10).fit(Xs)
    rows.append({'K': k, 'inertia': km.inertia_,
                 'sil': silhouette_score(Xs, km.labels_),
                 'dbi': davies_bouldin_score(Xs, km.labels_)})
sc = pd.DataFrame(rows)
print('--- K=2~8 三指标 ---')
print(sc.round(6).to_string(index=False))
print('轮廓系数最大在 K =', int(sc.loc[sc['sil'].idxmax(), 'K']),
      ' DBI 最小在 K =', int(sc.loc[sc['dbi'].idxmin(), 'K']),
      ' inertia 逐K降幅 =', [round(float(sc['inertia'][i-1] - sc['inertia'][i]), 1) for i in range(1, len(sc))])

K_FINAL = 4                                 # 定 K：肘部 K=4 拐点；K=4 的 sil 高于 K=5~8 全部，DBI 优于 K=3 与 K=5
km = KMeans(n_clusters=K_FINAL, random_state=42, n_init=10).fit(Xs)   # 用最终 K 重训一次
df['cluster'] = km.labels_                  # 每天的聚类编号

# ---------- A3-4：两个产物 ----------
daily_clusters = df[['dteday', 'cluster']]                       # 含日期 + 聚类编号
daily_clusters.to_csv('../data_outputs/daily_clusters.csv', index=False, encoding='utf-8-sig')

cluster_summary = df.groupby('cluster')[FEATS].mean().round(6)   # 每簇各特征均值
cluster_summary['count'] = df.groupby('cluster').size()          # 每簇天数
cluster_summary = cluster_summary.reset_index()                  # 簇编号变成独立一列
cluster_summary.to_csv('../data_outputs/cluster_summary.csv', index=False, encoding='utf-8-sig')
print('\n--- daily_clusters.csv ---')
print(daily_clusters.head().to_string(index=False), ' 行数 =', len(daily_clusters))
print('\n--- cluster_summary.csv ---')
print(cluster_summary.to_string(index=False))

# ---------- A3-3：散点用最终 K 的标签，标题写明只是二维投影 ----------
plt.scatter(df['temp'], df['cnt'], c=df['cluster'], cmap='tab20', alpha=0.5)
plt.xlabel('temp')
plt.ylabel('cnt')
plt.title(f'K={K_FINAL} clusters: temp vs cnt (2D projection only)')
plt.savefig('../figures/cluster_scatter.png', dpi=150)
plt.close()

# ---------- A3-5：命名依据（先算基线，再逐簇对比） ----------
base = df[FEATS].mean()
print('\n--- 命名依据：每簇均值 vs 全表均值 ---')
tab = cluster_summary.set_index('cluster')[FEATS].T              # 转置成“特征×簇”更好读
print(tab.round(4).to_string())
print('全表均值:', base.round(4).to_dict())
print('每簇天数:', df['cluster'].value_counts().sort_index().to_dict())
for c in sorted(df['cluster'].unique()):
    sub = df[df['cluster'] == c][FEATS].mean()
    pct = {f: round((sub[f] / base[f] - 1) * 100, 1) for f in FEATS}
    print(f'簇{c}: 相对全表 %={pct}  天数={int((df["cluster"]==c).sum())} '
          f'({round(100*(df["cluster"]==c).mean(),1)}%)')

```
