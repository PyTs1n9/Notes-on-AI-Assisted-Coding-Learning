# 第十五课：数据类型与特征准备

## 【本节核心知识点】

数据"干净"了还不够——模型只吃数字：把 `dteday` 转成真正的日期并拆出年/月/星期几（`pd.to_datetime` + `.dt`），用 `astype` 改类型、`pd.get_dummies` 把类别列拆成 0/1，最后切出**特征表 X** 和**标签 y**。

## 【核心概念讲解】

### 0. 前情提要

第十三课查缺失、第十四课查重复和异常，"数据靠不靠谱"这一关过了。但审计完的数据还是**一整张表**：日期是文本、`season` 是代号、`cnt` 混在所有列里——这都不是模型能直接吃的形态。

这节课做的是**特征准备**（feature preparation（特征准备））：把一整张表改造成 `X`（特征表，模型看的）+ `y`（标签，模型要猜的）。第二课的 `train_test_split(X, y, ...)` 吃的就是这两个东西，所以这节课是把旧知识和后面的任务包 A2（回归预测）接上的桥。对标任务包 A1 的收尾和 A2 的第一步。

### 1. 文本日期的麻烦 → `pd.to_datetime`

`dteday` 读进来是 `'2011-01-01'` 这样的**文本**，文本没法算"这是星期几"，也没法比较先后（字符串比较只认字典序）。`pd.to_datetime` 把它转成**日期类型**（`datetime64`），转完就能取年、取月、取星期几。

从日期里额外算出来的列叫**衍生特征**（derived feature（衍生特征））：`年`、`月`、`星期几`。这些不是原始表里有的，是从已有信息里"拆"出来的——模型很吃这一套，比如"周末租车量普遍更高"这件事，模型靠 `星期几` 才学得到。

### 2. `.dt` 访问器 + 一个先钉住的坑

`.dt` 是日期列专用的工具箱：`.dt.year` 取年、`.dt.month` 取月、`.dt.weekday` 取星期几。

**前提**：列必须**先转成 datetime**，否则直接报 `AttributeError: Can only use .dt accessor with datetimelike values`。

**坑（先钉住）**：数据里原本就有一列 `weekday`，它的约定是 **0 = 周日、…、6 = 周六**（UCI 这份数据自带的口径）；而 `.dt.weekday` 的约定是 **0 = 周一、…、6 = 周日**。同一天，两列的数差 1，`day.csv` 里 **731 行全都不一样**——这不是你算错了，是两套约定不同。所以新拆的列我起名叫 `星期几`，和原列区分开。

### 3. `astype`：类型转换

`astype` 干一件事：把一列换成另一种类型。本课用它的理由是**语义**：`season`（季节）的 1~4 只是代号，写成数字会让模型以为"4 比 1 大"（冬天比春天大三倍？没这回事）。先 `astype('str')` 转成文本，是在告诉 pandas："这是**标签**，不是**数量**。"

### 4. 类别特征 → 独热编码

**类别特征**（categorical feature（类别特征））= 只有少数几个取值、取值之间没有大小含义的列：`season`（1~4）、`weathersit`（1~3）。

办法是**独热编码**（one-hot encoding（独热编码））：把一列拆成多列，每列只装"是不是这一档"的 `True/False`。`season` 一列 → `season_1` ~ `season_4` 四列，行 `(1, 0, 0, 0)` 表示"春"。这样既给了模型数字，又不制造假的大小关系。

### 5. X 和 y

- **y（标签，label（标签））**：要预测的那一列——本课是 `cnt`（当天租车量）；
- **X（特征，feature（特征））**：用来预测的那些列——去掉 `cnt`，也去掉日期列 `dteday`（文本/日期类型模型不直接吃，年月星期几已经拆出来了）。

规矩只有一条：**X 和 y 的行数必须一样多、顺序必须一一对应**（第 100 行的特征配第 100 行的标签），否则模型学到的是张冠李戴。

## 【核心内置函数拆解】

### ① `pd.to_datetime(序列)` — 文本转日期

- **作用**：把文本形式的日期转成真正的日期类型。
- **完整语法**：`pd.to_datetime(df['dteday'])`。
- **关键参数**：`format`（格式不标准时用来指定，如 `format='%Y/%m/%d'`，本课不展开）；`errors='coerce'`（转不动的值变成 `NaT` 而不报错，本课不展开）。
- **返回值**：同长度的 Series，dtype 为 `datetime64`——**2.x 显示 `datetime64[ns]`、3.x 常显示 `datetime64[us]`，单位是版本差异，都算对**。
- **常见坑**：**不接变量等于白转**——必须写 `df['dteday'] = pd.to_datetime(df['dteday'])` 赋回原列；`NaT` 是"日期界的 NaN"。
- **适用场景**：日期列读进来是文本时；要按星期/月份拆特征之前。

### ② `df['dteday'].dt.year` — `.dt` 访问器取日期成分

- **作用**：从日期列里取出年、月、星期几等成分，用来造新列。
- **完整语法**：`df['dteday'].dt.year` / `.dt.month` / `.dt.weekday`。
- **关键参数**：没有参数，是一组属性；`.dt.dayofweek` 和 `.dt.weekday` 等价。
- **返回值**：数值 Series（本课两套环境里都显示 `int32`）。
- **常见坑**：**列必须先转 datetime**，否则报 `AttributeError: Can only use .dt accessor with datetimelike values`；`.dt.weekday` 是 **周一 = 0 … 周日 = 6**，和数据里原有的 `weekday` 列（0 = 周日）差一套约定。
- **适用场景**：造周末/月份特征；按时间拆数据。

### ③ `df['列'].astype(类型)` — 改类型

- **作用**：把一列换成指定的类型。
- **完整语法**：`df['season'].astype('str')`，类型也常写 `'int64'`、`'float64'`。
- **关键参数**：目标类型（字符串）。
- **返回值**：**新的 Series**——原列不变，要赋回：`df['season'] = df['season'].astype('str')`。
- **常见坑**：转不动会报 `ValueError`（比如 `'abc'` 转不了 float）；数字文本 `'12'` 转 int/float 没问题；目标 `'str'` 的显示在 2.x 是 `object`、3.x 是 `str`，版本差异不算错。
- **适用场景**：代号列转文本（表明"这是标签"）；把读成文本的数字列救回数值列。

### ④ `pd.get_dummies(df, columns=['列名'])` — 类别列拆成 0/1

- **作用**：把类别列拆成多列 0/1（独热编码）。
- **完整语法**：`pd.get_dummies(df, columns=['season', 'weathersit'])`。
- **关键参数**：`columns` = 要拆的列名列表；**只有点名的列会被拆**，其他列原样保留。不传 `columns` 时它自己找文本列——先点名更可控。
- **返回值**：**新的 DataFrame**：被点名的列消失，多出 `season_1` … `season_4` 这样的 0/1 列（值是 `True`/`False`）。
- **常见坑**：**不接变量等于白拆**（和 `drop_duplicates` 同一个坑）；拆完旧列名从 `list(df.columns)` 里消失，核对列名就能确认拆没拆。
- **适用场景**：模型要吃数字、又不能让类别代号被当成大小关系时。

### ⑤ `df.drop(columns=['列名'])` — 删列，切出 X

- **作用**：删掉指定的列，把特征和标签分开。
- **完整语法**：`df.drop(columns=['cnt', 'dteday'])`（一次可删多列）。
- **关键参数**：`columns` = 要删的列名列表；老写法 `df.drop(['cnt'], axis=1)` 等价。
- **返回值**：**新的 DataFrame**，原表不动。
- **常见坑**：**不接变量等于白删**；列名拼错报 `KeyError`。
- **适用场景**：切 X（删掉标签列和不该进模型的列）；删 ID 列、纯文本列。

## 【完整代码示例 + 逐行注释】

```python
# ============ 第十五课演示：给租赁数据"转日期 → 拆特征 → 出 X/y" ============
import pandas as pd                                    # 读表、转日期、独热、出特征表都靠它

df = pd.read_csv('day.csv', encoding='utf-8-sig')      # 真实 UCI 数据：2011-2012 两年共 731 天

# ---------- 第 1 步：dteday 现在是文本，先转成真正的日期 ----------
print(df['dteday'].dtype)                              # 先看类型：文本列（3.x 显示 str、2.x 显示 object）
df['dteday'] = pd.to_datetime(df['dteday'])            # 函数①：文本 '2011-01-01' → 日期类型 datetime64
print(df['dteday'].dtype)                              # 再看类型：datetime64[ns] 或 [us]（版本差异，都算对）

# ---------- 第 2 步：从日期里拆出年、月、星期几（衍生特征） ----------
df['年'] = df['dteday'].dt.year                        # 函数②：.dt.year 取年份
df['月'] = df['dteday'].dt.month                       # 函数②：.dt.month 取月份 1~12
df['星期几'] = df['dteday'].dt.weekday                 # 函数②：.dt.weekday 周一=0 … 周日=6
print(df['星期几'].head(3))                            # 2011-01-01 是星期六 → 5；01-02 周日 → 6；01-03 周一 → 0

# ---------- 第 3 步：类别列转成文本，再拆成一排 0/1 列 ----------
df['season'] = df['season'].astype('str')              # 函数③：int → 文本，告诉 pandas"这是标签，不是数量"
df = pd.get_dummies(df, columns=['season'])            # 函数④：season 一列拆成 season_1 … season_4（0/1 列）
print(df.shape)                                        # 列变多了：season 一列被拆成了 4 列
print(list(df.columns))                                # 新列名都在里面，旧的 season 已经消失

# ---------- 第 4 步：出特征表 X 和标签 y ----------
y = df['cnt']                                          # 标签 y：要预测的"当天租车量"
X = df.drop(columns=['cnt', 'dteday'])                 # 函数⑤：去掉标签列和日期列，剩下的都是特征
print(X.shape)                                         # 特征表尺寸
print(y.shape)                                          # 标签尺寸：行数必须和 X 一样多
print(y.head(3))                                       # 前 3 天的租车量
```

#### 老师答疑（思考题：为什么必须先把 `dteday` 转成日期类型，才能拆"星期几"？）

你的答案「因为不转的话是 object 类型，无法识别」方向对，补全成两层：

1. **访问器不给用**：`dteday` 是文本（`object`/`str`）时，pandas 不发 `.dt` 工具箱——`df['dteday'].dt.weekday` 直接报 `AttributeError: Can only use .dt accessor with datetimelike values`（函数②的常见坑）。
2. **就算硬算也算不出**：文本 `'2011-01-01'` 只是字符串，字符串比较只认字典序，它身上没有"这是星期几"这个信息；转成 `datetime64` 之后日期才有了日历结构，`.dt.weekday` 才有东西可取。

一句话版：**先转类型 = 先让 pandas 认出"这是日期"，`.dt` 才拿得到年月和星期几。**

## 【本节重点总结】

1. 日期先 `pd.to_datetime` 转类型，才能用 `.dt.year / .dt.month / .dt.weekday` 拆出衍生特征——顺序不能反，否则直接报错。
2. 类别列先 `astype('str')` 表明"这是标签"，再 `pd.get_dummies(df, columns=[...])` 拆成 0/1；`to_datetime` / `astype` / `get_dummies` / `drop` 全都要**接变量**才生效。
3. `y = df['cnt']`、`X = df.drop(columns=['cnt', 'dteday'])`——X 和 y 行数必须相等、顺序一一对应，这就是模型的"配方"。
