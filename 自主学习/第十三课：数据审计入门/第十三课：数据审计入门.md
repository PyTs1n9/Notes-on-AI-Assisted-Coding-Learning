# 第十三课：数据审计入门

## 【本节核心知识点】

拿到陌生数据别急着清洗建模——先做**数据审计**（data audit，数据审计）：查形状、查类型、查缺失、看统计摘要，最后拼出一张"每个字段一行"的审计表雏形。

## 【核心概念讲解】

### 0. 前情提要

第十二课把聚类结果画出来、读成了"人话"，聚类线到此收尾（单元测试③ 随时可开）。这条新线对标实战任务包 A1「真实租赁数据审计」——清洗、回归、聚类全都建立在"数据靠不靠谱"之上，所以先学会**验房**再动手。

工具你其实都见过：第三课学过 `shape / head / dtypes / describe`（当时还闹过"票价变文字、电影名混进统计"的笑话），第八课学过 `isnull()` 查缺失。这一课把它们串成固定流程，第一次在 **731 行 × 16 列的真实数据**上跑。

### 1. 数据审计 = 先验房，再动手

类比：租房前要验房（看户型、查水电、找裂缝）。数据审计就是在清洗/建模之前查清数据的底细：

- 有多大？每列叫什么、什么类型？
- 缺不缺？缺多少？缺在哪列？
- 数值范围合不合理（有没有离谱值）？

产出 = **审计表 + 审计结论**。这一步花的几分钟，比后面每个 bug 都值。

### 2. `shape` 与字段类型：多大、都是什么

- `shape` 返回 `(行数, 列数)` 元组——注意它是**属性，不加括号**（第三课的坑）。
- `dtypes` 的索引就是**字段名**（field，字段，表的列名），值是类型：`int64`/`float64` 是数值列，`object`（文档用的 pandas 3.x 显示 `str`）是文本列。
- 文本列是审计的重点嫌疑：第三课 `describe` 里冒出"电影名"，根子就是数值列被存成了文本——先看 `dtypes` 就能逮住这类坑。

### 3. `head()`：先看 5 行长什么样

列名对不对、单位像不像、日期是 `2011-01-01` 还是 `20110101`——第一眼就有数。它只"看"不动，数据不会被改。

### 4. 缺失值逐列统计

**缺失值**（missing value，缺失值）= 空格子。第八课用 `isnull().sum().sum()` 一锤子问"总共缺多少"；审计要问的是"**哪一列**缺多少"——把最后一层 `sum()` 去掉：

- `isnull()` → 每个格子变 `True`（是空的）/ `False`（不是）
- `.sum()` → `True` 当 1 加、`False` 当 0 加 → **每列**的缺失个数

每一列都是 0 = 没缺失——"0"也是审计结论（演示的 `day.csv` 就是全 0）。

### 5. `describe()`：数值列的体检摘要

八行统计量：`count / mean / std / min / 25% / 50% / 75% / max`。

- **四分位数**（quartile，四分位数）：把一列从小到大排好，`25%` 表示"比它小的占四分之一"，`50%` 就是中位数，`75%` 表示"比它小的占四分之三"。
- **`count` = 非缺失个数**——这是审计的交叉验证神器：哪列 `count` 小于总行数，哪列就有缺失，正好和 `isnull().sum()` 对上。
- 文本列默认不出现（第三课的知识）。

### 6. 审计表雏形

把"类型"和"缺失数"两个 Series 装进一个 DataFrame：两者的索引都是字段名，**自动对齐**，于是每个字段一行——这就是任务包 A1 里 `data_profile` 审计表的雏形。

## 【核心内置函数拆解】

### ① `df.shape` — 表有多大

- **作用**：返回表格的尺寸。
- **完整语法**：`df.shape`（属性，**不加括号**）。
- **关键参数**：无。
- **返回值**：元组 `(行数, 列数)`，如 `(731, 16)`。
- **常见坑**：写成 `df.shape()` 会报 `'tuple' object is not callable`；行数 = 数据条数，列数 = 字段总数。
- **适用场景**：审计第一步；读数据后、切分前后核对行数有没有变。

### ② `df.dtypes` — 每列叫什么、什么类型

- **作用**：列出全部字段名和它们的类型。
- **完整语法**：`df.dtypes`（属性，不加括号）。
- **关键参数**：无。
- **返回值**：Series——索引是字段名，值是类型（`int64`/`float64`/`object`…）。
- **常见坑**：文本列在 pandas 2.x 显示 `object`、3.x 显示 `str`，同一种东西的版本显示差异，**不算错**；数值列一旦混成文本（第三课事故），`mean` 等统计全废——审计先看它。
- **适用场景**：审计第二步；判断某列能不能算平均、能不能进模型。

### ③ `df.head(n=5)` — 看前几行

- **作用**：取前 n 行做"快照"，认识数据长什么样。
- **完整语法**：`df.head()`（默认 5 行）或 `df.head(3)`。
- **关键参数**：`n`：取几行，默认 5。
- **返回值**：新的 DataFrame（前 n 行），**原表不变**。
- **常见坑**：它只是"看"，不会截断数据；列太多放不下时中间列会折叠成 `...`，那是显示宽度限制，不是数据丢了。
- **适用场景**：读完数据的第一眼；核对列名、单位、格式。

### ④ `df.isnull().sum()` — 逐列数缺失

- **作用**：统计每一列各有多少个缺失值。
- **完整语法**：`df.isnull().sum()`；要"总缺失数"再加一层 `.sum()`（第八课的三层连招）。
- **关键参数**：无。
- **返回值**：Series——索引是字段名，值是该列缺失个数。
- **常见坑**：`isnull()` 只认真正的空格子（NaN），字符串 `'NA'`、数字 `0`、空字符串 `''` 都**不算**缺失；`True` 当 1 加是 pandas 的规则（`True=1`、`False=0`）。
- **适用场景**：审计第三步；任何建模、分组、画图之前的必查项。

### ⑤ `df.describe()` — 数值列的统计摘要

- **作用**：一次给出所有数值列的八行统计量。
- **完整语法**：`df.describe()`，常配 `.round(2)` 控制小数位。
- **关键参数**：一般不带参数直接用（`percentiles`/`include` 第三课提过，本课不展开）。
- **返回值**：DataFrame——行是 `count/mean/std/min/25%/50%/75%/max`，列是各数值列。
- **常见坑**：默认**只统计数值列**（文本列不出现）；**`count` = 非缺失个数**，有缺失的列会小于总行数；表太宽时中间列折叠成 `...`，要看全列得记住列的顺序或换窄表。
- **适用场景**：审计第四步；快速发现离谱值（`min`/`max` 超出常识范围）。

### ⑥ `pd.DataFrame({'列名': 数据, ...})` — 拼审计表

- **作用**：把多个 Series/列表按字典拼成一张新表。
- **完整语法**：`pd.DataFrame({键1: 数据1, 键2: 数据2})`（第三课字典造表的进阶用法）。
- **关键参数**：字典的**键 = 新表的列名**；值 = 等长的数据。
- **返回值**：新 DataFrame。
- **常见坑**：值是 Series 时按**索引对齐**——`df.dtypes` 和 `df.isnull().sum()` 的索引都是字段名，正好一一对上；若两个 Series 索引不同，会错位出 `NaN`；值是普通列表时按位置排、不看索引。
- **适用场景**：造审计表、汇总表；把散落的统计量拼成"每行一个对象"的表。

## 【完整代码示例 + 逐行注释】

```python
# ============ 第十三课演示：给真实的单车租赁数据做一次"数据审计" ============
import pandas as pd                                    # 读表、造审计表

df = pd.read_csv('day.csv', encoding='utf-8-sig')      # 真实 UCI 共享单车数据：2011-2012 两年共 731 天

# ---------- 第 1 步：先看"多大、每列叫什么、什么类型" ----------
print(df.shape)                                        # 函数①：行数 × 列数 → (731, 16)
print(df.dtypes)                                       # 函数②：索引 = 字段名，值 = 字段类型

# ---------- 第 2 步：看前 5 行，认识数据长什么样 ----------
print(df.head())                                       # 函数③：前 5 行快照

# ---------- 第 3 步：逐列数缺失值（空格子） ----------
print(df.isnull().sum())                               # 函数④：每列各缺几个；全 0 = 这份数据没有缺失

# ---------- 第 4 步：数值列统计摘要 ----------
print(df.describe().round(2))                          # 函数⑤：count/mean/std/min/四分位/max

# ---------- 第 5 步：审计表雏形：每个字段一行体检结果 ----------
audit = pd.DataFrame({                                 # 函数⑥：两个 Series 字段名相同，自动按字段对齐
    '类型': df.dtypes,                                 # 第 1 列：字段类型
    '缺失数': df.isnull().sum(),                       # 第 2 列：该字段缺失几个
})
print(audit)                                           # 索引 = 字段名，16 个字段一屏看完
```
