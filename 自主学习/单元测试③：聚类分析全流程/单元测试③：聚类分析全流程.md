## 【知识速览】函数速查表

| 函数/属性 | 作用 | 记忆点 / 坑 |
|---|---|---|
| `StandardScaler().fit_transform(X)` | 标准化：各列拉回均值 0、标准差 1 | 必须在 KMeans **之前**做；返回 numpy 数组 |
| `KMeans(n_clusters=k, random_state=13, n_init=10)` | 把样本分成 k 簇 | 先创建再 `fit`；`random_state` 固定可复现、`n_init=10` 防运气差 |
| `km.labels_` | 每个样本的簇号 | 尾下划线属性：`fit` 之后才有、**不加括号** |
| `km.cluster_centers_` | 各簇中心（标准化坐标） | 形状 (k, 特征数)，想看原始单位要 `inverse_transform` |
| `km.inertia_` | 簇内平方和（越小越紧凑） | K 越大**必然**越小，不能直接取最小的 K |
| `silhouette_score(X, labels)` | 轮廓系数：内紧外松，越大越好 | 找**峰值**；`labels` 必须是同一次聚类的 `km.labels_` |
| `davies_bouldin_score(X, labels)` | DBI：簇间相似度，越小越好 | 找**谷值**，方向跟轮廓系数**相反** |
| `max(列表)` / `min(列表)` + `.index(...)` | 程序找峰/谷对应的 K | 不许手写死数字 |
| `plt.plot(Ks, inertias, 'o-')` | 画肘部曲线 | x 必须显式传 K 值列表 |
| `plt.scatter(x, y, c=簇标签, cmap='viridis')` | 散点图按簇着色 | `c` 传的是簇标签数组 |
| `plt.imshow(km.cluster_centers_)` | 聚类中心热力图 | 别忘 `colorbar` 和两轴刻度标签 |
| `df.groupby('簇标签').mean()` | 按簇算各列平均 | 原始尺度的数最好读 |
| `df['簇标签'].value_counts().sort_index()` | 各簇样本数 | `.to_dict()` 变成字典 |

## 【测试题】

### 一、概念题（每题 2 分，共 10 分）

1. 什么是无监督学习？KMeans 的训练数据里有没有标签 y？它靠什么判断两个样本「像」？
2. 为什么 KMeans 之前必须 `StandardScaler` 标准化？不做的后果是什么？
3. `inertia_` 是什么（说人话）？为什么「选 inertia 最小的 K」是错的？肘部法则怎么定 K？
4. 轮廓系数和 DBI 各是越大越好还是越小越好？`silhouette_score(X, labels)`、`davies_bouldin_score(X, labels)` 里的 `labels` 从哪来、有什么讲究？
5. 散点图、聚类中心热力图、分组平均特征表三件套各回答什么问题？给簇起名字时为什么必须引自己表里的数字？

### 二、函数题（每题 2 分，共 8 分）

1. `StandardScaler().fit_transform(X)` 返回什么？标准化后各列的均值、标准差约等于多少？
2. `KMeans(n_clusters=3, random_state=13, n_init=10)` 三个参数各管什么？`km.labels_`、`km.cluster_centers_`、`km.inertia_` 三张成绩单各是什么、什么时候才有？
3. `silhouette_score(X, labels)` 和 `davies_bouldin_score(X, labels)` 的返回值各是什么、方向如何？为什么说 `labels` 必须是「同一次聚类」给出的 `km.labels_`？
4. `plt.plot(Ks, inertias, 'o-')` 的 x、y 各传什么？`plt.scatter(x, y, c=...)` 的 `c` 管什么？`plt.imshow(km.cluster_centers_)` 画的是什么、默认横纵轴各代表什么？

### 三、纠错题（每题 3 分，共 12 分：指出错误 + 写出正确写法/说法）

1. 有人直接 `km = KMeans(n_clusters=3).fit(df)`，在原始数据上聚类——错在哪？会出什么后果？正确写法？
2. `s = silhouette_score(km.labels_, X_scaled)` ——错在哪？正确写法？
3. 有人总结：「K=10 的 `inertia_` 最小，所以最佳 K 就取 10」——错在哪？正确的定 K 方法是什么？
4. 解读只写「簇 0 是高消费群体」，不带任何数字——错在哪？举一个正确的写法。

**题目 1：会员分群与肘部法则（30 分）**（数据 `member.csv`，150 行 2 列：`月消费金额`、`到店次数`，某商场 150 位会员的消费行为，`read_csv` 记得 `encoding='utf-8-sig'`）

1. 读数据 + 体检：打印 `df.shape`、`df.dtypes`、缺失值总数；
2. 标准化：`StandardScaler().fit_transform(两列特征)`，打印 `X_scaled.shape`、各列均值（`.round(4)`）、各列标准差（`.round(4)`）；
3. 肘部循环：`for k in range(2, 11)`，每档 `KMeans(n_clusters=k, random_state=13, n_init=10)`（参数别改，验收值按它钉），打印每个 K 的 `inertia_`（`round(..., 2)`）和下降幅度（上一档减本档，`round(..., 2)`；K=2 行写 `—` 或 `0` 都行）；
4. 肘部曲线：`plt.plot(K值, inertia列表, 'o-')`——x 必须传 K 值列表，配 x/y 轴标签、标题，`savefig` 成图片文件（中文字体 `rcParams` 两行照课上抄）；
5. 结论一句话：肘部是 K = ？，结合你自己打印的下降幅度说说为什么。

**验收点**：① `df.shape` == (150, 2)、缺失 0、两列 dtype 都是数值；② 标准化后形状 (150, 2)，打印的两列均值绝对值 < 0.001、两列标准差与 1 之差 < 0.001；③ K=2~10 的 `inertia_`（round 2）依次为 **83.70 / 23.75 / 18.02 / 15.34 / 13.43 / 11.65 / 10.39 / 9.62 / 8.56**（每档 ±0.05）；对应的下降幅度（round 2）依次为 **— / 59.95 / 5.72 / 2.69 / 1.90 / 1.78 / 1.27 / 0.76 / 1.06**（每档 ±0.05，由你的程序自己算自己打）；④ 肘部曲线的 x 传 K 值、y 传 inertia（只传一维 y 的不算过），图带 x/y 轴标签 + 标题，并 `savefig` 出图——这问看你的代码和生成的图片；⑤ 结论说 **K = 3**，并且理由里引用你自己打印的下降幅度数字（比如「2→3 降了将近 60，3→4 只降 5.72」）。

**题目 2：城市分型——定 K + 可视化解读（30 分）**（数据 `city.csv`，120 行 3 列：`人口密度`、`平均房价`、`地铁站数`，120 座城市的三项指标）
