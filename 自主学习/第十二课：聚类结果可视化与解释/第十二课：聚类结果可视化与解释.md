# 第十二课：聚类结果可视化与解释

## 【本节核心知识点】

KMeans 给出簇号只是半场：把分簇结果**画出来**（散点图、聚类中心热力图）并**算出每簇的平均特征**，给每簇起个业务名字，聚类才变成能用的结论。

## 【核心概念讲解】

### 0. 前情提要

第九课用 KMeans 把顾客分成 3 簇，第十课肘部法则、第十一课轮廓系数与 DBI 三证合一确认了 K=3。但到目前为止，我们手里只有一列 0/1/2 的簇号——**分完了，还没看懂**。这一课把结果变成"人话"。

### 1. 为什么要"解释"聚类

簇号 0、1、2 本身没有意义，它们只是"第几堆"。业务方要的是画像（persona，画像）："哪堆人收入高但消费低？""哪堆人是核心客户？"——这就要看**每簇长什么样**。

### 2. 二维散点图（scatter plot，散点图）——"分堆"看得见

每个点是一个顾客，x、y 各放一列特征，**颜色放簇号**——一眼看出三堆分得开不开、有没有混在一起。两列特征画一张图；数据有 3 列特征时就任选两列画。

### 3. 聚类中心热力图（heatmap，热力图）——"每簇的平均人"

聚类中心（cluster center，聚类中心）存在 `km.cluster_centers_` 里，形状是 **(簇数 × 特征数)** 的二维数组：每一行是一个簇的"平均人"在各特征上的坐标。热力图把二维数组画成色块：**颜色越深（按配色方案）代表值越大**，哪格红哪格蓝一眼分明。注意这里画的是**标准化后的值**——各特征量纲一致才公平比较。

### 4. 分组平均特征——回到原始尺度算每簇均值

热力图好看但数字读不准，所以还要一张表：把簇号存回原表当新列，`groupby('簇标签').mean()` 按簇分组求各列平均——**原始尺度**（比如年收入多少元）业务方读得懂。

### 5. 起名字 = 业务解读

对着平均特征表给每簇起名（"高收入低消费组""核心客户组"），**理由必须引用自己表里的数字**——不引数字的解读只是猜。这是聚类分析（cluster analysis，聚类分析）落到业务的最后一公里。

## 【核心内置函数拆解】

### ① `plt.scatter(x, y, c=标签)` — 按簇着色画散点图

- **作用**：把每个样本画成一个点，用颜色区分它属于哪个簇。
- **完整语法**：`plt.scatter(x列, y列, c=着色依据, cmap='viridis', s=40)`。
- **关键参数**：`x`/`y` 各传一列（Series 或数组）；`c` 传簇标签列（每个点的颜色依据）；`cmap` 是配色方案名（`'viridis'` 黄绿色系，色盲友好）；`s` 是点的大小。
- **返回值**：一个散点图对象（通常不用接，画完 `savefig` 就行）。
- **常见坑**：`c` 的长度必须和 `x`/`y` 一样（都是样本数），传错列会报 `ValueError`；图上要显示中文标签，先抄 `rcParams` 那两行，否则中文变方框（tofu，豆腐块）。
- **适用场景**：两列特征看分簇效果、看簇与簇有没有重叠。

### ② `plt.imshow(二维数组)` + `plt.colorbar()` — 画热力图

- **作用**：把二维数组画成色块矩阵，数值大小用颜色深浅表示；`colorbar` 在旁边加一条"颜色 ↔ 数值"对照条。
- **完整语法**：`plt.imshow(二维数组, cmap='coolwarm', aspect='auto')`、`plt.colorbar(label='色条标题')`、`plt.xticks(位置列表, 标签列表)`、`plt.yticks(位置列表, 标签列表)`。
- **关键参数**：`imshow` 只吃**二维数组**（行 × 列）；`cmap='coolwarm'` 是红蓝配色（红=大、蓝=小）；`aspect='auto'` 让色块随画布拉伸（默认会压成方块）；`xticks`/`yticks` 的**位置列表和标签列表必须成对**，位置是第几列/第几行（从 0 数）。
- **返回值**：`imshow` 返回图像对象；`colorbar` 返回色条对象（通常都不接）。
- **常见坑**：`km.cluster_centers_` 正好是 (簇数 × 特征数) 的二维数组，直接喂给 `imshow` 就是"每行一簇、每列一特征"的热力图；不加 `colorbar` 就不知道颜色对应多大的值；刻度不换标签的话横轴显示 0、1，看不出是哪个特征。
- **适用场景**：看聚类中心各特征的相对高低、给"每簇的平均人"画像。

### ③ `df.groupby('列').mean()` — 按簇分组求各列平均

- **作用**：按某一列（这里是簇标签）把行分成几组，每组对其他数值列求平均。
- **完整语法**：`df.groupby('分组列').mean()`，常配 `.round(2)` 控制小数位。
- **关键参数**：`groupby` 的参数是分组依据的列名；返回的新表以分组列为**索引**（index，索引，行的标签）。
- **返回值**：新 DataFrame——每行一个组，每列是该组的平均值；配合 `means.loc[簇号, 列名]` 取单个数。
- **常见坑**：`mean()` 只对数值列求平均，表里若混着文本列（比如姓名）会报错或跳过，用之前先确认 `df.dtypes`；分完组想数人数用 `df['簇标签'].value_counts().sort_index()`（按簇号排好序），别用 `mean()`。
- **适用场景**：统计不同簇的平均特征、给每簇做画像。

## 【完整代码示例 + 逐行注释】

```python
# ============ 第十二课演示：把顾客的 3 簇画出来、标出来、算出来 ============
import pandas as pd                                    # 读数据、分组统计
import matplotlib.pyplot as plt                        # 画图
from sklearn.preprocessing import StandardScaler       # 标准化
from sklearn.cluster import KMeans                     # KMeans

plt.rcParams['font.sans-serif'] = ['Microsoft YaHei', 'SimHei']  # 中文字体，防止中文变方框
plt.rcParams['axes.unicode_minus'] = False                      # 负号正常显示

# ---------- 1. 老流程：读数据 → 标准化 → KMeans(K=3) ----------
df = pd.read_csv('customers.csv', encoding='utf-8-sig')  # 读顾客数据（80 行 2 列）
X_scaled = StandardScaler().fit_transform(df)            # 标准化（第九课的老规矩）
km = KMeans(n_clusters=3, random_state=42, n_init=10)    # K=3：第九课人工定、第十一课三证合一确认
km.fit(X_scaled)                                         # 训练
df['簇标签'] = km.labels_                                 # 把簇号存回表格当新列（0/1/2）

# ---------- 2. 二维散点图：每个点按簇着色 ----------
plt.figure(figsize=(7, 5))                               # 新建画布（宽 7 高 5 英寸）
plt.scatter(df['年收入（元）'], df['消费评分'],             # x、y 各传一列
            c=df['簇标签'], cmap='viridis', s=40)          # 函数①：c=着色依据（簇标签）
plt.xlabel('年收入（元）')                                 # x 轴标签
plt.ylabel('消费评分')                                     # y 轴标签
plt.title('顾客 3 簇散点图（颜色 = 簇号）')                 # 标题
plt.savefig('顾客-散点图.png', dpi=120)                    # 存成图片（dpi=清晰度）
plt.close()                                              # 关掉画布，防止和下一张图串台

# ---------- 3. 聚类中心热力图 ----------
plt.figure(figsize=(5, 4))                               # 新建画布
plt.imshow(km.cluster_centers_, cmap='coolwarm', aspect='auto')  # 函数②：3 行(簇)×2 列(特征)
plt.colorbar(label='标准化后的值')                         # 色条：颜色 ↔ 数值对照
plt.xticks([0, 1], ['年收入', '消费评分'])                 # x 轴刻度换成特征名（位置、标签成对传）
plt.yticks([0, 1, 2], ['簇0', '簇1', '簇2'])              # y 轴刻度换成簇号
plt.title('聚类中心热力图（标准化值）')
plt.savefig('顾客-中心热力图.png', dpi=120)                # 存成图片
plt.close()                                              # 关掉画布

# ---------- 4. 统计不同簇的平均特征（原始尺度，最好读） ----------
means = df.groupby('簇标签').mean().round(2)              # 函数③：按簇分组、各列求平均
sizes = df['簇标签'].value_counts().sort_index()           # 各簇人数（按簇号排好序）
print(means)                                             # 打印平均特征表

# ---------- 5. 读结果：数字用 f-string 从表里拼，不手写 ----------
for i in range(3):                                       # 逐簇读
    print(f'簇{i}：{sizes[i]} 人，平均年收入 {means.loc[i, "年收入（元）"]:.0f} 元，'
          f'平均消费评分 {means.loc[i, "消费评分"]:.1f}')
```
