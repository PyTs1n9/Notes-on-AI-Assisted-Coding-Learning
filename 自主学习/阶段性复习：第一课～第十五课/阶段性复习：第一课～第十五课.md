## 二、语法理解复习（Python 基础语法）

课程里用到的语法就这几样，全部要求「看懂 + 会自己写」。

### 1. 变量、类型与打印

- 变量就是「起个名字存东西」：`count = 0`、`name = '南京'`。赋值会覆盖旧值。
- 常见类型：整数 `int`、小数 `float`、文字 `str`。文字和数字**不一回事**：`'8' + '2'` 是 `'82'`，`8 + 2` 才是 `10`。
- `print` 可以用**逗号**一次打多个东西：`print('个数：', count)`。
- `#` 后面是注释，程序不执行。

### 2. 列表（list）

```python
nums = [4, 7, 2, 7, 9]   # 造一个列表
print(nums[0])           # 下标从 0 开始：第一个元素是 4
print(nums[-1])          # 负数下标从末尾数：最后一个是 9
print(len(nums))         # 元素个数：5
nums.append(1)           # 往末尾追加一个值（原地改，不用接变量）
print(nums)              # [4, 7, 2, 7, 9, 1]
```

### 3. 字典（dict）

```python
info = {'甲': 88, '乙': 92}   # 键: 值，键不能重复
print(info['甲'])            # 按键取值：88
info['丙'] = 76              # 加新键值对
print(len(info))             # 键值对个数：3
```

### 4. for 循环与 range

```python
total = 0                          # 累加变量先清零
for n in [4, 7, 2]:               # 依次取出每个元素
    total = total + n              # 累加
print(total)                       # 13

for i in range(1, 4):             # range 起点含、终点不含：1、2、3
    print(i)
```

**坑**：`range(1, len(列表))` 会**漏掉第 0 个**元素——想数全部元素写 `range(0, len(列表))`，或者干脆 `for x in 列表`。

### 5. if 条件与比较

```python
picked = []
for n in [4, 7, 2, 9]:
    if n > 5:              # 比较：> < >= <= == !=（双等号才是「判断相等」）
        picked.append(n)   # 单等号 = 是赋值，条件里写单等号直接报错
print(picked)              # [7, 9]
```

- 组合条件：`and`（并且）、`or`（或者）。

### 6. 方法 vs 属性（一个括号的差别）

- **方法**要加括号：`列表.append(值)`、`df.head()` —— 是「做一件事」。
- **属性**不加括号：`df.shape`、`model.coef_` —— 是「查一个现成的信息」。
- sklearn 学到的参数都是**尾下划线属性**（`coef_`、`labels_`、`inertia_`），**训练之后才有**。

## 三、函数理解复习（函数卡片总表）

考核只写函数名不给调用写法，所以每个函数的「长什么样」在这里记熟。看表顺序：**作用 → 语法 → 参数 → 返回值 → 坑**。

### 1. NumPy 两个入门函数

| 函数 | 作用 | 完整语法 | 关键参数 | 返回值 | 常见坑 |
|---|---|---|---|---|---|
| `np.array` | 列表转数组 | `np.array(列表)` | — | ndarray 数组 | sklearn 不收普通列表 |
| `reshape` | 改形状 | `数组.reshape(-1, 1)` | `-1` = 行数自动算 | 新数组（不改原数组） | sklearn 特征必须二维，一维直接报错 |

### 2. Pandas 造表与查看

| 函数/属性 | 作用 | 完整语法 | 返回值 | 常见坑 |
|---|---|---|---|---|
| `pd.Series` | 造一列带标签的数据 | `pd.Series(数据, index=None, name=None)` | Series | — |
| `pd.DataFrame` | 造一张表 | `pd.DataFrame({'列名': 数据, ...})` | DataFrame | 字典的键 = 列名 |
| `head` / `tail` | 看前 / 后几行 | `df.head(n=5)` | 新的表（前 n 行） | 默认 5 行 |
| `info` | 表格体检报告 | `df.info()` | **None（只打印）** | 别套进 `print` 里 |
| `describe` | 数值列统计摘要 | `df.describe()` | 8 行统计量的表 | **默认只统计数值列** |
| `shape` | 多少行多少列 | `df.shape` | 元组 `(行数, 列数)` | 属性，不加括号 |
| `columns` | 列名清单 | `df.columns` | 列名索引 | 属性，不加括号 |
| `dtypes` | 每列类型 | `df.dtypes` | 每列一个类型 | 属性，不加括号 |

### 3. Pandas 取数与 CSV 读写

| 写法 | 作用 | 坑 |
|---|---|---|
| `df['列名']` | 取一列，得 Series | 取出来是一列不是表 |
| `df.loc[行名, 列名]` | 按**名字**取 | 名字切片**两端都包含** |
| `df.iloc[行号, 列号]` | 按**位置**取 | 从 0 数，位置切片**不含末尾** |
| `df[布尔条件]` | 按条件挑行 | 组合条件用 `&`/`|`，**每个条件加括号** |
| `pd.read_csv(路径, encoding='utf-8-sig')` | CSV 读进内存 | 中文 CSV 记得 encoding |
| `df.to_csv(路径, index=False, encoding='utf-8-sig')` | 表存成 CSV | 不写 `index=False` 会多存一列行号；**存读成对** |

### 4. Pandas 清洗

| 函数 | 作用 | 完整语法 | 返回值 | 常见坑 |
|---|---|---|---|---|
| `isnull` | 找缺失 | `df.isnull().sum()`（逐列）/ `.sum().sum()`（总数） | 数字 | 全 0 也是审计结论 |
| `duplicated` | 找重复行 | `df.duplicated().sum()` | 重复行数 | 判断「和**前面**的行是否整行相同」 |
| `drop_duplicates` | 删重复行 | `df = df.drop_duplicates()` | 去重后的新表 | **不接变量等于白删**；删完用 shape 对账 |
| `quantile` | 取分位数 | `df['列'].quantile(0.25)` | 一个数 | IQR 法的原料；缺失值自动跳过 |

**IQR 四分位距法**（第十四课核心公式）：`IQR = Q3 − Q1`，下限 `= Q1 − 1.5×IQR`，上限 `= Q3 + 1.5×IQR`；超出 [下限, 上限] 的行是**异常候选**。0/1 型列（IQR=0）别硬套。**识别 ≠ 处理**：捞出来是代码的事，删还是留是业务判断。

### 5. Pandas 特征准备（第十五课）

| 函数 | 作用 | 完整语法 | 返回值 | 常见坑 |
|---|---|---|---|---|
| `to_datetime` | 文本转日期 | `df['日期列'] = pd.to_datetime(df['日期列'])` | datetime64 类型的列 | **不接变量不生效**；转了才能拆成分 |
| `.dt` 访问器 | 拆日期成分 | `df['日期列'].dt.year / .dt.month / .dt.weekday` | 一列整数 | `.dt.weekday` 是 **0=周一**；衍生新列先查列名别撞车 |
| `astype` | 改类型 | `df['列'] = df['列'].astype('str')` | 转换后的新列 | 不接变量不生效 |
| `get_dummies` | 类别列拆 0/1 | `df = pd.get_dummies(df, columns=['列名'])` | 拆完的新表 | 旧类别列消失、换成 `列名_取值` 若干列 |
| `drop` | 删列 | `X = df.drop(columns=['列名1', '列名2'])` | 删完的新表 | 切 X 用它；X 和 y **行数相等、顺序对应** |

### 6. sklearn 线性回归

| 函数/属性 | 作用 | 完整语法 | 返回值 | 常见坑 |
|---|---|---|---|---|
| `LinearRegression` | 建模 | `model = LinearRegression()` | 未训练的模型 | — |
| `fit` | 训练 | `model.fit(X_train, y_train)` | 模型本身 | **只喂训练集**；特征要二维 |
| `predict` | 预测 | `model.predict(X_new)` | 预测值数组 | X_new 也要二维 |
| `coef_` / `intercept_` | 学到的斜率/截距 | `model.coef_` | 数组 / 数字 | 尾下划线属性，训练后才有 |
| `score` | 模型自带打分 | `model.score(X, y)` | 回归下就是 **R²** | 成绩以**测试集**为准 |
| `train_test_split` | 切训练/测试集 | `train_test_split(X, y, test_size=0.25, random_state=21)` | `X_train, X_test, y_train, y_test`（**这个顺序**） | 切的是样本行，两边行数永远跟 X/y 对得上；`random_state` 固定才能复现 |

### 7. 回归评价指标（第五课）

| 函数 | 含义 | 完整语法 | 方向 | 坑 |
|---|---|---|---|---|
| `mean_absolute_error` | MAE：平均差了多少 | `mean_absolute_error(y_true, y_pred)` | 越小越好 | 两个参数顺序：真实值在前 |
| `mean_squared_error` | MSE：平方重罚大误差 | 同上 | 越小越好 | 单位是「平方」 |
| `root_mean_squared_error` | RMSE = √MSE，回原单位 | 同上 | 越小越好 | 汇报最常用 RMSE + R² |
| `r2_score` | R²：比闭眼猜平均值好多少 | 同上 | 越接近 1 越好 | 0 = 等于猜平均值，负数 = 更差 |

**必记关系**：RMSE ≥ MAE；`model.score(X_test, y_test)` 与 `r2_score(y_test, 预测值)` 数值相等。

### 8. 正则化与调参（第六、七课）

| 函数/属性 | 作用 | 完整语法 | 关键参数 | 返回值 | 坑 |
|---|---|---|---|---|---|
| `Ridge` | L2 正则化，系数整体往 0 压、不归零 | `Ridge(alpha=1.0)` | `alpha` 越大压得越狠（=0 退回普通线性回归） | 模型 | 系数比 OLS 小 |
| `Lasso` | L1 正则化，没用特征的系数**压成 0** | `Lasso(alpha=1.0, max_iter=10000)` | `alpha`、`max_iter` | 模型 | 顺手做特征选择；不收敛就加大 `max_iter` |
| `KFold` | 定「怎么切折」 | `KFold(n_splits=5, shuffle=True, random_state=42)` | `n_splits` 折数、`shuffle` 洗不洗牌 | 切折方案 | **默认不洗牌**——有序数据会切偏 |
| `cross_val_score` | K 折打分 | `cross_val_score(模型, X, y, cv=切折方案)` | `cv`、`scoring` | 每折分数的数组，`.mean()` 取平均 | `scoring='neg_*'` 返回**负数**（sklearn 统一口径「分数越大越好」） |
| `GridSearchCV` | 网格搜索挑超参数 | `GridSearchCV(模型, {'alpha': [...]}, cv=切折方案)` | `param_grid`、`cv` | 搜索器 | `fit` 后才有成绩 |
| `best_params_` / `best_score_` | 选出的参数 / 它的平均分 | `gs.best_params_` | — | 字典 / 数字 | **裁判**（挑参数），不兼考生（报成绩） |
| `cv_results_` | 每个候选的成绩表 | `gs.cv_results_` | — | 字典/表 | 画 alpha 曲线的数据源 |

**数据流向铁律**：凡 `fit` 系列只许碰训练集——`scaler.fit_transform(X_train)` + `scaler.transform(X_test)`、`gs.fit(X_train, y_train)`；测试集一旦参与「学」，成绩就是虚的。

### 9. 聚类（第九～十二课）

| 函数/属性 | 作用 | 完整语法 | 返回值 | 坑 |
|---|---|---|---|---|
| `StandardScaler` | 标准化：各列拉回均值 0、标准差 1 | `X_scaled = StandardScaler().fit_transform(X)` | numpy 数组 | 必须在 KMeans **之前**做 |
| `KMeans` | 把样本分成 k 簇 | `km = KMeans(n_clusters=k, random_state=42, n_init=10)` → `km.fit(X_scaled)` | 聚类器 | `random_state` 固定可复现、`n_init=10` 防运气差 |
| `labels_` | 每个样本的簇号 | `km.labels_` | 一维数组 | fit 后才有，不加括号 |
| `cluster_centers_` | 各簇中心 | `km.cluster_centers_` | 形状 (k, 特征数) | 是**标准化坐标**，想看原单位要还原 |
| `inertia_` | 簇内平方和（多紧凑） | `km.inertia_` | 一个数 | K 越大**必然**越小，不能直接取最小 |
| `silhouette_score` | 轮廓系数：内紧外松 | `silhouette_score(X_scaled, km.labels_)` | −1~1 的数 | **越大越好、找峰值**；labels 必须是同一次聚类的 |
| `davies_bouldin_score` | 簇间相似度 | `davies_bouldin_score(X_scaled, km.labels_)` | ≥0 的数 | **越小越好、找谷值**，方向和轮廓系数相反 |
| `max` / `min` + `.index` | 程序找峰/谷对应的 K | `Ks[scores.index(max(scores))]` | 一个 K | **不许手写死数字** |
| `groupby(...).mean()` | 按簇算各列平均 | `df.groupby('簇标签').mean().round(2)` | 分组平均表 | 原始尺度的数最好读 |
| `value_counts` | 各簇样本数 | `df['簇标签'].value_counts().sort_index().to_dict()` | 计数 | `.sort_index()` 让簇号有序 |

**三证合一定 K**：肘部（inertia 下降由陡变缓的拐点）＋ 轮廓系数峰值 ＋ DBI 谷值；打架时如实写「谁最优、谁分歧」，取折中要给理由。

## 四、数据清洗流程（第十三～十五课）

**五步流水线（顺序不能乱）**：

1. **审计**（第十三课）：形状 → 类型 → 前几行长相 → 逐列缺失 + 缺失总数 → 统计摘要；最后用两个同索引的 Series 拼一张「每字段一行」的审计表。`describe` 的 `count` 行和缺失数互相印证（缺 1 个 → count 少 1）。
2. **删重复**（第十四课）：先数重复行数，再删，删完**用形状对账**。
3. **捞异常候选**（第十四课）：**在删完重复之后**算 IQR（顺序不同数值会差一点）：Q1、Q3 → IQR → 上下限 → 条件筛选捞行、打印行数。
4. **转类型、拆日期**（第十五课）：文本日期先转日期类型，再拆年/月/星期几衍生列——顺序反了直接报错；衍生列起名前先查列名别撞车。
5. **类别拆 0/1、切 X/y**（第十五课）：类别列先表明是文本，再拆独热列；标签单列、特征删掉标签列，行数相等、顺序对应。

**代码骨架**（自己能从头敲出来才算会）：

```python
import pandas as pd

# ---------- ① 审计 ----------
df = pd.DataFrame({                                  # 造一张带脏数据的表
    '城市': ['南京', '苏州', '南京', '苏州', '南京', '南京'],
    '客单价': [32.5, 28.0, 32.5, 120.0, 30.2, 28.0],
    '评分': [4.6, 4.2, 4.6, 4.5, None, 4.3],
})
print(df.shape)                 # 表有多大
print(df.dtypes)                # 每列什么类型
print(df.isnull().sum())        # 逐列数缺失
print(df.isnull().sum().sum())  # 缺失总数
print(df.describe())            # 数值列统计摘要，重点看 count 行

# ---------- ② 删重复 ----------
print(df.duplicated().sum())    # 先数重复行数
df = df.drop_duplicates()       # 再删（要接变量）
print(df.shape)                 # 删完对账

# ---------- ③ IQR 捞异常候选（在删完重复之后） ----------
q1 = df['客单价'].quantile(0.25)                       # 第一四分位
q3 = df['客单价'].quantile(0.75)                       # 第三四分位
iqr = q3 - q1                                          # 四分位距
low = q1 - 1.5 * iqr                                   # 下限
high = q3 + 1.5 * iqr                                  # 上限
print(round(q1, 4), round(q3, 4), round(iqr, 4), round(low, 4), round(high, 4))
out = df[(df['客单价'] < low) | (df['客单价'] > high)]  # 两个条件用 |，各加括号
print(len(out))                 # 异常候选行数

# ---------- ④ 类别拆 0/1 ----------
df['城市'] = df['城市'].astype('str')   # 先表明是文本
df = pd.get_dummies(df, columns=['城市'])  # 再拆独热列
print(df.shape)
print(list(df.columns))
```

**坑清单**：`drop_duplicates` 不接变量白删；IQR 必须算在删重之后；异常候选 ≠ 该删；`astype`/`get_dummies`/`to_datetime` 全都要接变量才生效；衍生新列撞上已有列名会**整列覆盖**。

## 五、线性回归流程（第一～八课）

**七步流水线**：读数据 → 体检 → 切 X/y → 划分训练测试集 → 三模型训练 → 指标评价 → 交叉验证/网格搜索 → 结果分析。

```python
import pandas as pd
from sklearn.model_selection import train_test_split, KFold, cross_val_score, GridSearchCV
from sklearn.linear_model import LinearRegression, Ridge, Lasso
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

# ---------- 读数据 + 体检 ----------
df = pd.DataFrame({                                  # 造 8 个样本的小表（真实项目用 read_csv）
    '面积': [50, 60, 70, 80, 90, 100, 110, 120],
    '房龄': [10, 8, 6, 5, 4, 3, 2, 1],
    '租金': [2900, 3350, 3800, 4250, 4700, 5150, 5600, 6050],
})
print(df.shape)
print(df.isnull().sum().sum())

# ---------- 切 X/y + 划分 ----------
X = df[['面积', '房龄']]      # 特征表：两列
y = df['租金']                # 标签：一列
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.25, random_state=21)  # 返回顺序别记错
print(X_tr.shape, X_te.shape)

# ---------- 三模型训练（只喂训练集） ----------
m_ols = LinearRegression()                     # 普通线性回归
m_ridge = Ridge(alpha=2)                       # L2：系数整体压小
m_lasso = Lasso(alpha=0.5, max_iter=10000)     # L1：没用的系数压成 0
m_ols.fit(X_tr, y_tr)                          # fit 只碰训练集
m_ridge.fit(X_tr, y_tr)
m_lasso.fit(X_tr, y_tr)

# ---------- 测试集指标（成绩以测试集为准） ----------
for name, m in [('OLS', m_ols), ('Ridge', m_ridge), ('Lasso', m_lasso)]:
    pred = m.predict(X_te)                                       # 预测测试集
    print(name,
          round(mean_absolute_error(y_te, pred), 2),             # MAE 越小越好
          round(mean_squared_error(y_te, pred), 2),              # MSE
          round(r2_score(y_te, pred), 4),                        # R² 越接近 1 越好
          round(m.score(X_te, y_te), 4))                         # score 就是 R²，两者相等

# ---------- 交叉验证 + 网格搜索（裁判挑参数） ----------
cv = KFold(n_splits=5, shuffle=True, random_state=21)            # 5 折、洗牌、种子固定
print(round(cross_val_score(m_ols, X, y, cv=cv).mean(), 4))      # 5 折平均分
gs = GridSearchCV(Ridge(), {'alpha': [0.01, 0.1, 1, 10, 100]}, cv=cv)  # 网格候选
gs.fit(X_tr, y_tr)                                               # fit 只碰训练集！
print(gs.best_params_, round(gs.best_score_, 4))                 # 选出的参数 + 裁判分
```

**必记分工**：`best_score_` 是**裁判**（在候选里挑 alpha），测试集指标是**考生**（报最终成绩）——裁判不能兼考生，两者不能混着比大小。选模型看指标 + CV 稳不稳（差距 < 0.005 算打平）；Lasso 看 `coef_` 顺手做特征选择。

**坑清单**：`train_test_split` 返回顺序 `X_train, X_test, y_train, y_test`；fit 系列只碰训练集（`gs.fit(X, y)` 拿全数据搜索 = 测试集泄进参数选择，红线）；RMSE ≥ MAE；`score` 和 `r2_score` 相等；`neg_*` 指标返回负数。

## 六、聚类分析流程（第九～十二课）

**七步流水线**：读数据 → 体检 → 标准化 → 定 K（三证合一）→ 最终聚类 → 可视化 → 解读。

```python
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, davies_bouldin_score

plt.rcParams['font.sans-serif'] = ['SimHei']       # 中文正常显示（两行照抄）
plt.rcParams['axes.unicode_minus'] = False          # 负号正常显示

# ---------- 造数据 + 体检 ----------
df = pd.DataFrame({
    '面积': [12, 15, 11, 55, 60, 58, 110, 115, 108],
    '游客量': [8, 10, 9, 40, 45, 42, 85, 90, 88],
})
print(df.shape, df.isnull().sum().sum())

# ---------- 标准化（必须在聚类之前） ----------
X_scaled = StandardScaler().fit_transform(df[['面积', '游客量']])  # 拉回均值 0、标准差 1
print(X_scaled.shape)

# ---------- 定 K：一个循环收集三把尺子 ----------
Ks = []              # K 值
inertias = []        # 簇内平方和（找肘部）
sils = []            # 轮廓系数（找峰值）
dbis = []            # DBI（找谷值）
for k in range(2, 5):
    km = KMeans(n_clusters=k, random_state=42, n_init=10)   # 参数固定才可复现
    km.fit(X_scaled)                                        # 聚类
    Ks.append(k)                                            # 收集结果
    inertias.append(km.inertia_)
    sils.append(silhouette_score(X_scaled, km.labels_))     # labels 必须同一次聚类
    dbis.append(davies_bouldin_score(X_scaled, km.labels_))
    print(k, round(km.inertia_, 2), round(sils[-1], 4), round(dbis[-1], 4))

best_k = Ks[sils.index(max(sils))]      # 程序找轮廓峰值的 K，不许手写死数字
print('轮廓系数峰值 K =', best_k)

# ---------- 最终聚类 + 解读 ----------
km = KMeans(n_clusters=best_k, random_state=42, n_init=10)  # 用定好的 K 重跑一次
km.fit(X_scaled)
df['簇标签'] = km.labels_                 # 簇号存回表里
print(df.groupby('簇标签').mean().round(2))  # 分组平均表：解读就引这里的数字

# ---------- 两张图 ----------
plt.scatter(df['面积'], df['游客量'], c=df['簇标签'], cmap='viridis')  # 按簇着色
plt.xlabel('面积')
plt.ylabel('游客量')
plt.title('公园分簇散点图')
plt.savefig('散点图.png')
plt.close()

plt.imshow(km.cluster_centers_)          # 聚类中心热力图
plt.colorbar()
plt.title('聚类中心热力图')
plt.savefig('热力图.png')
plt.close()
```

**坑清单**：不标准化直接聚类 → 大数字特征霸占距离；「选 inertia 最小的 K」是错的（K 越大必然越小）；轮廓找峰、DBI 找谷，方向别记反；`labels` 必须是**同一次聚类**的（循环残留的旧模型标签会把图和结论带沟里）；解读不引数字只是猜；改完代码必须重跑，产物才落地。

## 七、易错清单（历次批改里真实踩过的坑）

1. **注释里的数字不算数**——要验收的值必须由程序打印出来，交代码必须贴真实运行输出。
2. **存读成对**：`to_csv` 不写 `index=False`，读回来多一列行号；`describe().T` 存盘时把字段名行标签丢掉，产物对不上字段。
3. **改一处要顺着往下看**：改了赋值却漏了紧跟着的 `print`，打印的还是旧列。
4. **循环残留变量**：`labels_` 取自 for 循环最后一次（K=8）的模型，图里 8 个簇和宣布的 K=4 自相矛盾——画图前用最终 K 重新 fit 一次。
5. **fit 系列只碰训练集**：`gs.fit(X, y)` 拿全数据搜索 = 测试集泄进参数选择（实测最优 alpha 从 100 被改写成 1）。
6. **函数里往全局列表 append**：同一张审计表被登记两遍，行数翻倍。
7. **print 整列布尔当证据**：被省略号截断看不全，要打 `.all()` 之类的汇总判定。
8. **新列起名撞已有列名**：衍生列不是新建而是**整列覆盖**，形状少一列、验收点连环挂。
9. **交付物命名/位置不按要求**：存图文件名、产物目录照题面写。
10. **结论先定再找理由**：结论数字必须指回自己打印的表；指标打架时如实写分歧，取折中要给理由。
