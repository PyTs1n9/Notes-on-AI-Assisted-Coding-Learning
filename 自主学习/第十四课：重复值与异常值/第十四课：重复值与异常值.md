# 第十四课：重复值与异常值

## 【本节核心知识点】

第十三课查完"缺不缺"，这节课查另外两件脏事：有没有**重复行**（`duplicated` / `drop_duplicates`），有没有**离谱值**（IQR 四分位距法），最后按业务含义判断怎么处理。

## 【核心概念讲解】

### 0. 前情提要

第十三课给 731 天真实数据做了五步审计（`shape → dtypes → head → isnull().sum() → describe`），结论是"没有缺失"——**0 也是审计结论**，这节课沿用这个思路：先量出来，再下判断。

这节课对标任务包 A1 的后半段：审计不光要交 `data_profile`（缺不缺），还要交**重复检查**和 `outlier_candidates`（异常候选表）。所以两个新问题必须会答：

- 这张表里有没有**整行一模一样**的记录？
- 有没有跟大家**差得离谱**的数值？

### 1. 重复值 = 整行 16 个字段全都一样

**重复值**（duplicate（重复值））= 同一条记录被记了两遍。

怎么来的很常见：两张表拼在一起导出、导出时手抖贴了两遍、同一天的数据录了两次。

判断标准只有一条：**整行所有字段都完全相同**。只要有一个字段不同（哪怕日期差一天），pandas 就不算重复。

危害：多记的那份会把统计带偏——比如"平均每天租车量"被重复行拉高，后面建模也会把同一件事学两遍。

### 2. 异常值 ≠ 错误值

**异常值**（outlier（异常值/离群点））= 跟其余数据差得特别远的数。

先记住一句话：**异常 ≠ 错误**。周六租车量冲到 8000 辆是真实发生的事，不是录错了；但把 `hum`（湿度）录成 9.5（正常范围 0~1）就是错的。所以识别出来只能叫"**异常候选**"，要不要处理得按业务含义判断。

### 3. IQR 法：给"离谱"画一条线

第十三课认识了四分位数：把一列从小到大排好，`25%` 是下四分位（记 Q1），`75%` 是上四分位（记 Q3）。IQR 法就在它上面加三步：

- **IQR（interquartile range（四分位距），四分位距）= Q3 − Q1**：中间那一半数据的宽度；
- **下限 = Q1 − 1.5 × IQR**，**上限 = Q3 + 1.5 × IQR**：往两边各放宽"1.5 个 IQR"；
- 落在下限以下、上限以上的行 = **异常候选**。

`1.5` 是统计学里的经验系数（把中间大部分数据圈进去，太远的才报出来），不用深究来历——本课只需要会套。

处理方式只有三种：**保留并标注**（真实极端值）、**删掉**（确认是录错）、**当缺失处理**。这一步靠业务说话，代码只负责把候选行捞出来。

### 4. 坑：0/1 列套 IQR 会误伤

`holiday`（是否节假日）只有 0 和 1 两种取值，四分位全挤在 0 上 → `IQR = 0` → 上下限都变成 0 → 所有 `holiday = 1` 的行全被判成"异常"（真实数据里有 21 行）。这些是**正常节假日，不是异常**。所以二值列、取值极少的列别硬套 IQR，看一眼 `IQR` 是不是 0 就知道要不要换方法——这就是"按业务含义判断"。

## 【核心内置函数拆解】

### ① `df.duplicated()` — 找重复行

- **作用**：逐行判断这一行是否和它**前面**的行完全一样。
- **完整语法**：`df.duplicated()`（默认参数就够用）。
- **关键参数**：`keep='first'`（默认）——每组重复里第一行算"不是重复"，后面的才算重复；`keep=False`——每组所有行都标成重复。
- **返回值**：Series——索引是行号，值是 `True`（是重复）/`False`（不是）；配 `.sum()` 就是重复行数（`True` 当 1 加）。
- **常见坑**：只比较**整行**，有一个字段不同就不算；`'1'` 和 `1`（文本和数字）也不算相同；它只"查"不动，原表不变。
- **适用场景**：合并两张表之后；删重复之前先数一数；审计的例行检查。

### ② `df.drop_duplicates()` — 删重复行

- **作用**：删掉重复行，每组完全相同的记录只留一条。
- **完整语法**：`df.drop_duplicates()`。
- **关键参数**：`keep='first'`（默认，留每组第一条）或 `keep='last'`（留最后一条）；`subset=['列名']` 可以只按某几列判重（本课不展开）。
- **返回值**：**新的 DataFrame**，原表不动。
- **常见坑**：**写完不接变量等于白删**——`df.drop_duplicates()` 这样单独一行，删的结果没存下来，必须写 `df = df.drop_duplicates()`；另外"删完 shape 没变"不代表写错了，本来就没重复时 shape 就是不变。
- **适用场景**：审计发现重复之后；两张表 `concat` 拼接之后。

### ③ `df['列'].quantile(q)` — 取分位数

- **作用**：取该列第 q 分位的那一个数值，是算 IQR 的原料。
- **完整语法**：`df['windspeed'].quantile(0.25)`。
- **关键参数**：`q` 是 **0~1 之间的小数**——`0.25` 就是 25%，不是 25。
- **返回值**：一个数（float）。
- **常见坑**：`quantile(0.25)` 和 `describe()` 里的 `25%` 行是**同一个数**，可以互相对账；默认跳过缺失值；文本列用它没意义。
- **适用场景**：算 Q1/Q3/IQR；做箱线图之前。

### ④ `df[(条件1) | (条件2)]` — 条件筛选捞行

- **作用**：只把满足条件的行拿出来（第三、四课的条件筛选就是它，这里把两个条件拼起来）。
- **完整语法**：`df[(df['windspeed'] > 上限) | (df['windspeed'] < 下限)]`。
- **关键参数**：`|` 表示"或"、`&` 表示"且"；**每个条件都必须加括号**。
- **返回值**：满足条件的行组成的新 DataFrame（原表不变）。
- **常见坑**：不能写成 `or` / `and`——pandas 会报 `ValueError`（它不知道该按哪一列判断），只能用 `|` `&`；这种"先算出 True/False 再按行取"的写法叫**布尔索引**（boolean indexing（布尔索引））。
- **适用场景**：捞异常候选行、按条件取子表。

## 【完整代码示例 + 逐行注释】

```python
# ============ 第十四课演示：给真实单车租赁数据找"重复行"和"异常值" ============
import pandas as pd                                    # 读表、找重复、算分位数都靠它

df = pd.read_csv('day.csv', encoding='utf-8-sig')      # 真实 UCI 数据：2011-2012 两年共 731 天

# ---------- 第 1 步：找重复行（整行 16 个字段全都一样才算重复） ----------
print(df.duplicated().sum())                           # 函数①：每行给 True/False，sum 把 True 当 1 加 → 重复行数

# ---------- 第 2 步：删重复，用前后 shape 对比看删了没有 ----------
print(df.shape)                                        # 删之前
df = df.drop_duplicates()                              # 函数②：去掉重复行，每组只留第一条（结果要用变量接住）
print(df.shape)                                        # 删之后 → 两次一模一样，一行没少

# ---------- 第 3 步：用 IQR 给"风速 windspeed"算异常上下限 ----------
q1 = df['windspeed'].quantile(0.25)                    # 函数③：下四分位，就是 describe 里的 25% 那个数
q3 = df['windspeed'].quantile(0.75)                    # 函数③：上四分位，就是 describe 里的 75% 那个数
iqr = q3 - q1                                          # IQR（四分位距）= 上四分位 - 下四分位
lower = q1 - 1.5 * iqr                                 # 下限：比它还小的算异常候选
upper = q3 + 1.5 * iqr                                 # 上限：比它还大的算异常候选
print(f'Q1={q1:.4f}  Q3={q3:.4f}  IQR={iqr:.4f}  下限={lower:.4f}  上限={upper:.4f}')

# ---------- 第 4 步：按上下限把异常候选行捞出来 ----------
out = df[(df['windspeed'] < lower) | (df['windspeed'] > upper)]   # 函数④：两个条件用 | 连接，条件各自加括号
print(len(out))                                        # 异常候选行数
print(out['windspeed'])                                # 每一行的风速（左边的数字是行号）

# ---------- 第 5 步：坑演示：0/1 列套 IQR 会误伤 ----------
q1h = df['holiday'].quantile(0.25)                     # holiday（是否节假日）只有 0 和 1 两种取值
q3h = df['holiday'].quantile(0.75)
ih = q3h - q1h                                          # 四分位全挤在 0 上 → IQR = 0
outh = df[(df['holiday'] < q1h - 1.5 * ih) | (df['holiday'] > q3h + 1.5 * ih)]   # 上下限都变成 0
print(f'holiday 的 IQR={ih:.1f}，被判异常的行数={len(outh)}')   # 这些其实都是正常节假日，别急着删
```

## 【本节重点总结】

1. 重复行 = 整行完全相同：`duplicated().sum()` 先数，`df = df.drop_duplicates()` 再删，删完用 shape 对账。
2. 异常候选 = 超出 `Q1 − 1.5×IQR` ~ `Q3 + 1.5×IQR` 这条线的行；`quantile` + 条件筛选两招就够，`IQR=0` 的 0/1 列别硬套。
3. 识别 ≠ 处理：捞出来是代码的事，删还是留是业务判断——`异常 ≠ 错误`。
