# 第十七课：数据预处理：缺失值、标准化、独热编码与流水线

## 【本节核心知识点】

把数值列和类别列分别处理，再用 `Pipeline` 串成一条可复用的预处理流程；核心红线是：训练数据才能 `fit`，验证/测试数据只能 `transform`。

## 【核心概念讲解】

### 1. 为什么要做数据预处理

原始数据通常不能直接交给模型：数值列可能有缺失值，类别列是文字，数值列之间还可能量纲不同。

**数据预处理**（data preprocessing（数据预处理））就是在建模前，把原始字段变成模型可以稳定使用的数值特征。

本课分成两条支路：

- 数值列：缺失值填补，再做标准化；
- 类别列：缺失值填补，再做独热编码。

### 2. `fit` 和 `transform` 的数据流

- `fit`：从数据中学习规则，例如学习均值、标准差、类别列表；
- `transform`：使用已经学到的规则转换新数据；
- `fit_transform`：先学习规则，再立刻转换同一批训练数据。

正确顺序是：

> 训练集：`fit_transform`；测试集：`transform`

测试集不能参与 `fit`。例如，测试集的均值不能拿来填补训练流程中的缺失值，否则测试集信息提前进入了模型，这就是数据泄漏（data leakage（数据泄漏））。

### 3. 为什么要使用 `ColumnTransformer` 和 `Pipeline`

`ColumnTransformer` 允许我们指定：哪些列走数值处理，哪些列走类别处理。

`Pipeline` 允许我们把多个步骤按顺序串起来。模型训练时只需要调用一次 `fit`，预测时只需要调用一次 `predict`，预处理步骤不会被忘记，也不容易把训练集和测试集的操作顺序写乱。

### 4. 本课五个核心对象的关系

> 数值列：`SimpleImputer` → `StandardScaler`  
> 类别列：`SimpleImputer` → `OneHotEncoder`  
> 两条支路：`ColumnTransformer`  
> 完整流程：`ColumnTransformer` → `LinearRegression`  
> 统一封装：`Pipeline`

## 【核心内置函数拆解】

### ① `SimpleImputer` — 填补缺失值

- **作用**：用指定策略填补缺失值，让后续处理和模型不再遇到 `NaN`。
- **完整语法**：`SimpleImputer(strategy='mean')`。
- **关键参数**：`strategy='mean'` 用均值填补数值列；`strategy='median'` 用中位数填补；`strategy='most_frequent'` 用出现次数最多的值填补类别列；`strategy='constant'` 用固定值填补。
- **返回值**：一个缺失值处理器；调用 `fit_transform` 或 `transform` 后返回转换后的数组。
- **常见坑**：不要先用全表均值填补再划分训练集和测试集；应把填补器放进流水线，让它只在训练集上学习。
- **适用场景**：数值缺失、类别缺失，且希望保留样本而不是直接删行。

### ② `StandardScaler` — 标准化数值列

- **作用**：把数值列转换到相近的尺度，常见结果是训练数据每列均值接近 0、波动尺度接近 1。
- **完整语法**：`StandardScaler()`。
- **关键参数**：本课使用默认参数；它会在 `fit` 时学习训练集的均值和尺度。
- **返回值**：一个标准化处理器；调用转换方法后返回标准化数组。
- **常见坑**：测试集只能 `transform`，不能重新 `fit`；否则训练集和测试集使用的坐标系不同。
- **适用场景**：线性模型、KMeans、距离计算等对特征尺度敏感的任务。

### ③ `OneHotEncoder` — 把类别变成 0/1 特征

- **作用**：把一个类别列拆成多个 0/1 列，例如天气列变成天气晴、天气阴、天气雨等列。
- **完整语法**：`OneHotEncoder(handle_unknown='ignore', sparse_output=False)`。
- **关键参数**：`handle_unknown='ignore'` 遇到训练集没见过的新类别时不报错；`sparse_output=False` 返回普通数组，便于初学阶段查看结果。
- **返回值**：一个类别编码器；转换后返回独热编码数组。
- **常见坑**：测试集可能出现训练集没见过的类别，所以实战中通常设置 `handle_unknown='ignore'`。
- **适用场景**：线性回归、逻辑回归、树模型前的类别字段数值化。

### ④ `ColumnTransformer` — 分列调用不同处理流程

- **作用**：让数值列和类别列分别走不同的预处理器，再把结果横向拼接。
- **完整语法**：`ColumnTransformer([('名称', 处理器, 列名列表)])`。
- **关键参数**：每个三元组依次写处理名称、处理器和要处理的列；`remainder='drop'` 丢弃没有列入流程的字段。
- **返回值**：一个列转换器；转换后返回拼接好的特征数组。
- **常见坑**：列名必须和输入表一致；同一列不要同时放进两个互相冲突的处理分支。
- **适用场景**：一张表里同时有数值列和类别列时。

### ⑤ `Pipeline` — 串联预处理和模型

- **作用**：把预处理器和模型连接成一个整体，统一执行训练、转换和预测。
- **完整语法**：`Pipeline([('步骤名', 对象), ('模型名', 模型)])`。
- **关键参数**：步骤按列表顺序执行；最后一个步骤通常是模型；步骤名用于定位和调参。
- **返回值**：一个流水线对象；可以像模型一样调用 `fit`、`predict`。
- **常见坑**：不要在流水线外先用全数据拟合预处理器；不要把测试集单独 `fit_transform`。
- **适用场景**：希望让预处理、交叉验证、模型训练保持一致时。

### ⑥ `ColumnTransformer.get_feature_names_out()` — 查看处理后的列名

- **作用**：查看数值处理和独热编码后最终生成的特征名称。
- **完整语法**：`preprocessor.get_feature_names_out()`。
- **关键参数**：本课不传参数；前提是列转换器已经完成 `fit`。
- **返回值**：包含处理器名称和最终特征名的数组。
- **常见坑**：必须先 `fit`；如果只创建对象还没有学习类别列表，就不能直接取输出列名。
- **适用场景**：检查特征数量、解释模型输入、排查列顺序问题。

## 【完整代码示例 + 逐行注释】

```python
import numpy as np  # 导入 numpy，用明确的 NaN 表示缺失值
import pandas as pd  # 导入 pandas，用表格保存原始数据
from sklearn.compose import ColumnTransformer  # 函数④：让不同列走不同处理流程
from sklearn.impute import SimpleImputer  # 函数①：填补缺失值
from sklearn.linear_model import LinearRegression  # 导入线性回归模型
from sklearn.model_selection import train_test_split  # 函数⑦：划分训练集和测试集
from sklearn.pipeline import Pipeline  # 函数⑤：串联预处理步骤和模型
from sklearn.preprocessing import OneHotEncoder  # 函数③：类别列独热编码
from sklearn.preprocessing import StandardScaler  # 函数②：数值列标准化

# 创建一张同时包含数值列、类别列和缺失值的小表
raw_df = pd.DataFrame({
    '面积': [50.0, 60.0, None, 80.0, 90.0, 100.0, 110.0, 120.0],
    '楼层': [2.0, 5.0, 3.0, None, 8.0, 10.0, 12.0, 15.0],
    '区域': ['东区', '西区', '东区', '南区', np.nan, '西区', '北区', '东区'],
    '租金': [3.0, 3.8, 3.5, 4.5, 5.0, 5.8, 6.2, 7.0]
})

# 划分特征和标签，租金是要预测的标签
X = raw_df.drop(columns=['租金'])
y = raw_df['租金']

# 准备训练集和测试集，固定随机种子保证结果可复现
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)

# 指定数值列和类别列
numeric_features = ['面积', '楼层']
categorical_features = ['区域']

# 创建数值列处理流程：中位数填补后标准化
numeric_pipeline = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', StandardScaler())
])

# 创建类别列处理流程：众数填补后独热编码
categorical_pipeline = Pipeline([
    ('imputer', SimpleImputer(strategy='most_frequent')),
    ('encoder', OneHotEncoder(handle_unknown='ignore', sparse_output=False))
])

# 创建分列处理器，把两条支路的结果拼在一起
preprocessor = ColumnTransformer([
    ('numeric', numeric_pipeline, numeric_features),
    ('category', categorical_pipeline, categorical_features)
])

# 创建完整流水线：先预处理，再训练线性回归模型
model_pipeline = Pipeline([
    ('preprocessor', preprocessor),
    ('model', LinearRegression())
])

# 函数⑧：只让流水线在训练集上学习缺失值规则、标准化规则和类别列表
model_pipeline.fit(X_train, y_train)

# 函数⑨：使用训练集学到的规则转换测试数据并完成预测
predictions = model_pipeline.predict(X_test)

# 取出已经拟合的列转换器
fitted_preprocessor = model_pipeline.named_steps['preprocessor']

# 函数⑩：查看预处理后最终生成的特征名称
feature_names = fitted_preprocessor.get_feature_names_out()

# 函数⑪：单独查看测试集经过预处理后的二维数组
transformed_test = fitted_preprocessor.transform(X_test)

# 打印原始表、切分结果和预处理结果的关键信息
print('raw shape:', raw_df.shape)
print('train shape:', X_train.shape)
print('test shape:', X_test.shape)
print('transformed test shape:', transformed_test.shape)
print('feature names:', list(feature_names))
print('predictions:', [round(value, 4) for value in predictions])
print('test score:', round(model_pipeline.score(X_test, y_test), 4))
```

## 【本节重点总结】

1. 数值列通常走“填补缺失值 → 标准化”，类别列通常走“填补缺失值 → 独热编码”。
2. `ColumnTransformer` 负责分列，`Pipeline` 负责串联；两者组合后能把预处理和模型统一管理。
3. 所有会学习数据规则的 `fit` 都只对训练集执行，测试集只能使用已经学好的规则进行 `transform`。
