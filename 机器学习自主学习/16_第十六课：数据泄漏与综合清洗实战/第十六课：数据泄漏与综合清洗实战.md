# 第十六课：数据泄漏与综合清洗实战

## 【本节核心知识点】

特征里混进"答案本身"，模型不用学就能答对——用**恒等关系**（`.all()`）和**相关系数**（`df.corr()`）把泄漏列找出来删掉，再把「审计 → 重复 → 异常 → 类型 → 泄漏剔除 → 落盘」整条流水线一次跑通，产出 4 个清洗文件。

## 【核心概念讲解】

### 0. 前情提要

第十三课查缺失、第十四课查重复和异常、第十五课把表改造成 `X` 和 `y`。三关都过了，但还有一件更隐蔽的事没查：**特征里有没有混进"答案本身"**。这节课是数据清洗线的收尾，把前三课的东西串成一条完整流水线，对标任务包 A1 的收尾和 A2 的入口。

### 1. 数据泄漏：把答案抄给模型

**数据泄漏**（data leakage（数据泄漏））= 把标签的信息、或标签算出来的中间结果放进特征，模型不用学规律就能"答对"。

本数据里现成的例子：`cnt = casual + registered` **全表成立**——`casual`（临时用户租车量）加 `registered`（注册用户租车量）正好就是 `cnt`（总租车量）。把这两列放进特征，模型只要做加法就满分。

两个后果：

- **上线就崩**：真实场景要预测"明天多少人租"，而 `casual`/`registered` 是**当天结束后才统计出来的**，预测那一刻根本拿不到；
- **评估是假的**：离线分数再高也没用，因为模型学的不是"天气/季节影响租车"，而是"把两列加起来"。

**泄漏列 ≠ 标签列**：`cnt` 是要预测的**标签**，必须留；`casual`/`registered` 是**答案的成分**，必须删。这一字之差是本课最容易搞混的地方。

### 2. 两把尺子找泄漏

- **恒等关系**：某几列加加减减正好等于标签 → 用 `.all()` 验证"是不是每一行都成立"；
- **相关系数**：和标签特别像的列（接近 1）要重点怀疑 → 用 `df.corr()` 一屏看完。

两把尺子要一起用：相关高 ≠ 一定泄漏（`temp` 影响租车是真规律），相关不极高 ≠ 没泄漏（几列**组合**起来才等于标签的，单看可能不高）。**最后还得过一遍业务**：这个字段在"预测那一刻"拿得到吗？

### 3. 综合清洗流水线

读数据 → 审计（缺失/重复/类型）→ 删重 → 算异常候选 → 特征类型准备 → **剔除泄漏列** → 落盘产物。前三步分别是第十三、十四、十五课的内容，本课只新增"剔除泄漏列"这一环，但要**自己把整条线跑一遍**。

## 【核心内置函数拆解】

### ① `df.corr(numeric_only=True)` — 相关系数矩阵

- **作用**：算数值列两两之间的**相关系数**（correlation（相关系数），取值 -1 ~ 1，越接近 ±1 两列变化越"同步"），形成一张方阵表。
- **完整语法**：`df.corr(numeric_only=True)`。
- **关键参数**：`numeric_only=True` 只让数值列参与——文本列 `dteday` 自动被排除；不同版本默认行为有差异，**写上更稳**。
- **返回值**：**新的 DataFrame**，行名和列名都是数值列名，交叉格 = 这两列的相关系数。
- **常见坑**：**对角线永远是 1**（列和自己比）；`instant` 这种行号列也会算出数字，但没意义；**相关 ≠ 因果**。
- **适用场景**：找和标签最像的列（泄漏候选）；特征初筛。

### ② `布尔序列.all()` / `.any()` — 整列断言

- **作用**：把一整列 `True/False` 收缩成**一个**值：`all()` = 是不是全都成立；`any()` = 是不是至少有一个成立。
- **完整语法**：`same.all()`、`same.any()`。
- **关键参数**：没有。
- **返回值**：Python 的 `True` / `False`（单个值，不是序列）。
- **常见坑**：**别直接 `print(整列布尔)` 当证据**——列一长就被 `...` 截断，只看得到首尾（这是 A1 批改里栽过的坑）；要打就先 `.all()` 再打。
- **适用场景**：验证恒等关系/约束是否全表成立；`df.isnull().any()` 查"有没有哪列缺数据"。

### ③ `pd.concat([表1, 表2], ignore_index=True)` — 多表按行拼

- **作用**：把多张表**竖着**（一行接一行）拼成一张。
- **完整语法**：`pd.concat([hour候选, day候选], ignore_index=True)`。
- **关键参数**：`ignore_index=True` 重排行索引（不写的话索引会重复 0, 1, 2…）；`axis=0` 是默认值，不用写。
- **返回值**：**新的 DataFrame**。
- **常见坑**：**两张表列名不完全一样时，缺的列会补成 `NaN`**（`hour` 多一列 `hr`，`day` 的行在 `hr` 上就是空的）——这是拼表的正常行为，不是 bug；不接变量等于白拼。
- **适用场景**：多张审计表/候选表合并落盘；分批读入的数据合起来。

### ④ `df.to_csv(路径, index=False, encoding='utf-8-sig')` — 表存成 CSV

- **作用**：把表写成 CSV 文件，本课一次落 4 个产物。
- **完整语法**：`df.to_csv('hour_clean.csv', index=False, encoding='utf-8-sig')`。
- **关键参数**：`index=False` 不存行号；`encoding='utf-8-sig'` 让 Excel 打开中文列名不乱码。
- **返回值**：`None`（它写文件，不返回表）。
- **常见坑**：**存读成对**——`index=False` 存的，读回来就别加 `index_col=0`；同名文件**直接覆盖**，跑之前想清楚文件名。
- **适用场景**：审计表、清洗结果、候选清单落盘。

## 【完整代码示例 + 逐行注释】

```python
# ============ 第十六课演示：给租赁数据做"泄漏体检" ============
import pandas as pd                                    # 读表、算相关系数、删列都靠它

df = pd.read_csv('ride_feat.csv', encoding='utf-8-sig')   # 第十五课的练习数据：400 行 × 16 列

# ---------- 第 1 步：泄漏体检——标签是不是被"加"出来的 ----------
same = df['cnt'] == df['casual'] + df['registered']    # 每行比一次：cnt 等不等于两个分项之和
print(same.all())                                      # 函数②：整列是不是全 True
print(int(same.sum()))                                 # 有几行成立（400 = 每一行都成立）

# ---------- 第 2 步：相关系数——谁和标签最像 ----------
corr = df.corr(numeric_only=True)['cnt']               # 函数①：数值列两两相关，只取 cnt 这一列
print(corr.sort_values(ascending=False).head(5))       # 从大到小排，看和 cnt 最像的前 5 名

# ---------- 第 3 步：把"答案的成分"从特征里删掉 ----------
X = df.drop(columns=['cnt', 'casual', 'registered', 'instant', 'dteday'])  # 复习（第十五课函数⑤）
print(X.shape)                                         # 特征表尺寸：行不变，列变少
```

**真实运行结果**（`.venv` 实测）：

```text

registered    0.880530
casual        0.663166
atemp         0.443404
temp          0.430542
Name: cnt, dtype: float64
(400, 11)
```

> 怎么读：第 1 步 `True` 说明**每一行**都满足 `cnt = casual + registered`，`400` 是成立的行数（= 全表行数）——泄漏坐实。第 2 步是相关系数从大到小的前 5 名：第一行 `cnt 1.000000` 是它自己（对角线永远是 1），紧接着 `registered 0.880530`、`casual 0.663166` 就是泄漏的那两列——和标签像到这个程度，不是因为它们"预测"了租车量，而是它们**就是**租车量的一部分。第 3 步把 `cnt`（标签）和 `casual`/`registered`（答案成分）连同 `instant`（行号）、`dteday`（文本日期）一起删掉，行数不变、列数变少，剩下的才是真正能拿去建模的特征。

### 验收结论

当前 `test.py` 能运行，但本轮不通过。已用 `BaiQing3.10AI` 和课程 `.venv` 分别实跑，原代码的主要问题是：

- 缺少缺失值总数统计；
- 没有生成 `data_profile.csv`；
- 没有生成 `outlier_candidates.csv`；
- 使用 `drop_duplicates('windspeed')` 删除了相同风速值的正常行，导致清洗结果错误为 `hour (30, 13)`、`day (650, 12)`；本题只能删除整行完全重复数据，IQR 筛选不能先按 `windspeed` 去重。

### 正确答案

下面代码已按本课 9 步要求整理，并已在两个环境实跑通过。它会生成 `hour_clean.csv`、`day_clean.csv`、`data_profile.csv`、`outlier_candidates.csv` 四个文件。

```python
import pandas as pd  # 导入 pandas，用于读表、清洗和保存 CSV

# 保存两张表的审计结果，最后写入 data_profile.csv
profile_rows = []  # 创建列表，保存 hour 和 day 各自的一行审计结果

# 保存两张表的异常候选行，最后写入 outlier_candidates.csv
outlier_frames = []  # 创建列表，保存两张表的异常候选行

# 依次处理 hour.csv 和 day.csv
for file_name in ['hour.csv', 'day.csv']:
    # 读取当前 CSV 文件
    df = pd.read_csv(file_name, encoding='utf-8-sig')

    # 从文件名中取出 hour 或 day，作为产物中的文件标识
    source_name = file_name.split('.')[0]

    # 记录原始表的行数和列数
    original_rows = df.shape[0]
    original_columns = df.shape[1]

    # 统计整张表的缺失值总数
    missing_total = int(df.isnull().sum().sum())

    # 统计重复行数量
    duplicate_rows = int(df.duplicated().sum())

    # 删除完全重复的行
    df = df.drop_duplicates()

    # 验证 cnt 是否等于 casual 加 registered
    leakage_same = df['cnt'] == df['casual'] + df['registered']

    # 统计泄漏恒等关系成立的行数
    leakage_rows = int(leakage_same.sum())

    # 计算数值列的相关系数矩阵，并取出 cnt 这一列
    corr = df.corr(numeric_only=True)['cnt']

    # 打印本表的关键验收结果
    print(f'{source_name} shape:', (original_rows, original_columns))
    print(f'{source_name} missing:', missing_total)
    print(f'{source_name} duplicates:', duplicate_rows)
    print(f'{source_name} leakage rows:', leakage_rows)
    print(f'{source_name} casual corr:', round(corr['casual'], 6))
    print(f'{source_name} registered corr:', round(corr['registered'], 6))

    # 计算 windspeed 的第一四分位数
    q1 = df['windspeed'].quantile(0.25)

    # 计算 windspeed 的第三四分位数
    q3 = df['windspeed'].quantile(0.75)

    # 计算四分位距
    iqr = q3 - q1

    # 计算 IQR 下界
    lower = q1 - 1.5 * iqr

    # 计算 IQR 上界
    upper = q3 + 1.5 * iqr

    # 筛选 windspeed 的异常候选行
    outlier_df = df[(df['windspeed'] < lower) | (df['windspeed'] > upper)].copy()

    # 添加候选行的来源文件列
    outlier_df['源文件'] = source_name

    # 保存当前表的候选行，后面统一拼接
    outlier_frames.append(outlier_df)

    # 删除行号列、日期列和泄漏列，但保留 cnt 标签列
    clean_df = df.drop(columns=['instant', 'dteday', 'casual', 'registered'])

    # 打印清洗后的表形状
    print(f'{source_name}_clean shape:', clean_df.shape)

    # 保存当前表的清洗结果，不保存 pandas 行索引
    clean_df.to_csv(f'{source_name}_clean.csv', index=False, encoding='utf-8-sig')

    # 保存当前表的一行审计结果
    profile_rows.append({
        '文件': source_name,
        '行数': original_rows,
        '列数': original_columns,
        '缺失总数': missing_total,
        '重复行数': duplicate_rows,
        '泄漏成立行数': leakage_rows
    })

# 把 hour 和 day 的审计结果组成两行表
profile_df = pd.DataFrame(profile_rows)

# 保存审计汇总表，不保存 pandas 行索引
profile_df.to_csv('data_profile.csv', index=False, encoding='utf-8-sig')

# 把两张表的异常候选行按行拼接
outlier_candidates = pd.concat(outlier_frames, ignore_index=True)

# 保存异常候选行汇总表，不保存 pandas 行索引
outlier_candidates.to_csv('outlier_candidates.csv', index=False, encoding='utf-8-sig')

# 打印两个汇总产物的形状，便于验收
print('data_profile shape:', profile_df.shape)
print('outlier_candidates rows:', outlier_candidates.shape[0])
print('outlier source counts:')
print(outlier_candidates['源文件'].value_counts().sort_index())

# 业务结论：casual 和 registered 是 cnt 的组成部分，预测时不能作为可用特征
print('结论：casual 和 registered 是 cnt 的组成部分，预测时不能作为特征。')
```
