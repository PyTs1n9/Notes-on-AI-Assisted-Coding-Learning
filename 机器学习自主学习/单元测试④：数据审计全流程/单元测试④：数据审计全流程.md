## 【知识速览】函数速查表

| 函数/属性 | 作用 | 记忆点 / 坑 |
|---|---|---|
| `shape` | 查看行列尺寸 | 属性，不加括号 |
| `dtypes` | 查看各列类型 | 文本列在 pandas 2.x/3.x 的显示可能不同 |
| `head`、`describe` | 查看样例与数值摘要 | `count` 是非缺失数量；宽表可能折叠显示 |
| `isnull`、`sum` | 统计缺失 | 连续聚合层数决定逐列或总数 |
| `duplicated`、`drop_duplicates` | 查找/移除整行重复 | 删除结果要接回变量；重复判断默认看整行 |
| `quantile` | 计算分位数 | 分位参数使用 0 到 1 的小数 |
| `to_datetime`、`.dt` | 日期转换与提取成分 | 先转换，再使用日期访问器 |
| `astype`、`get_dummies` | 类型转换、类别编码 | 返回结果要赋回；新列别覆盖已有列 |
| `drop` | 删除指定列 | 返回新表；检查标签与泄漏列是否删错 |
| `corr` | 计算相关系数矩阵 | 高相关只是线索，不等于泄漏 |
| `all`、`any` | 汇总布尔条件 | `all` 检查是否全部成立，避免打印长布尔列 |
| `concat`、`to_csv` | 合并表、写 CSV | 核对列对齐；`index=False` 不保存行号 |

## 【我的作答】

### 一、概念题

1. 针对咧和某个具体的值通过shape或者列表核对
2. 一整行存在重复的值，会删除多余有用的元素
3. 通过限定上限和下限，主要是取一个范围
4. 日期文本是字符串，直接用日期访问器提取会无法计数
5. 模型直接有显式公式关系，casual+registered=total，casual和registered不能用

### 二、函数题

1. 形状返回一个元组，分别是行列，列类型返回一个series，分别是column和对应的dtype，逐列缺失统计返回series，分别是列名和缺失数量
2. 一个是统计数量，一个是删除重复
3. 日期转换是把字符串日期转化成数字，可以进行训练；日期访问器是把一串日期变成单独的一列特征；独热编码是给字符串列编号
4. 能反映数据是否泄露，体现出数据的相关性

### 三、纠错题

1. df.drio_duplicates()返回的是新数组
2. 不能直接把为1的删除，而是应该要分上下界限，越界的先判断再删除
3. 文本无法放入特征列进行模型训练
4. 相关系数矩阵是提供参考，关系高不一定一定是数据泄露了

### 四、代码题

#### 题目1

```python
import pandas as pd

df = pd.read_csv('clinic.csv', encoding='utf-8-sig')

print(df.shape)
print(df.dtypes)
print(df.head())
print(df.isnull().sum())
print(df.isnull().sum().sum())
print(df.duplicated().sum())
df = df.drop_duplicates()
print(df.shape)

q1 = df['temperature'].quantile(0.25)
q3 = df['temperature'].quantile(0.75)
iqr = q3 - q1
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr
print(f'lower {lower:.2f}')
print(f'upper {upper:.2f}')
```

#### 一、概念题完整参考答案

1. 缺失统计回答“这一列有多少个空值”；`describe` 的 `count` 回答“这一列有多少个非缺失值”。对同一张表的同一列，总行数减去缺失数应等于非缺失数；核对时必须使用相同的删重前后口径。
2. 整行重复指两条或多条记录的全部对应字段相同。仅某列相同不代表同一条记录，例如两名患者温度相同而就诊编号不同，不能因为温度相同就删掉一人。
3. Q1、Q3 分别是第一、第三四分位数；IQR 是 Q3 减 Q1。下界为 Q1 减 1.5 倍 IQR，上界为 Q3 加 1.5 倍 IQR；低于下界或高于上界的记录只是异常候选。真实极端情况也可能越界，必须结合原始记录和业务含义判断。
4. 普通字符串列没有 pandas 日期访问器可用的日期结构，先转换为 datetime，再取年月或星期。季节等类别代码只是名称代号，不能自动解释成大小或倍数；独热编码用各类别的指示列表达类别。
5. 数据泄漏是特征带入了不应在预测时使用的标签信息或其他不可用信息。共享单车中 `cnt = casual + registered`，若提前预测当天总量，两项事后统计分项不可作为输入；标签要单独留作 y，不能混入 X。

#### 二、函数题完整参考答案

1. `shape` 返回行列数元组；`dtypes` 返回按列名索引、以类型为值的 Series；逐列缺失统计返回按列名索引、以缺失数为值的 Series。`shape` 是属性，不加括号。
2. 重复统计只标记或计数，不改原表；删重返回删除重复记录后的新 DataFrame。默认操作不原地修改，应把新表赋回原变量或另取名称保存。
3. `to_datetime` 把日期文本转为 datetime，`.dt` 从日期列提取年月星期等数值特征；`get_dummies` 把类别列拆为多个指示列。日期支路先转日期、再提取日期特征；类别支路按题目先转文本、再独热编码。两个支路互不依赖，没有必要规定它们之间的绝对顺序。
4. 相关矩阵提供数值列两两线性相关程度，可帮助发现需进一步审查的字段，不能单独证明泄漏或因果。恒等关系先逐行产生布尔值，用 `all` 判断是否全部成立，用 `sum` 统计成立行数；仍需核对预测时点是否可用。

#### 三、纠错题完整参考答案

1. `drop_duplicates` 默认返回新 DataFrame，单独调用不改变后续使用的原变量。正确做法是用原变量接住返回值，或使用另一个变量保存新表；完整代码的题1已给出对应赋值行。
2. 二值列的四分位数可能都挤在 0，IQR 为零，合法的 1 也会越界；不能据此删除合法类别。应按该字段的允许类别和业务规则校验，而不是机械套连续值的 IQR。
3. 第一处错是文本未先转 datetime 就用 `.dt`；第二处错是新列名与旧列重复，会覆盖旧列。正确流程是先转日期，再用未占用的列名保存星期，同时检查打印行也指向新列。
4. 高相关不等于泄漏；应联合恒等关系、业务定义及预测时点可用性判断。清洗后的数据集保留目标列，建模时把它单独取为 y，并从 X 中排除；泄漏分项从 X 中剔除。

import pandas as pd  # 导入 pandas，完成日期、编码与泄漏审查
