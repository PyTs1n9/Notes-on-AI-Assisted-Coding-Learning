# 第十八课：聚类综合训练

## 【本节核心知识点】

用清洗后的 day 级真实共享单车数据，独立串起特征准备、训练集标准化、K 值比较、KMeans 聚类、指标评价、可视化和簇解释；所有会“学习数据”的步骤只在训练集拟合。

## 【核心概念讲解】

### 1. 本课要完成的完整任务

前面几课把聚类流程拆开练过：第九课训练 KMeans，第十课用肘部法则看 inertia，第十一课比较轮廓系数和 DBI，第十二课制作聚类图并解释各簇。本课把这些步骤合成一个独立任务，数据采用第十六课产出的真实日级清洗数据 `day_clean.csv`。

本课的目标不是预测 `cnt`，而是根据每天的天气、日期类别等特征，把相似的日子分到同一簇，再比较不同簇的平均租车量和天气特征。`cnt` 是结果分析字段，不放入聚类特征，避免用结果本身参与分组后再声称该组有某种租车表现。

### 2. 为什么先切分、再标准化

聚类没有传统监督学习中的标签 y，但标准化器仍会从数据中学习每列的均值和标准差。若先用全表拟合标准化器，再划分训练集和测试集，测试集的分布信息已经参与了学习。

因此本课将数据划为训练部分和测试部分：只用训练部分拟合 `StandardScaler`，再用同一个 scaler 转换两部分。这里的测试部分用于观察聚类分配与结果稳定性，不用于重新拟合 scaler 或选择参数。这个做法是数据卫生约束；由于聚类没有 y，不能把后面的平均 `cnt` 当作监督学习测试分数。

### 3. 类别数字列与数值列的区别

`season`、`mnth`、`weekday`、`weathersit` 等字段虽然在 CSV 中是数字，但数字可能只是类别代码。例如 weekday 的 6 不一定代表比 1 高六倍。因此本课把这些字段当作类别特征，用 `OneHotEncoder` 转成 0/1 列；温度、湿度、风速等连续量保留为数值特征并标准化。

聚类时，两类特征最后都成为数字列。独热列也进入 KMeans 的欧氏距离计算，所以它们会影响分组；这是一种明确的建模选择，不代表类别代码本身有大小关系。

### 4. 怎么比较 K

对候选 K 逐一训练 KMeans，并记录：

- `inertia_`：越小表示簇内更紧，但 K 增大时通常会下降，要看肘部而非只取最小值。
- 轮廓系数：越大通常越好，表示簇内紧、簇间分。
- DBI：越小通常越好。

三种指标可能不完全一致。先把各自最优 K 和肘部候选并排列出，再根据曲线变化和业务可解释性选最终 K；结论必须来自自己程序打印的数据，不预先写死。

### 5. 分簇后的解释

训练最终 KMeans 后，把每一天的簇编号加回对应数据行，按簇计算原始字段的平均值。聚类中心是标准化和独热编码后的坐标，适合检查算法形成的中心；业务画像表则回到原始字段单位，适合说明“这一簇的平均温度、湿度、租车量如何”。簇号只是任意编号，不自带高低、好坏含义。

## 【核心内置函数拆解】

### ① `train_test_split` — 划分数据

- **作用**：把样本划分成训练部分和测试部分。
- **完整语法**：`train_test_split(X, test_size=0.25, random_state=21)`。
- **关键参数**：`X` 是待划分数据；`test_size` 指测试部分比例；`random_state` 固定随机划分。
- **返回值**：按输入顺序返回 `X_train, X_test`；输入多组数组时按同一行关系一起切分。
- **常见坑**：不能把标签或分析字段误放进特征；划分后不要再用测试部分拟合 scaler。
- **适用场景**：希望留出一部分未参与拟合的数据，检查处理流程在新数据上的表现。

### ② `OneHotEncoder` — 类别独热编码

- **作用**：将类别拆成若干 0/1 特征列。
- **完整语法**：`OneHotEncoder(handle_unknown='ignore', sparse_output=False)`。
- **关键参数**：`handle_unknown='ignore'` 允许转换时出现训练阶段未见类别；`sparse_output=False` 返回普通密集数组，便于查看和与本课流程衔接。
- **返回值**：编码器对象；转换后得到编码矩阵。
- **常见坑**：先在训练数据上学习类别，再用同一编码器转换测试数据；不能分别在两部分拟合，否则列含义可能不一致。
- **适用场景**：类别字段需要进入 KMeans 等数值算法时。

### ③ `ColumnTransformer` — 按列分配处理流程

- **作用**：给数值列与类别列指定不同处理方式，并拼接输出。
- **完整语法**：`ColumnTransformer([('名称', 处理器, 列名列表)], remainder='drop')`。
- **关键参数**：每项依次是步骤名称、处理器、输入列；`remainder='drop'` 不处理未列出的字段。
- **返回值**：列转换器对象；转换后输出新的数值特征矩阵。
- **常见坑**：列名应来自特征表；`cnt` 等分析字段应排除，不要遗漏后意外进入距离计算。
- **适用场景**：一张表中连续数值列与类别列需要不同处理时。

### ④ `StandardScaler` — 数值标准化

- **作用**：按训练数据的均值和尺度转换数值列，避免不同量纲直接主导距离。
- **完整语法**：`StandardScaler()`。
- **关键参数**：本课使用默认设置；`fit` 学习统计量，`transform` 使用已学统计量转换。
- **返回值**：标准化器对象；转换后返回数值矩阵。
- **常见坑**：只对训练数据 `fit`；测试数据必须调用同一个对象的 `transform`。
- **适用场景**：KMeans 等基于距离的算法，或对尺度敏感的模型。

### ⑤ `KMeans` — 执行聚类

- **作用**：把样本分成指定数量的簇，并学习每簇中心。
- **完整语法**：`KMeans(n_clusters=4, random_state=21, n_init=10)`。
- **关键参数**：`n_clusters` 指簇数；`random_state` 固定随机过程；`n_init` 指不同初始化的运行次数。
- **返回值**：KMeans 模型对象；拟合后可读取 `labels_`、`cluster_centers_`、`inertia_`。
- **常见坑**：必须在已经预处理好的训练矩阵上拟合；测试集只调用模型的 `predict` 分配簇，不对测试集重新拟合。
- **适用场景**：已决定候选簇数，需要给样本分配簇标签时。

### ⑥ `silhouette_score` — 计算轮廓系数

- **作用**：从簇内紧密和簇间分离角度评价聚类。
- **完整语法**：`silhouette_score(X, labels)`。
- **关键参数**：`X` 是样本特征矩阵；`labels` 是同一批样本对应的簇编号。
- **返回值**：一个整体轮廓系数，通常越大越好。
- **常见坑**：X 与 labels 必须来自同一批样本、同一个候选模型；每个样本一个标签。
- **适用场景**：比较不同 K 的整体分离效果。

### ⑦ `davies_bouldin_score` — 计算 DBI

- **作用**：评价簇内散开程度相对簇间距离的情况。
- **完整语法**：`davies_bouldin_score(X, labels)`。
- **关键参数**：`X` 是样本特征矩阵；`labels` 是对应簇编号。
- **返回值**：DBI 数值，通常越小越好。
- **常见坑**：找最优 K 时必须找 DBI 的最小值，再用该位置映射回 K；不能复用 silhouette 的结果变量。
- **适用场景**：与轮廓系数、肘部法则并列比较候选 K。

### ⑧ `groupby` 与 `mean` — 生成簇画像

- **作用**：按簇分组，并计算各组字段的平均值。
- **完整语法**：`df.groupby('簇标签')[列名列表].mean()`。
- **关键参数**：`groupby` 中填写簇标签列；选取要解释的原始数值列。
- **返回值**：以簇标签为索引的分组统计表。
- **常见坑**：只对原始字段做业务解释；若把簇标签或独热编码列混入均值表，会让解释失真。
- **适用场景**：用实际单位描述各簇差异并形成可核查的业务结论。

### ⑨ `plt.scatter` 与 `plt.imshow` — 展示聚类

- **作用**：散点图展示两个字段下的样本分布；热力图展示簇中心矩阵的相对高低。
- **完整语法**：`plt.scatter(x, y, c=labels)`；`plt.imshow(matrix)`。
- **关键参数**：散点图的 `c` 可传簇标签；热力图矩阵的行通常是簇，列通常是特征。
- **返回值**：绘图对象；图形通过 `savefig` 保存。
- **常见坑**：二维散点图只是高维数据的一个投影；KMeans 中心若来自标准化后的独热特征空间，必须标明坐标对应的处理后特征，不可冒充原始单位。
- **适用场景**：直观展示簇分布与中心特征。

## 【完整代码示例 + 逐行注释】

> 本示例使用第十六课产出的 `day_clean.csv`。将该文件复制到本课文件夹再运行；代码先切分，再让预处理器只在训练数据上拟合。

```python
import pandas as pd  # 导入 pandas，用于读表和整理结果
import matplotlib.pyplot as plt  # 导入绘图库
from sklearn.cluster import KMeans  # 导入 KMeans 聚类模型
from sklearn.compose import ColumnTransformer  # 函数③：按列选择处理流程
from sklearn.model_selection import train_test_split  # 函数①：划分训练数据和测试数据
from sklearn.preprocessing import OneHotEncoder, StandardScaler  # 函数②/④：类别编码与数值标准化
from sklearn.metrics import silhouette_score, davies_bouldin_score  # 函数⑥/⑦：聚类评价

# 读取第十六课清洗后的日级数据
raw_df = pd.read_csv('day_clean.csv', encoding='utf-8-sig')  # 读取 CSV，正确处理 UTF-8 BOM

# 定义类别代码列，避免把类别编号当成连续大小
categorical_features = ['season', 'yr', 'mnth', 'holiday', 'weekday', 'workingday', 'weathersit']  # 列出类别字段

# 定义连续数值列
numeric_features = ['temp', 'atemp', 'hum', 'windspeed']  # 列出连续数值字段

# 只用这些字段做聚类，不把 cnt 等结果字段放入特征
feature_columns = numeric_features + categorical_features  # 合并特征字段名
X = raw_df[feature_columns]  # 从原表取出聚类特征

# 划分训练部分与留出部分
X_train, X_test = train_test_split(X, test_size=0.25, random_state=21)  # 函数①：固定划分结果

# 创建分列预处理器：数值列标准化，类别列独热编码
preprocessor = ColumnTransformer([  # 函数③：建立两类特征处理规则
    ('numeric', StandardScaler(), numeric_features),  # 函数④：数值列按训练集统计量标准化
    ('category', OneHotEncoder(handle_unknown='ignore', sparse_output=False), categorical_features)  # 函数②：类别列编码
])  # 结束列转换器定义

# 只在训练数据上学习均值、尺度和类别集合
X_train_ready = preprocessor.fit_transform(X_train)  # 函数③：训练集 fit 并转换

# 使用训练集学到的规则转换留出数据
X_test_ready = preprocessor.transform(X_test)  # 函数③：测试集只 transform

# 准备候选簇数与评价结果列表
Ks = list(range(2, 9))  # 创建 K=2 到 K=8 的候选值
inertias = []  # 保存每个 K 的 inertia
silhouettes = []  # 保存每个 K 的轮廓系数
dbis = []  # 保存每个 K 的 DBI

# 逐个候选 K 拟合模型并记录训练集指标
for k in Ks:  # 依次检查候选簇数
    km = KMeans(n_clusters=k, random_state=21, n_init=10)  # 函数⑤：创建当前 K 的模型
    km.fit(X_train_ready)  # 函数⑤：只在训练特征上拟合
    inertias.append(km.inertia_)  # 保存簇内距离平方和
    silhouettes.append(silhouette_score(X_train_ready, km.labels_))  # 函数⑥：计算训练集轮廓系数
    dbis.append(davies_bouldin_score(X_train_ready, km.labels_))  # 函数⑦：计算训练集 DBI
    print(f'K={k}, inertia={km.inertia_:.2f}, silhouette={silhouettes[-1]:.4f}, DBI={dbis[-1]:.4f}')  # 打印当前 K 的实测指标

# 根据各指标从实测列表中寻找候选最优 K
best_sil_k = Ks[silhouettes.index(max(silhouettes))]  # 轮廓系数取最大值对应 K
best_dbi_k = Ks[dbis.index(min(dbis))]  # DBI 取最小值对应 K

# 打印两个指标各自选出的 K，保留冲突信息
print('silhouette best K:', best_sil_k)  # 输出轮廓系数峰值 K
print('DBI best K:', best_dbi_k)  # 输出 DBI 谷值 K

# 用轮廓系数的候选 K 在训练数据上拟合最终模型
final_model = KMeans(n_clusters=best_sil_k, random_state=21, n_init=10)  # 函数⑤：创建最终模型
final_model.fit(X_train_ready)  # 函数⑤：拟合最终聚类

# 给留出数据分配簇号，不在留出数据上重新拟合
test_labels = final_model.predict(X_test_ready)  # 使用已训练模型预测留出样本的簇

# 把训练样本簇号对应到原始训练数据行
train_result = raw_df.loc[X_train.index].copy()  # 按原始索引取回训练行
train_result['簇标签'] = final_model.labels_  # 添加训练集聚类标签

# 打印主要检查信息
print('train transformed shape:', X_train_ready.shape)  # 输出训练处理矩阵形状
print('test transformed shape:', X_test_ready.shape)  # 输出测试处理矩阵形状
print('test cluster counts:', pd.Series(test_labels).value_counts().sort_index().to_dict())  # 输出测试样本各簇数量
print('train cluster counts:', pd.Series(final_model.labels_).value_counts().sort_index().to_dict())  # 输出训练样本各簇数量
print('business profile:')  # 打印画像表标题
print(train_result.groupby('簇标签')[numeric_features + ['cnt']].mean().round(2))  # 函数⑧：按簇比较原始单位均值

# 绘制训练集前两个连续特征的二维投影
plt.scatter(train_result['temp'], train_result['hum'], c=train_result['簇标签'])  # 函数⑨：按簇着色
plt.xlabel('temp')  # 设置横轴字段
plt.ylabel('hum')  # 设置纵轴字段
plt.title(f'Training clusters, K={best_sil_k}')  # 设置标题并标明 K
plt.savefig('day_cluster_scatter.png', dpi=150)  # 保存散点图
plt.close()  # 关闭当前图，释放绘图资源

# 绘制最终模型在处理后特征空间中的簇中心热力图
plt.imshow(final_model.cluster_centers_)  # 函数⑨：画标准化/独热后的中心矩阵
plt.colorbar()  # 显示颜色对应的数值
plt.xlabel('Processed feature index')  # 横轴代表处理后的特征索引
plt.ylabel('Cluster')  # 纵轴代表簇
plt.title('KMeans centers in processed feature space')  # 标明热力图展示的是处理后空间
plt.savefig('day_cluster_centers.png', dpi=150)  # 保存中心热力图
plt.close()  # 关闭当前图
```

**验收点**：

- 使用第十六课的 `day_clean.csv`，数据读入无错误，目标分析字段 `cnt` 未参与聚类特征；
- 划分之后，所有学习型预处理步骤只在训练数据上 `fit`，测试数据仅 `transform`；
- 训练与测试处理矩阵的行数分别对应各自样本数，输出列数相同，矩阵为二维且无缺失值；
- 候选 K 覆盖 2～8；每档均打印 inertia、轮廓系数、DBI，并在同一训练矩阵和该档 labels 上计算指标；
- 轮廓系数峰值 K 由最大值及其位置映射得到，DBI 谷值 K 由最小值及其位置映射得到；曲线横轴是 K、纵轴是 inertia；
- 最终模型在训练矩阵上拟合，测试簇号由最终模型预测得到；不得在测试矩阵上重新拟合；

- `X_train.index` 是训练样本的 index（行标签），不是“前多少行”。划分数据会打乱顺序，本轮前三个训练行标签实际为 `[423, 101, 675]`。
- `df.loc[...]` 用这些行标签从原表取回对应行，并保持提供的顺序。这样得到的是训练样本对应的原始字段，既有 `temp`、`hum`，也有没放入聚类特征的 `cnt`，正好用于后续画像。
- `.copy()` 再建一份独立的表。之后给这份表加簇号，不会把这列加回原来的 `df`。
- `train_result` 只是这份结果表的变量名，不是新函数。

第二行：`train_result['簇标签'] = km.labels_`。

- `km.labels_` 是最终模型对**拟合时那批训练行**分配的 label（簇号），不是测试样本的预测。测试样本必须另外使用 `predict`。
- 左侧表示“新增一个叫 `簇标签` 的列”；右侧是簇号数组，按位置依次放入结果表。
- 能这样贴，是因为 `df.loc[X_train.index]` 的行序与 `X_train_ready` 保持一致。本轮前三个训练簇号为 `[0, 1, 0]`，按这个顺序回贴；不能先把结果表排序，再把原数组原样贴上。

老师基于你本轮最终模型得到的真实核对输出：

```text
训练索引前3项： [423, 101, 675]
训练簇号前3项： [0 1 0]
         temp       hum   cnt  簇标签
423  0.359167  0.395833  4363    0
101  0.502500  0.739167  2034    1
675  0.280833  0.567083  5686    0
```

注意：簇号只表示编号。你本轮使用的划分与示例不同，不能把示例的“簇 0 特征”原封不动套到这次簇 0 上；应读你自己的画像表。

**顺序问题的直接答案**：不能保证。`train_result` 排序会改变每天所在的位置，而 `km.labels_` 仍保持模型拟合时的行序；把未重排的数组按位置贴上，可能把某一天的簇号给到另一天。保持两边相同行序后再贴标签，才能保证对应。本例不需要先排序；直接使用 `df.loc[X_train.index]` 取行，再贴 `km.labels_` 即可。你可以对照理解，无需先回答检查题才能获得参考答案；档案只记录已经实证的能力。

## 【本节重点总结】

1. 类别代码要作为类别处理，连续特征要按训练集学到的尺度转换。
2. K 的选择要同时核对 inertia 肘部、轮廓系数峰值和 DBI 谷值，不可只看一项或手写结果。
3. 聚类标签只表示分组编号；业务解释要回到原始数据表中的真实统计量。
