## 【知识速览】函数速查表

| 函数/属性 | 作用 | 记忆点 / 坑 |
|---|---|---|
| `StandardScaler().fit_transform(X)` | 标准化：各列拉回均值 0、标准差 1 | 必须在 KMeans **之前**做；返回 numpy 数组 |
| `KMeans(n_clusters=k, random_state=13, n_init=10)` | 把样本分成 k 簇 | 先创建再 `fit`；`random_state` 固定可复现、`n_init=10` 防运气差 |
| `km.labels_` | 每个样本的簇号 | 尾下划线属性：`fit` 之后才有、**不加括号** |
| `km.cluster_centers_` | 各簇中心（标准化坐标） | 形状 (k, 特征数)，想看原始单位要 `inverse_transform` |
| `km.inertia_` | 簇内平方和（越小越紧凑） | K 越大**必然**越小，不能直接取最小的 K |
| `silhouette_score(X, labels)` | 轮廓系数：内紧外松，越大越好 | 找**峰值**；`labels` 必须是同一次聚类的 `km.labels_` |
| `davies_bouldin_score(X, labels)` | DBI：簇间相似度，越小越好 | 找**谷值**，方向跟轮廓系数**相反** |
| `max(列表)` / `min(列表)` + `.index(...)` | 程序找峰/谷对应的 K | 不许手写死数字 |
| `plt.plot(Ks, inertias, 'o-')` | 画肘部曲线 | x 必须显式传 K 值列表 |
| `plt.scatter(x, y, c=簇标签, cmap='viridis')` | 散点图按簇着色 | `c` 传的是簇标签数组 |
| `plt.imshow(km.cluster_centers_)` | 聚类中心热力图 | 别忘 `colorbar` 和两轴刻度标签 |
| `df.groupby('簇标签').mean()` | 按簇算各列平均 | 原始尺度的数最好读 |
| `df['簇标签'].value_counts().sort_index()` | 各簇样本数 | `.to_dict()` 变成字典 |

### 一、概念题（每题 2 分，共 10 分）

1. 无监督学习就是让机器在没有标签的数据中发现规律。
KMeans 的训练数据里没有标签y。
靠样本到样本簇中心的距离。
2. 确保特征数据都是统一单位。
如果不做，就会影响最终标签的预测，比如火车票和行驶距离，就必须标准化。
3. inertia是每个簇中样本到簇中心的平均距离。
因为随K增大，inertia是必然减小的，簇数量的增多让样本的相关性被增强了，离散的样本少了，距离就少了，所以不能直接选inertia最小的K。
定inertia最能体现由陡到缓的那个K。

改：inertia_是所有样本到各自簇中心的距离平方和，表示簇内样本紧密程度，不是平均距离。K↑，簇↑，样本可以更靠近各自的簇中心，inertia通常持续下降。若只选择最小的inertia，往往会直接选择最大的K，是去判断聚类的意义。肘部法则需要观察K增大时inertia的下降幅度，前面下降的快，后来下降变缓的位置就是肘部K。

4. 轮廓系数越大越好，DBI越小越好。
从KMeans模型中得来，labels = km.labels_，这个是每个样本的簇号。

改：轮廓系数越大越好，表示簇内越紧密，簇间越分离；
DBI越小越好，表示各簇内部紧密且彼此区分更好，
label来自同一次KMeans聚类的km.labels_，并且必须对应传入的同一份特征X，不能拿一份数据标签去评价另一份数据，也不能把不同的K或模型产生的标签混用。

5. 散点图是每个样本的分散程度，用来回答这个簇分的好不好；
聚类中心热力图是和K簇的相关性，用来看这个K某个指数高还是低；
分组平均特征表不知道。
因为需要通过数字大小来判断这个指数是高还是低。

改：
- 散点图：观察样本在选定两个特征上的分布，以及不同簇之间是否分开。
- 聚类中心热力图：比较各簇中心在各个特征上的相对高低，观察每个簇的整体特征画像。
- 分组平均特征表：按簇统计每个原始特征的平均值，用来进行具体的业务解释。

簇的名字必须引用自己表中的数字，因为名字是对当前数据的解释，不能凭感觉命名。例如，簇 2 的平均房价为 61684.90、人口密度为 57.54、地铁站数为 2.92，因此可以称为“低密度高房价、交通不便型”，而不是只写“高消费群体”却不给依据。

### 二、函数题（每题 2 分，共 8 分）

1. 返回被标准化后的特征。
均值约等于0.。
标准差约等于1.。

改：
返回标准化后的特征数组；标准化后，各列的均值约等于 0，标准差约等于 1。fit 学习每列的均值和标准差，transform 使用这些统计量完成转换；fit_transform 是先学习再转换。

2. 分别管K的数量，随机种子，分10次的最小值。
每个样本的簇号，簇中心，簇内样本到簇中心距离的平方和，聚类的时候才有。

改：
n_clusters=3：指定要分成 3 个簇。
random_state=13：固定随机过程，使同样代码多次运行时更容易得到可复现结果。
n_init=10：使用 10 组不同的初始簇中心分别运行 KMeans，再保留结果较好的那一次；不是简单地“分 10 次取最小值”而不考虑完整训练过程。
km.labels_：每个样本所属的簇编号，长度等于样本数。
km.cluster_centers_：每个簇的中心，行数等于簇数，列数等于特征数。
km.inertia_：当前模型所有样本到各自簇中心的距离平方和。

3. 返回的是特征的轮廓系数，返回的是特征的DBI指数，方向不知道。
labels是样本的簇号，不同簇，编号就不同。

改：
silhouette_score(X, labels) 返回整体轮廓系数，越大越好；davies_bouldin_score(X, labels) 返回 DBI，越小越好。labels 是每个样本的簇编号，必须来自对这份 X 进行同一次聚类得到的 km.labels_。如果 X 和 labels 不是同一批样本、不是同一次 KMeans 的结果，指标计算的对象就错位，评价结果没有意义。

4. 每个簇号，样本到该簇的平均距离。
簇标签数组。
热力图，横轴是参数，纵轴是K簇。

改：
plt.plot(Ks, inertias, 'o-')：Ks 是横轴上的 K 值列表，inertias 是纵轴上的 inertia 列表；两者一一对应，'o-' 表示用圆点和线连接。
plt.scatter(x, y, c=...)：x 和 y 是每个样本的横纵坐标；c 指定每个点的颜色，传入簇标签后就能按簇着色。
plt.imshow(km.cluster_centers_)：把聚类中心矩阵画成热力图；默认横轴对应特征列，纵轴对应簇，也就是矩阵的行。
### 三、纠错题（每题 3 分，共 12 分）

1. 错在没有标准化，会导致样本到簇中心有的很近有的很远。
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df)
km = KMeans(n_clusters=3, random_state=13, n_init=10)

2. 样本簇号和特征写反了

先数据，再簇号

s = silhouette_score(km.labels_, X_scaled) 错在哪里？
函数参数顺序写反了。第一个参数必须是特征矩阵 X，第二个参数必须是簇标签 labels。正确写法是：

#### 一、概念题

**1. 什么是无监督学习？KMeans 的训练数据里有没有标签 y？它靠什么判断两个样本「像」？**

无监督学习是：训练数据没有人工提供的标签，模型自己从数据中发现结构或分组规律。KMeans 不需要标签 `y`，只使用特征矩阵 `X`。它主要根据样本之间的距离判断相似程度：距离越近，通常认为样本越相似；距离越远，通常认为样本差异越大。

**2. 为什么 KMeans 之前必须 `StandardScaler` 标准化？不做的后果是什么？**

KMeans 依靠距离进行聚类。如果不同特征的单位或数值范围差别很大，数值范围大的特征会在距离计算中占更大比重，挤压其他特征的影响。`StandardScaler` 会把各列转换到相近的尺度，使不同量纲的特征在距离计算中更公平。不标准化可能导致簇划分主要被某一个大数值特征控制，聚类结果失真。

**3. `inertia_` 是什么？为什么「选 inertia 最小的 K」是错的？肘部法则怎么定 K？**

`inertia_` 是所有样本到各自簇中心的距离平方之和，表示簇内样本的紧密程度；它不是平均距离。K 增大时，簇数量变多，样本可以更靠近各自的簇中心，所以 `inertia_` 通常会持续下降。若只选最小值，往往会直接选最大的 K，失去判断聚类结构的意义。肘部法则要观察 K 增大时 `inertia_` 的下降幅度：前面下降很快，后来下降明显变缓的位置，就是候选肘部 K。

**4. 轮廓系数和 DBI 各是越大越好还是越小越好？`labels` 从哪来、有什么讲究？**

轮廓系数越大越好，表示簇内更紧密、簇间更分离；DBI 越小越好，表示各簇内部紧密且彼此区分得更好。`labels` 应来自同一次 KMeans 聚类的 `km.labels_`，并且必须对应传入的同一份特征矩阵 `X`。不能拿一份数据的标签去评价另一份数据，也不能把不同 K 或不同模型产生的标签混用。

**5. 散点图、聚类中心热力图、分组平均特征表各回答什么问题？为什么命名必须引用表中数字？**

- 散点图：观察样本在选定两个特征上的分布，以及不同簇之间是否分开。
- 聚类中心热力图：比较各簇中心在各个特征上的相对高低，观察每个簇的整体特征画像。
- 分组平均特征表：按簇统计每个原始特征的平均值，用来进行具体的业务解释。

簇的名字必须引用自己表中的数字，因为名字是对当前数据的解释，不能凭感觉命名。例如，簇 2 的平均房价为 61684.90、人口密度为 57.54、地铁站数为 2.92，因此可以称为“低密度高房价、交通不便型”，而不是只写“高消费群体”却不给依据。

#### 二、函数题

**1. `StandardScaler().fit_transform(X)` 返回什么？标准化后各列的均值、标准差约等于多少？**

它返回标准化后的特征数组。标准化后，各列的均值约等于 0，标准差约等于 1。`fit` 学习每列的均值和标准差，`transform` 使用这些统计量完成转换；`fit_transform` 是先学习再转换。

**2. `KMeans(n_clusters=3, random_state=13, n_init=10)` 三个参数各管什么？三个属性分别是什么？**

- `n_clusters=3`：指定要分成 3 个簇。
- `random_state=13`：固定随机过程，使同样代码多次运行时更容易得到可复现结果。
- `n_init=10`：使用 10 组不同的初始簇中心分别运行 KMeans，再保留结果较好的那一次；不是简单地“分 10 次取最小值”而不考虑完整训练过程。

- `km.labels_`：每个样本所属的簇编号，长度等于样本数。
- `km.cluster_centers_`：每个簇的中心，行数等于簇数，列数等于特征数。
- `km.inertia_`：当前模型所有样本到各自簇中心的距离平方和。

这些属性要在模型完成 `fit` 之后才有可靠结果。

**3. `silhouette_score(X, labels)` 和 `davies_bouldin_score(X, labels)` 的返回值各是什么、方向如何？为什么 `labels` 必须是同一次聚类给出的？**

`silhouette_score(X, labels)` 返回整体轮廓系数，越大越好；`davies_bouldin_score(X, labels)` 返回 DBI，越小越好。`labels` 是每个样本的簇编号，必须来自对这份 `X` 进行同一次聚类得到的 `km.labels_`。如果 `X` 和 `labels` 不是同一批样本、不是同一次 KMeans 的结果，指标计算的对象就错位，评价结果没有意义。

**4. 三个绘图函数的参数分别表示什么？**

- `plt.plot(Ks, inertias, 'o-')`：`Ks` 是横轴上的 K 值列表，`inertias` 是纵轴上的 inertia 列表；两者一一对应，`'o-'` 表示用圆点和线连接。
- `plt.scatter(x, y, c=...)`：`x` 和 `y` 是每个样本的横纵坐标；`c` 指定每个点的颜色，传入簇标签后就能按簇着色。
- `plt.imshow(km.cluster_centers_)`：把聚类中心矩阵画成热力图；默认横轴对应特征列，纵轴对应簇，也就是矩阵的行。

#### 三、纠错题

**1. 直接在原始数据上聚类错在哪里？**

错在没有考虑不同特征的量纲和范围。KMeans 使用距离，如果某列数值范围远大于其他列，它会过度影响聚类结果。应先标准化，再用标准化后的数据训练模型：

```python
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df)
km = KMeans(n_clusters=3, random_state=13, n_init=10)
km.fit(X_scaled)
```

**2. `s = silhouette_score(km.labels_, X_scaled)` 错在哪里？**

函数参数顺序写反了。第一个参数必须是特征矩阵 `X`，第二个参数必须是簇标签 `labels`。正确写法是：

```python
s = silhouette_score(X_scaled, km.labels_)
```

也就是说，先传数据，再传簇号。

**3. 为什么不能因为 K=10 的 `inertia_` 最小就选 K=10？**

因为 K 越大，`inertia_` 通常越小，最小值往往只是因为簇数更多，并不代表聚类结构最好。应画出 K 与 inertia 的肘部曲线，观察下降由快变慢的位置，再结合轮廓系数、DBI 等指标进行判断。

**4. 只写“簇 0 是高消费群体”错在哪里？**

错在没有说明“高”的依据，也没有引用当前数据的实际统计结果。正确写法应引用自己打印的分组平均表，例如：

> 簇 2 可称为“低密度高房价、交通不便型”：平均人口密度为 57.54，平均房价为 61684.90，平均地铁站数只有 2.92。

这里的簇名、数字和结论都来自本题自己的 `means` 表。
