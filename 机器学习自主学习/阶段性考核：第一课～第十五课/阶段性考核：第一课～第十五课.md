| `drop` | 删列 | 切特征表用它 |
| `train_test_split` | 切训练集/测试集 | 返回四件套，顺序是考点；随机种子固定才可复现 |
| `LinearRegression` | 线性回归模型 | `fit` 只喂训练集 |
| `fit` / `predict` | 训练 / 预测 | 特征都要二维 |
| `coef_` / `intercept_` | 学到的斜率 / 截距 | 尾下划线属性，训练后才有 |
| `score` | 模型自带打分 | 回归下就是 R²；成绩看测试集 |
| `mean_absolute_error` / `mean_squared_error` / `root_mean_squared_error` / `r2_score` | MAE / MSE / RMSE / R² | 前三个越小越好，R² 越接近 1 越好 |
| `Ridge` / `Lasso` | L2 / L1 正则化 | `alpha` 控惩罚力度；Lasso 能把系数压成 0 |
| `KFold` | 定怎么切折 | 默认不洗牌，有序数据会切偏 |

| `GridSearchCV` | 网格搜索挑超参数 | `best_params_` 选的参数、`best_score_` 裁判分 |
| `StandardScaler` | 标准化 | 必须在聚类前做 |
| `KMeans` | 分成 k 簇 | 随机种子固定、`n_init` 防运气差 |
| `labels_` / `cluster_centers_` / `inertia_` | 簇号 / 簇中心 / 簇内平方和 | fit 后才有，不加括号 |
| `silhouette_score` / `davies_bouldin_score` | 轮廓系数 / DBI | 找峰 / 找谷，方向相反 |
| `max` / `min` + `.index` | 程序找峰/谷对应的 K | 不许手写死数字 |
| `groupby(...).mean` | 按簇算各列平均 | 解读就引这张表的数字 |
| `value_counts` | 各簇样本数 | 排个序更好读 |
| `plt.plot` / `plt.scatter` / `plt.imshow` | 折线 / 散点 / 热力图 | 折线的 x 要显式传；散点的着色传簇标签 |

| `range` / `append` / `len` / `round` | 整数序列 / 追加 / 个数 / 保留小数 | `range` 终点不含；round 打印不补零 |
